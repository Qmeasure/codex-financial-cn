# 最佳实践、示例和质量指南

本文档提供示例、成功要点、常见错误和综合质量检查清单。

## 标题示例

### 好的业绩更新标题：
- "Nike FY24 Q2：DTC 强劲抵消批发疲软 — 维持增持，目标价 95 美元"
- "Tesla Q3'24：Cybertruck 爬坡快于计划 — 上调预测，目标价升至 285 美元"
- "LVMH Q4'24：时装与皮具韧性较强，酒类疲弱 — 符合预期，重申买入"
- "Apple FY24 Q1：服务超预期、iPhone 低于预期 — 季度表现分化，下调目标价至 185 美元"

### 差的标题（避免）：
- "Nike 季度更新"（太泛，没有结论）
- "公司发布业绩"（只陈述显而易见的事实，没有分析）
- "Q3 业绩分析"（没有公司名，没有观点）

## 成功要点

1. **速度很重要**：业绩后 24-48 小时内发布，而不是几天后

2. **先给结论**：超预期还是低于预期？上调还是下调预测？

3. **所有内容都量化**：“强劲”没有意义，“12 亿美元收入高于预期 1.5 亿美元”才清楚

4. **聚焦驱动因素**：不要只写“收入超预期”，要解释原因

5. **展示推导过程**：旧预测 → 新预测，并说明原因

6. **如影响重大，更新目标价**：如果预测变化超过 5%，通常 PT 也应变化

7. **纳入业绩会信息**：引用管理层评论，不要只分析新闻稿

8. **与 peers 比较**：如果类似公司已披露业绩，说明相对表现

9. **保持简洁**：这不是综合报告，重点放在季度业绩

10. **把趋势画出来**：季度趋势图最有价值

## 常见错误

❌ **过于全面**：不要为季度业绩写成首次覆盖报告长度

❌ **缺少超预期/低于预期判断**：开头必须说明业绩是否高于或低于预期

❌ **未更新预测**：必须提供更新后的前瞻预测

❌ **语言模糊**：写“表现强劲”但没有量化

❌ **忽视指引**：如果公司给出指引，必须充分分析

❌ **太慢**：业绩后 5 天以上发布会失去时效性

❌ **重复基础信息**：不要花 3 页解释公司做什么

❌ **缺少目标价更新**：如果预测发生重大变化，PT 通常也应更新

❌ **没有投资影响**：必须把业绩与投资逻辑和评级连接起来

❌ **缺少引用**：每个数字都需要带可点击超链接的来源

❌ **纯文本 URL**：所有 URL 必须格式化为可点击超链接

## 综合质量控制清单

交付业绩更新前，核验以下所有项目：

### 内容与分析清单

**超预期/低于预期分析：**
- [ ] 报告以超预期/低于预期分析开头
- [ ] 具体差异已量化（例如“高于预期 1.2 亿美元或 3%”）
- [ ] 解释业绩为何不同于预期
- [ ] 分析每个关键指标（收入、EPS、利润率等）

**指标与表现：**
- [ ] 所有关键指标都有同比比较
- [ ] 相关时包含环比比较
- [ ] 提供分部/地域/产品拆分
- [ ] 分析经营指标（客户数、ARPU、销量等）

**指引与预测：**
- [ ] 已分析并量化指引变化（如公司提供）
- [ ] 如果没有指引，已明确说明
- [ ] 提供当前年度更新预测
- [ ] 提供下一年度更新预测
- [ ] 清楚展示旧预测 vs. 新预测
- [ ] 解释变化内容和原因

**估值与评级：**
- [ ] 如业绩支持，已更新目标价
- [ ] 如果 PT 不变，明确说明维持
- [ ] 已解释估值方法
- [ ] 评级已确认或调整，并给出清晰理由
- [ ] 已评估投资逻辑，并在需要时更新

### 格式与长度清单

**整体结构：**
- [ ] 报告为 8-12 页（不要更短或更长）
- [ ] 第 1 页采用业绩摘要格式
- [ ] 第 1 页标题包含“业绩更新”（不是“首次覆盖”）
- [ ] 使用事件驱动标题（例如“强劲的第三季度业绩……”）

**表格：**
- [ ] 包含 1-3 张摘要表（不是综合大表）
- [ ] 所有表格都有清晰列名
- [ ] 所有表格都有表头行底色
- [ ] 所有表格底部都有来源行
- [ ] 预测表展示旧值 vs. 新值，并包含变化列

**图表：**
- [ ] 全文嵌入 8-12 张图表
- [ ] 所有图表上方都有“图 X - [标题]”图题
- [ ] 所有图表下方都有“来源：[来源]”行
- [ ] 图表聚焦季度趋势
- [ ] 图表突出变化（超预期/低于预期、预测调整）
- [ ] 图表使用专业样式

### 引用与来源清单 ⭐⭐⭐ 强制

**图表和表格引用：**
- [ ] 每张图表都有具体来源，含文档名称和日期
- [ ] 每张表都有具体来源，含文档引用
- [ ] 适用时，来源引用包含页码或幻灯片编号

**超预期/低于预期引用：**
- [ ] 超预期/低于预期分析引用一致预期来源（Bloomberg、FactSet 等）
- [ ] 一致预期来源包含“截至”日期（业绩前收盘）
- [ ] 公司披露结果引用业绩新闻稿或 10-Q

**指引引用：**
- [ ] 当前指引引用业绩会文字稿或新闻稿
- [ ] 先前指引引用上一季度材料
- [ ] 当前和先前指引来源均有超链接

**统计与指标：**
- [ ] 关键统计数据有带来源的脚注
- [ ] 脚注引用具体文档和页码/slide 编号
- [ ] 管理层引用注明发言人姓名和来源文档

**超链接：** ⭐⭐⭐ 关键
- [ ] 所有 URL 都是可点击超链接（不是纯文本）
- [ ] 超链接使用有意义的显示文本
- [ ] Word 文档中超链接为蓝色、带下划线格式
- [ ] 超链接已测试且可用（Ctrl+Click 打开正确页面）
- [ ] 所有 SEC 披露文件链接到 EDGAR viewer；A股/港股材料链接到交易所或公司公告页
- [ ] 所有业绩材料都有超链接（公告、文字稿、演示材料）
- [ ] 用于比较的上一季度材料有超链接
- [ ] 文档任何位置都不显示裸 URL

**来源章节：**
- [ ] 报告末尾包含“来源与参考”章节
- [ ] 该章节列出所有业绩材料及日期
- [ ] 所有材料都有可点击超链接
- [ ] 列出一致预期数据来源（订阅数据没有链接也需列出）
- [ ] 包含先前期间参考材料

### 准确性清单

**数字准确性：**
- [ ] 数字与公司披露结果完全一致
- [ ] 所有计算数学正确
- [ ] 预测变化计算正确
- [ ] 估值计算准确
- [ ] 图表与文字描述一致

**事实准确性：**
- [ ] Ticker symbol 无拼写错误
- [ ] 公司名称无拼写错误
- [ ] 日期当前且准确
- [ ] 季度/年份引用正确
- [ ] 年份标记正确（A 表示 actual，E 表示 estimate）

### 时效性清单

**发布时间：**
- [ ] 报告在业绩发布后 24-48 小时内发布
- [ ] 如果晚于 48 小时，标注为 “delayed reaction”
- [ ] ✅ **已通过搜索近期业绩核验所有数据来自最新季度**
- [ ] ✅ **没有依赖知识截止日期，已主动搜索当前数据**
- [ ] 一致预期为业绩前预测（不是业绩后预测）
- [ ] 没有过时信息
- [ ] 业绩发布日期在过去 1-3 个月内（不是 6 个月以上）

### 写作风格清单

**清晰与直接：**
- [ ] 以数字开头（写“收入增长 15% 至 12 亿美元”，不要写“收入强劲”）
- [ ] 使用 “vs.”，不要使用 “versus”
- [ ] 全篇直接、简洁
- [ ] 聚焦新增信息，不重复公司基础介绍
- [ ] 避免无量化的模糊语言（如“表现强劲”）

**专业标准：**
- [ ] 保持机构语气
- [ ] 全篇术语一致
- [ ] 不使用非正式语言
- [ ] 使用正确金融记号

## 交付前最终检查

向用户发送报告前，执行以下快速最终检查：

### 5 分钟最终审阅：
1. **第 1 页**：评级是否清楚？目标价是否更新？关键结论是否有说服力？
2. **数字**：披露结果是否与公司新闻稿完全一致？
3. **引用**：抽查 3-4 个 figures/tables，是否都有带可点击超链接的来源？
4. **预测**：旧预测 vs. 新预测是否清楚？变化是否已解释？
5. **图表**：是否嵌入全部 8-12 张？是否都有编号和 caption？
6. **长度**：是否为 8-12 页（不是 6 页，也不是 15 页）？
7. **超链接**：测试 3-4 个超链接，Ctrl+Click 是否可用？
8. **时效性**：是否在业绩后 48 小时内发布？

如果所有项目均通过，报告可以交付。

## 摘要交付格式

向用户交付完成的报告时，提供以下摘要：

```
[公司] Q[X] [年份] 业绩更新已完成

业绩结果：[超预期 / 符合预期 / 低于预期]
- 收入：$X.XB（高出/低于 $XXM 或 X%）
- EPS：$X.XX（高出/低于 $X.XX）

关键结论：
■ [Takeaway 1]
■ [Takeaway 2]
■ [Takeaway 3]

更新预测：
- FY[Year]E 收入：$XX.XB（此前：$XX.XB，[+/-]X%）
- FY[Year]E EPS：$X.XX（此前：$X.XX，[+/-]X%）

评级：[维持 / 上调 / 下调] [评级]
目标价：$XXX（此前：$XXX）- [+/-]XX% 上涨空间

交付物：
✓ 8-12 页业绩更新报告（DOCX）
✓ 8-12 张嵌入图表
✓ 更新预测，含旧值/新值比较
✓ 完整来源章节，含可点击超链接
✓ [可选：更新后的 XLS 财务模型]

File: [Company]_Q[X]_[Year]_Earnings_Update.docx
```
