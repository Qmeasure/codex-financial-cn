# 报告结构与模板

本文档提供业绩更新 DOCX 报告的逐页模板和格式要求。

## 中文机构材料补充规则

本报告必须遵守根目录 `CN_DOCX_OUTPUT_CONTRACT.md`，默认使用 `cn_institutional_research_brief` preset。报告必须生成真实 DOCX 文件；Markdown、聊天摘要或纯文本不能替代主交付物。

### 市场、页眉和币种

- **A股**：页眉或首页元数据必须标注股票代码、交易所、人民币口径、会计准则、公告日期和数据日期；金额默认使用人民币万元/亿元。
- **港股**：页眉或首页元数据必须标注港交所代码、港元口径、会计准则、公告日期和数据日期；涉及人民币业务数据时需说明是否折算。
- **美股/ADR**：页眉或首页元数据必须标注交易所或 ADR 代码、美元口径、US GAAP/IFRS、SEC 或公司披露日期、数据日期。
- **跨市场比较**：必须标注币种、汇率来源、折算日期、会计准则和是否统一口径。

### 评级、目标价和口径说明

- 无评级时写“未评级”，不得空置或编造评级。
- 无目标价时写“未设目标价”，不得空置或编造目标价。
- 一致预期未接入 Bloomberg、FactSet、S&P Global、LSEG 等授权源时，只在数据源发现记录中列为未覆盖数据项，不得写入固定提示标签。
- 订阅数据源没有公开 URL 时，必须列出数据源/数据库名称和数据日期，不得写入固定提示标签。

### 必含章节

每份中文业绩更新报告必须包含：

- “数据来源与口径说明”：列明官方披露、用户文件、数据库/MCP、免费网页辅助来源、数据日期、币种、单位和会计准则。
- “数据来源与口径说明”必须包含“数据源发现记录摘要”：当前会话检查过哪些 MCP / connector / 授权数据源；哪些适用、哪些不可用或覆盖不足；哪些数据来自官方披露；哪些数据来自免费网页辅助；哪些数据项未被 Bloomberg / FactSet / LSEG / S&P Capital IQ 等授权源覆盖。
- “风险与数据缺口”：列明缺少授权源、口径不一致、未取得一致预期、未完成视觉 QA 等问题。
- “免责声明”：说明本材料仅供专业人员审阅，不构成投资、法律、税务、会计或监管建议。

## 格式要求

### 1. 第 1 页要求
- 清晰写明评级（维持跑赢、上调至买入等）
- 醒目展示更新后的目标价
- 用摘要表展示旧/新预测
- 使用 ■ 符号写 3-4 个段落式要点

### 2. 所有表格要求
- 底部包含 Exhibit 来源行：仅保留最重要的 1 个来源，使用可点击链接
- 列标题清晰
- 表头行使用底色
- 缺失的一致预期或市场口径单元格显示 `—`，详细缺口放入“数据来源与口径说明”

### 3. 所有图表要求
- 图表上方写“图 X - [标题]”
- Exhibit 下方写单一主来源：“来源：[有意义显示文本]”
- 来源 caption 默认 6pt、最大 7pt；hyperlink run 必须显式设置同一小字号
- 使用专业样式
- 完整来源清单放在“数据来源与口径说明”或“来源与参考资料”，不得堆在 Exhibit 下方

### 4. 年份标记
- 使用 A 表示实际值（Q3'24A）
- 使用 E 表示预测值（Q4'24E）

### 5. 写作风格
- 用数字开头（写“收入增长 15% 至 $1.2B”，不要只写“收入增长强劲”）
- 使用 “vs.”，不要使用 “versus”
- 直接、简洁
- 聚焦新的变化

### 6. 超链接要求
- 所有 URL 都必须在 Word 中设置为可点击超链接
- 蓝色、带下划线，支持 Ctrl+Click 打开
- 显示文本必须有意义（不要直接显示原始 URL）
- 每条来源引用在适用时都应带可点击链接
- 不使用纯文本 URL，始终设置为超链接
