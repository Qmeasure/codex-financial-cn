# 业绩更新详细工作流

本文档提供业绩更新流程各阶段的详细分步说明。

## ⚠️⚠️⚠️ 关键警告：始终使用最新业绩数据 ⚠️⚠️⚠️

**先停下来读这一段：**

训练数据已经过时。必须按 `../../../DATA_QUERY_ORDER_CN.md` 先填写数据源发现记录，列明可用/不可用 MCP、connector、已授权数据源和官方材料；Gate 通过后，才可在覆盖不足时网页搜索并获取**最新**业绩材料。使用过时业绩数据是业绩分析中的第一大错误。

**开始前：**
1. **检查今天日期** - 写下当前日期
2. **生成数据源发现记录** - 先列出用户文件、当前会话可用 MCP/connector、本地数据库和已授权数据源
3. **核验日期** - 确认业绩公告发生在过去 3 个月内
4. **如果超过 3 个月** - 说明拿错季度，重新按数据查询顺序查找

## 阶段 1：业绩数据收集（30–60 分钟）

### 步骤 1：识别最新业绩期间

**关键**：始终按 `../../../DATA_QUERY_ORDER_CN.md` 获取最新业绩，不要依赖知识截止日期。
**关键**：不要使用训练数据中的业绩数据，它已经过时。

**步骤 1a：获取最新业绩公告**

**🚨 先查可用 MCP/已授权源，再在不足时网页搜索；训练数据已经过时。🚨**

**强制步骤 0：填写数据源发现记录**

在任何网页搜索、公司官网抓取、SEC/交易所抓取前，先按 `../../../DATA_QUERY_ORDER_CN.md` 填写：

```
数据源发现记录
- 用户文件：
- 当前会话可用 MCP / connector：
- 本地数据库 / 已授权数据源：
- 本任务适用数据源：
- 已调用或未调用原因：
- 覆盖缺口：
- 降级路径：
```

**Gate 规则：** 未生成该记录，不得进入网页搜索，不得抓取公司官网、SEC 或交易所页面，也不得开始写报告。

**强制步骤 1：检查今天日期**
- **明确写下今天日期**：[月] [日], [年]
- **用该日期核验**找到的任何业绩是否在 3 个月内
- **示例**：“今天是 2024 年 10 月 29 日”

**强制步骤 2：按顺序查找“最新业绩”**
- **先完成数据源发现记录**，列明当前会话可用/不可用的财报、公告、行情、业绩会或机构数据 MCP、connector、已授权数据源和官方材料。
- **Gate 通过且覆盖不足时，才可使用网页搜索**，检索词例如：
  - `[公司名称] 最新业绩结果`
  - `[公司名称] 最近季度业绩`
  - `[股票代码] 最新季度业绩`
- **或搜索公司投资者关系网站**：
  - 访问 `investor.[company].com` 或 `[company].com/investors`
  - 进入“新闻稿”、“新闻”或“业绩”栏目
  - **按日期排序，找到最新公告**
  - 查找关键词：`业绩`、`结果`、`财务结果`、`季度业绩`

**强制步骤 3：核验公告日期**
- **查看找到的业绩公告日期**
- **计算**：该日期距离今天是否在 3 个月内？
- **如果是** → 进入下一步
- **如果不是（超过 3 个月）** → 🚨 拿错季度，重新按数据查询顺序查找更近材料

**❌ 需要避免的常见错误：**
- ❌ 不检查 MCP/已授权源也不搜索，直接使用训练数据中的业绩数据
- ❌ 基于预期假设 “Q3 2024” 就是最新
- ❌ 抓到第一条业绩公告就使用，不检查日期
- ❌ 不把公告日期与今天日期对比
- ❌ 公告已经超过 4 个月仍继续分析

**✅ 正确做法：**
- ✅ 先检查今天日期
- ✅ 明确搜索“最新”或“最近”
- ✅ 阅读材料上的真实公告日期
- ✅ 确认公告日期距离今天在 3 个月内
- ✅ 不确定时，先重新填写数据源发现记录；Gate 通过且覆盖不足时再换检索词搜索

**强制步骤 4：识别季度**
- **阅读标题/头条**，识别季度（Q1、Q2、Q3、Q4 或财年季度）
- **阅读文件自身的发布日期**
- **同时验证季度名称和日期都是最新**

3. **如果 IR 网站不清楚，使用替代查找方式：**
   - 先确认数据源发现记录已列出可用/不可用 MCP、connector、授权源和官方材料
   - Gate 通过且覆盖不足时网页搜索：`[公司名称] 最新业绩结果`
   - Gate 通过且覆盖不足时网页搜索：`[公司名称] 最近季度业绩`
   - Gate 通过且覆盖不足时网页搜索：`[股票代码] 最新季度业绩`
   - SEC EDGAR 或交易所抓取也必须在 Gate 通过后执行，并记录原因

**能找到最新数据的搜索示例：**
- `Nike 最新业绩结果` → 返回最近已报告季度
- `AAPL 最近季度业绩` → 显示 Apple 最新业绩
- `Tesla 2024 年 Q3 业绩` → 结果确认 2024 年 Q3 是否存在

**步骤 1b：理解公司财年日历**

通过搜索识别最新季度后，理解公司财年，以便正确解释该季度：

**常见财年模式：**
- **自然年（CY）**：Q1=1–3 月，Q2=4–6 月，Q3=7–9 月，Q4=10–12 月
- **Nike 财年**：Q1=6–8 月，Q2=9–11 月，Q3=12–2 月，Q4=3–5 月（5 月财年末）
- **Apple 财年**：Q1=10–12 月，Q2=1–3 月，Q3=4–6 月，Q4=7–9 月（9 月财年末）
- **Walmart 财年**：Q1=2–4 月，Q2=5–7 月，Q3=8–10 月，Q4=11–1 月（1 月财年末）

许多公司会在业绩公告页眉说明财年。如需要，搜索 `[公司] 财年日历`。

**步骤 1c：强制验证 - 确认已取得最新数据**

🛑 **停止 - 在核验下列所有项目之前不要继续：**

- [ ] ✅ **已生成数据源发现记录**
- [ ] ✅ **已说明本任务可用/不可用 MCP 或授权源**
- [ ] ✅ **若未使用 MCP/授权源，已写明原因**
- [ ] ✅ **在 Gate 通过前没有进行网页搜索、官网抓取、SEC/交易所抓取**
- [ ] ✅ **已按数据查询顺序主动查找**“最新业绩”或“最近业绩”
- [ ] ✅ **已找到业绩公告日期**：[月] [日], [年]
- [ ] ✅ **已确认公告日期距离今天在 3 个月内**（亲自计算）
- [ ] ✅ **没有只按今天日期推断季度**
- [ ] ✅ **能看到实际新闻稿**确认季度/期间
- [ ] ✅ **已打开并阅读**实际业绩材料（不是只假设存在）

**🚨 红旗 - 任何一项为真，都说明拿错季度：**
- 🚨 公告日期超过 90 天
- 🚨 依赖预期，而不是搜索找到的材料
- 🚨 还没有实际看过确认该季度存在的新闻稿或披露文件
- 🚨 未检查 MCP/已授权源且未搜索，直接使用训练数据
- 🚨 无法说出准确公告日期
- 🚨 当今天已是 2024+ 时，找到的公告日期来自 2023 年或更早

**如果存在任何红旗**：停止并重新按数据查询顺序查找。不要继续使用过时数据。

**步骤 1c：处理命名差异**

不同公司使用不同术语；要识别以下模式：

**季度术语：**
- “Q1 2024”、“FY24 Q1”、“2024 年第一季度”、“1Q24”
- “2024 财年第三季度”、“Q3 FY2024”、“3Q FY24”

**业绩公告标题：**
- “[公司] 发布 2024 年 Q3 业绩”
- “[公司] 公布 2024 财年第三季度财务业绩”
- “[公司] Q3 收入同比增长 15%”

**SEC 披露文件搜索：**
- 公司法定名称可能不同于常用名称（例如“Meta Platforms, Inc.”与“Facebook”）
- 用股票代码搜索可更可靠地找到披露文件
- 查找最近 10-Q（季度）或 10-K（如果是 Q4/全年）

### 步骤 2：收集业绩材料

在按数据查询顺序确认最新季度后，收集以下材料：

**⚠️ 重要：先检查 MCP/已授权源和官方材料，覆盖不足时再搜索并访问实际文件，不要依赖训练数据。**

**主要材料（必需）：**
- **业绩新闻稿** - 通常位于公司投资者关系网站的“新闻稿”或“新闻”
  - 进入 IR 网站并找到实际新闻稿
  - 搜索模式：`[公司名称] 最新业绩`、`[公司名称] Q[X] [年份] 业绩结果`
  - 查找 PDF 或 HTML 版本
  - **核验日期与步骤 1 找到的日期一致**（应在过去 1–3 个月内）
  - **阅读实际文件**，确认季度并获取报告数字

- **10-Q 或 10-K 披露文件** - 位于 SEC EDGAR（`sec.gov/edgar/searchedgar/companysearch.html`）
  - 用股票代码搜索
  - 第 1–3 季：查找最近 10-Q
  - 第 4 季：查找 10-K（年度报告）
  - 注意：可能在业绩公告后 1–5 天提交
  - 直接链接格式：`https://www.sec.gov/cgi-bin/viewer?accession=[accession-number]`

- **业绩会文字记录** - 🚨 **核验文字记录日期** 🚨
  - **搜索**：`[公司] 最新业绩会文字记录` 或 `[公司] Q[X] [年份] 业绩会文字记录`
  - **来源**：
    - 公司 IR 网站（部分公司直接发布文字记录）
    - Seeking Alpha：搜索 `[公司] [最新季度] 业绩会文字记录`
    - AlphaStreet、Motley Fool（替代来源）
  - **关键日期检查**：
    - ✅ **使用任何文字记录前，核验文字记录自身日期**
    - ✅ **文字记录日期必须与步骤 1 的业绩公告日期匹配**
    - ✅ **如果文字记录写的是“2023 年 Q2”，而公告是“2024 年 Q3”，说明拿错文字记录**
    - 🚨 **常见错误**：未检查日期就抓取旧文字记录
  - 如文字记录尚不可得，听网络直播回放，或注明需等待文字记录

**补充材料（如可得）：**
- **投资者演示/幻灯片** - 通常与新闻稿一起发布在 IR 网站
  - 标题通常为“Q[X] [年份] 业绩演示”或“投资者演示”
  - PDF 格式，包含管理层在业绩会上展示的幻灯片

- **补充数据文件** - 一些公司提供包含详细指标的 Excel 文件
  - 查找“补充财务信息”或“投资者数据表”

**参考材料（用于对比）：**
- **上一季度业绩** - 用于 QoQ 对比
  - 来自上一季度（约 90 天前）的业绩公告

- **去年同期季度** - 用于同比对比
  - 来自去年同一季度（4 个季度前）

- **此前预测** - 如果此前覆盖过该公司
  - 来自上一份业绩更新或首次覆盖报告
  - 检查此前对本季度指标的预测

- **一致预期** - 来自 Bloomberg、FactSet、Refinitiv 或 Yahoo Finance
  - 关键：使用业绩公告发布**前**的一致预期
  - 查找“截至[业绩公告前日期]”，确保是公告前一致预期
  - 用于超预期/低于预期分析

**🛑 进入步骤 3 前强制验证：**

- [ ] ✅ **所有材料显示同一季度**（例如都写 “Q3 2024”，不能混用季度）

**搜索与访问 - 核验已主动搜索：**
- [ ] ✅ **已搜索**“最新业绩”（不是按当前日期假设）

- [ ] ✅ **已通过日期确认**这是最新季度

### 步骤 4：识别业绩会核心主题

听取或阅读业绩会文字记录，并记录：
- 管理层语气（自信、谨慎、防御？）
- 强调的核心议题（产品发布、地域趋势、竞争）
- 分析师提问（投资者担心什么？）
- 公司指引（上调、下调、维持、首次给出？）
- 任何意外信息或超预期表述

## 阶段 2：分析（2–3 小时）

### 步骤 5：超预期/低于预期分析

对每个超预期或低于预期的关键指标，解释：

**如果超预期：**
- 超预期由什么驱动？
- 是一次性因素还是可持续因素？
- 管理层是否上调未来指引？
- 对我们的投资论点有何影响？

**如果低于预期：**
- 问题出在哪里？
- 是公司特有问题还是行业普遍问题？
- 管理层是否采取纠偏行动？
- 对我们的投资论点有何影响？

**示例格式：**
```
■ **DTC 表现强劲推动收入超预期 3%**

收入为 135 亿美元，高于我们 131 亿美元预测 4 亿美元（3%），
也高于一致预期 132 亿美元 3 亿美元（2%）。超预期主要由
Direct-to-Consumer 渠道驱动，该渠道同比增长 18%（我们的预测为 12%），
抵消了低于预期的批发业务（-5%，而我们预测为持平）。
管理层提到数字化需求强劲和成功产品发布（Pegasus 40 跑鞋、新 Jordan 配色）
是关键驱动因素。DTC 目前占总收入的 42%，高于一年前的 38%，
显示渠道转型策略正在取得成效。
```

### 步骤 6：分部/地域/产品分析

按以下维度分析表现：
- 业务分部（如公司多分部）
- 地域（北美、欧洲、中国等）
- 产品类别
- 渠道（零售、批发、电商）

识别：
- 哪些部分超预期？
- 哪些部分低于预期？
- 与前几个季度相比的趋势
- 管理层对各领域前景的表述

### 步骤 7：利润率分析

分析盈利能力：
- 毛利率上升还是下降？为什么？
- 经营利润率上升还是下降？为什么？
- 关键驱动因素（定价、mix、成本、杠杆）
- 未来展望

### 步骤 8：指引分析

如果公司给出指引：
- 将新指引与此前指引对比
- 与内部预测和市场预期对比
- 评估可信度（公司是否有保守指引后超预期的历史？）
- 识别指引背后的关键假设

如果公司未给出指引：
- 明确说明这一点
- 基于结果和管理层表述提供独立展望

### 步骤 9：更新财务模型

更新以下预测：
- 当年（剩余季度）
- 下一年
- 如需要，也更新再下一年

**清晰展示：**
```
更新后预测：
─────────────────────────────────────────────────
                        旧预测      新预测      变化        原因

FY2024E EBITDA          $X.XB       $X.XB       +X.X%      [Brief reason]
FY2024E EPS             $X.XX       $X.XX       +X.X%      [简要原因]

FY2025E 收入            $XX.XB      $XX.XB      +X.X%      [简要原因]
FY2025E EBITDA          $X.XB       $X.XB       +X.X%      [简要原因]
FY2025E EPS             $X.XX       $X.XX       +X.X%      [简要原因]
```

### 步骤 10：更新估值与目标价

基于更新后的预测：
- 重新计算 DCF（使用更新后现金流）
- 更新可比公司倍数（如果 peer group 已披露）
- 确定新的公允价值
- 判断目标价是否变化

**目标价决策：**
- 如果预测变化显著（>5%）→ 通常调整目标价
- 如果预测变化较小（<5%）→ 可以维持目标价
- 如果投资论点增强/弱化 → 即使预测变化不大，也可能调整目标价

### 步骤 11：评估评级影响

决定是否调整评级：
- 如果结果显著好于预期且指引上调 → 考虑上调评级
- 如果结果显著差于预期且指引下调 → 考虑下调评级
- 如果大致符合或表现分化 → 通常维持评级

**考虑因素：**
- 股价反应（上涨/下跌/持平？）
- 估值（相对更新后预测是贵还是便宜？）
- 风险收益（不对称性是否变化？）

## 阶段 3：图表生成（1–2 小时）

### 步骤 12：生成 8–12 张图表

创建图表时重点关注**季度趋势**和**新增变化**。

**必需图表（共 8–12 张）：**

1. **季度收入变化**（柱状图）
   - 最近 8–12 个季度
   - 展示每季度相对预测的超预期/低于预期
   - 突出当前季度

2. **季度 EPS 变化**（柱状图）
   - 最近 8–12 个季度
   - 展示相对预测的超预期/低于预期
   - 包含 Adjusted 和 GAAP

3. **季度利润率趋势**（折线图）
   - 毛利率、EBIT 利润率、净利率
   - 最近 8–12 个季度
   - 展示轨迹

4. **按分部/地域拆分收入**（堆叠柱状图或表格）
   - 当前季度与去年同期
   - 按分部列示增长率

5. **核心经营指标**（多折线图）
   - 客户数量、ARPU、销量等（选择与公司相关的指标）
   - 最近 8–12 个季度

6. **超预期/低于预期汇总**（瀑布图或表格）
   - 展示超预期/低于预期构成
   - 说明相对预测的差异来源

7. **预测修订图**（修订前/修订后对比）
   - 旧 FY 预测与新 FY 预测
   - 用柱状图展示变化

8. **估值图**（P/E 或 EV/EBITDA 倍数）
   - 历史倍数区间
   - 当前倍数
   - 公允价值倍数

**可选图表（如篇幅允许）：**
- 同业对比（如果同业已披露）
- 指引与市场预期对比
- 现金流指标
- 资产负债表亮点（如值得关注）

**图表风格指南：**
- 关注趋势（季度变化）
- 突出变化（超预期/低于预期、预测修订）
- 保持简单清晰（这是快速周转报告）

## 阶段 4：报告创建（2–3 小时）
