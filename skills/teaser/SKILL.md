# Teaser

## 工作流

### 第 1 步：收集输入

- 公司描述（做什么、如何赚钱）
- 板块 / 行业
- 关键财务指标：收入、EBITDA、增长率、利润率
- 地域布局
- 核心卖点（3-5 个亮点）
- 哪些内容匿名化，哪些内容可披露
- 目标买方受众（战略买方、财务买方或两者）

### 第 2 步：Teaser 结构

一页，专业排版：

**页眉**
- 交易代码名（例如 “Project [Name]”）
- 行业描述（例如“领先的专业工业服务平台”）
- “保密 — 仅供讨论”

**公司描述**（2-3 句）
- 不披露名称的情况下说明公司做什么
- 市场地位（例如“领先的……提供商”、“……领域前三参与者”）
- 地域（区域层级，不写具体城市）

**投资亮点**（4-6 条）
- 市场领导地位 / 定位
- 收入质量（经常性收入占比、留存、分散度）
- 增长特征和路径
- 利润率结构和扩张机会
- 管理团队实力
- 战略价值 / 协同潜力

**财务摘要**（表格或关键指标）

| 指标 | 数值 |
|------|------|
| 收入 | $XXM |
| 收入增长 | XX% CAGR |
| EBITDA | $XXM |
| EBITDA 利润率 | XX% |
| 员工数 | XXX |

**交易概览**（2-3 句）
- 出售内容（100% 出售、控股权、成长股权）
- 初步时间表
- 表达兴趣的联系方式

### 第 3 步：匿名化检查

确保 teaser 不会意外暴露公司身份：
- 不出现公司名称、品牌名称或产品名称
- 不写具体城市（使用区域，例如“美国东南部”、“中西部”）
- 不写具名客户或合作伙伴
- 如果员工数太有辨识度，则不披露
- 如果行业较小，使用收入区间而非精确数字
- 不使用 logo、截图或可识别图片

### 第 4 步：输出

- Word 文档（.docx）：一页、清晰排版
- 用于分发的 PDF 版本
- 可选 PowerPoint 版本（单页幻灯片）

## 重要说明

- Teaser 的作用是激发兴趣，而不是完成交易；保持紧凑、有吸引力
- 少即是多；好的 teaser 会让买方愿意签 NDA 了解更多
- 语言可以有愿景但必须准确；如果属实，可以使用“领先”、“差异化”、“高增长”等表述
- 提供足够财务细节以筛选认真买方，但不要多到让无效买方浪费时间
- 分发前始终由客户和法律顾问审阅
- 跟踪 teaser 接收方；这会成为流程外联日志
