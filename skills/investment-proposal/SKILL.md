# 投资建议书

## 工作流

### 第 1 步：潜在客户背景

收集：
- **潜在客户姓名** 和家庭情况
- **当前情况**：是否已有顾问？是否自主管理？是什么触发了本次会面？
- **资产**：估计 AUM、账户类型、当前持仓（如已分享）
- **目标**：退休、财富保全、增长、收入、教育、传承
- **风险承受能力**：保守、稳健、进取（或问卷评分）
- **约束**：ESG 偏好、集中持股、流动性需求
- **费用敏感度**：当前支付多少费用？
- **竞争情况**：他们还在考虑哪些机构？

### 第 2 步：建议书结构

**I. 关于本机构**（1 页）
- 机构概览、历史、AUM
- 投资理念（用清楚易懂的语言）
- 团队简介（与该客户相关）
- 客户服务模式（会面频率、联系人）

**II. 理解您的需求**（1 页）
- 复述客户目标和顾虑，体现已认真倾听
- 在 discovery 中识别出的关键规划事项
- 对客户而言“成功”是什么样

**III. 建议投资策略**（2-3 页）
- 推荐资产配置及理由
- 配置如何对应客户目标和风险承受能力
- 投资工具（ETF、公募基金、单只证券、另类资产）
- 税务敏感策略（asset location、tax-loss harvesting）

建议配置：

| 资产类别 | 配置 | 工具 | 理由 |
|----------|------|------|------|
| | | | |

**IV. 预期结果**（1-2 页）
- 预测增长情景（保守、稳健、乐观）
- 达成目标的 Monte Carlo 概率
- 收入预测（如退休或收入导向）
- 风险指标（最大回撤、波动率）
- 与当前组合对比（如已知）

**V. 费率结构**（1 页）
- 顾问费率表（如适用分层费率）
- 底层基金费用
- 总 all-in 成本估计
- 费用相对行业平均的比较
- 价值主张：客户为该费用获得什么

**VI. 开始使用**（1 页）
- 开户流程
- 资产转入时间表
- 迁移计划（如从其他顾问转入）
- 前 90 天预期事项
- 所需文件和下一步

### 第 3 步：定制化

- 根据潜在客户匹配语气（企业高管 vs. 小企业主 vs. 退休人士）
- 如果客户有集中持股，直接回应该问题
- 如果客户在比较 robo-advisor，强调规划和关系价值
- 如果客户对价格敏感，优先讲总价值和结果，不只讲费用

### 第 4 步：输出

- 带机构品牌的 PowerPoint 演示（12-15 页）
- 可留存 PDF 版本
- 用于跟进邮件的一页式摘要

## 重要说明

- 建议书应体现个性化，而不是模板化；必须引用客户具体情况
- 不要过度销售业绩；设定现实预期并强调流程
- 始终包含免责声明（预测为假设、过往表现不代表未来等）
- 迁移计划很重要；客户担心更换顾问造成扰动
- 48 小时内发送建议书并给出明确下一步
- 面向潜在客户展示前必须经过合规审阅
