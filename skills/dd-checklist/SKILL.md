## 中文版执行契约

- 默认使用中国大陆金融语境：A股优先，港股和美股兼容；如用户指定市场、币种、会计准则或模板，以用户输入为准。
- 数据来源必须遵守根目录 `DATA_SOURCES_CN.md`：官方披露、用户文件、已授权 MCP/数据库优先；免费源只作辅助；监管、会计、KYC、基金文件和月结判断无依据时写“需确认”。
- 所有产物必须遵守根目录 `CN_OUTPUT_FORMATTING.md`：中文字体栈、中文日期、币种/单位、图表标题、表格表头、来源脚注、风险提示和免责声明都要按中文机构材料处理。
- 用户模板和品牌规范优先，但不得突破中文可读性、来源脚注、币种/单位/日期/口径说明这些底线。
- 保留 DCF、LBO、WACC、EV/EBITDA、IRR、MOIC、NAV、KYC、AML、MCP、CLI 等专业缩写和代码标识。


# 尽职调查清单

## 工作流

### 步骤 1：界定尽调范围

向用户询问：
- **目标公司**：名称、行业、商业模式
- **交易类型**：平台型收购、add-on、成长型股权投资、recap、carve-out
- **交易规模 / 复杂度**：决定尽调深度
- **核心顾虑**：需要优先关注的已知问题（客户集中度、监管、环境等）
- **时间线**：LOI / 交割目标时间

### 步骤 2：生成工作流清单

围绕所有主要工作流生成清单，并按行业定制：

**财务尽职调查**
- 盈利质量（QoE）：收入和 EBITDA 调整
- 营运资本分析：正常化 vs. 实际
- 债务及类债务项目
- 资本开支：维护性 vs. 增长性
- 税务结构和风险敞口
- 审计历史和会计政策
- Pro forma 调整：run-rate、协同效应

**商业尽职调查**
- 市场规模和增长（TAM/SAM/SOM）
- 竞争定位和市场份额
- 客户分析：集中度、留存、NPS
- 定价能力和合同结构
- 销售 pipeline 和 backlog
- Go-to-market 效率

**法律尽职调查**
- 公司结构和组织架构图
- 重大合同（客户、供应商、合作伙伴）
- 诉讼历史和未决索赔
- IP 组合和保护
- 监管合规
- 雇佣协议和竞业限制

**运营尽职调查**
- 管理团队评估
- 组织结构和关键人风险
- IT 系统和基础设施
- 供应链和供应商依赖
- 设施和不动产
- 保险覆盖

**HR / 人员尽职调查**
- 组织架构和员工人数趋势
- 薪酬基准比较
- 福利和养老金义务
- 关键员工留任风险
- 文化评估
- 工会/劳动协议

**IT / 技术尽职调查**（适用于技术驱动业务）
- 技术栈和架构
- 技术债评估
- 网络安全状态
- 数据隐私合规（GDPR、CCPA、SOC2）
- 产品路线图和 R&D 投入
- 可扩展性评估

**环境 / ESG**（如适用）
- 环境负债
- 监管合规历史
- ESG 风险与机会

### 步骤 3：状态跟踪

对每个事项跟踪：

| 事项 | 工作流 | 优先级 | 状态 | 负责人 | 备注 |
|------|--------|--------|------|--------|------|
| QoE 报告 | 财务 | P0 | 待处理 | | |
| 客户访谈 | 商业 | P0 | 进行中 | | 10 个中已完成 3 个 |

状态选项：未开始 → 已请求 → 已收到 → 审阅中 → 已完成 → 红旗

### 步骤 4：红旗摘要

维护尽调过程中发现的红旗清单：
- 发现了什么
- 属于哪个工作流
- 严重程度（deal-breaker / significant / manageable）
- 缓释因素或解决路径
- 对估值或交易条款的影响

### 步骤 5：输出

- Excel 工作簿，按工作流设置标签页（默认）
- 摘要 dashboard：各工作流完成百分比、未完成事项、红旗
- 面向 deal team 的周度状态更新格式

## 行业特定补充项

根据行业自动添加相关事项：
- **软件/SaaS**：ARR 质量、cohort analysis、托管成本、SOC2
- **医疗健康**：监管批准、报销风险、payor mix
- **工业**：设备状态、环境修复、安全记录
- **金融服务**：监管资本、合规历史、信贷质量
- **消费**：品牌健康度、渠道组合、季节性、库存管理

## 重要说明

- 优先处理影响 LOI 或交割的 P0 事项。
- 对卖方响应缓慢的事项做标记，这可能暗示潜在问题。
- 将数据室内容与清单交叉核对，识别缺口。
- 随着尽调推进持续更新清单；它是一份动态文档。
