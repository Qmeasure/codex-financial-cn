# 晨会纪要

## 工作流

### 第 1 步：隔夜进展

扫描覆盖范围内的相关事件：

**业绩与指引**
- 是否有覆盖公司在隔夜或盘前发布业绩？
- 业绩 surprise（收入、EPS、关键指标超预期/低于预期）
- 指引变化（上调、下调、维持）

**新闻与事件**
- M&A 公告或传闻
- 管理层变动
- 产品发布或监管决定
- 竞争机构分析师上调/下调评级
- 影响板块的宏观数据或政策变化

**市场背景**
- 隔夜期货 / 盘前走势
- 板块 ETF 表现
- 相关大宗商品或货币变动
- 今日关键经济数据发布

### 第 2 步：晨会纪要格式

保持紧凑，晨会纪要应能在 2 分钟内读完：

---

**[日期] 晨会纪要 — [分析师姓名]**
**[覆盖板块]**

**Top Call：[标题 — PM 最需要听到的一件事]**
- 用 2-3 句说明关键进展及其重要性
- 股票影响：目标价、评级维持/调整

**隔夜/盘前进展**
- [公司 A]：一句话总结业绩/新闻 + 我们的观点
- [公司 B]：一句话总结 + 我们的观点
- [板块/宏观]：相关板块级进展

**今日关键事件**
- [时间]：[公司] 业绩会
- [时间]：经济数据发布（预期 vs. 我们观点）
- [时间]：会议或投资者日

**交易想法**（如有）
- [多头/空头] [公司]：1-2 句论点 + 催化剂
- 风险：什么会让该判断出错

---

### 第 3 步：业绩快速观点

如果覆盖公司已发布业绩，提供快速反应：

| 指标 | 一致预期 | 实际 | 超预期/低于预期 |
|------|----------|------|----------------|
| 收入 | | | |
| EPS | | | |
| [关键指标] | | | |
| 指引 | | | |

**我们的观点**：2-3 句说明这对股票是利好还是利空，是否改变我们的论点。

**行动**：维持 / 上调 / 下调评级？是否调整目标价？

### 第 4 步：输出

- 用于邮件/Slack 分发的 Markdown 文本
- 如需正式分发，输出 Word 文档
- 最多 1 页；PM 和交易员不会读更长内容

## 重要说明

- 要有观点：只总结新闻而没有观点的晨会纪要没有价值
- 把最重要的内容放在开头，不要埋没标题
- “没有新闻”也是有效晨会纪要：写明“隔夜无重大事项，维持当前配置/观点”
- 区分可行动事件（业绩、M&A）和噪音（小型分析师笔记、非事件）
- 为观点标注时间戳；如果 6 点写成，注明盘前走势到开盘前可能变化
- 如果判断出错，在下一份晨会纪要中承认；可信度比每次都正确更重要
