# 清理数据

清理当前工作表或指定区域中的混乱数据。

## 环境

- **如果在 Excel 内运行（Office 加载项 / Office JS）：** 直接使用 Office JS（`Excel.run(async (context) => {...})`）。通过 `range.values` 读取，通过 `range.formulas = [["=TRIM(A2)"]]` 写入辅助列公式。是否原地覆盖或使用辅助列的决策仍然适用。
- **如果处理独立 .xlsx 文件：** 使用 Python/openpyxl。

## 工作流

### 第 1 步：范围

- 如果提供了区域（例如 `A1:F200`），使用该区域
- 否则使用当前工作表的完整已使用区域
- 为每列画像：检测主导类型（文本 / 数字 / 日期）并识别异常值

### 第 2 步：检测问题

| 问题 | 检查内容 |
|---|---|
| 空格 | 前后空格、双空格 |
| 大小写 | 分类列中大小写不一致（`usa` / `USA` / `Usa`） |
| 文本数字 | 数值以文本存储；数字单元格中混有 `$`、`,`、`%` |
| 日期 | 同一列中混合格式（`3/8/26`、`2026-03-08`、`March 8 2026`） |
| 重复项 | 完全重复行和近似重复行（大小写/空格差异） |
| 空白 | 本应填充列中的空单元格 |
| 混合类型 | 某列 98% 为数字但有 3 个文本项 |
| 编码 | mojibake（`Ã©`、`â€™`）、不可打印字符 |
| 错误 | `#REF!`、`#N/A`、`#VALUE!`、`#DIV/0!` |

### 第 3 步：提出修复

修改任何内容前，先展示摘要表：

| 列 | 问题 | 数量 | 建议修复 |
|---|---|---|---|

### 第 4 步：应用

- **优先使用公式，而不是硬编码清理后数值**：如果清理结果可以用公式表达（例如 `=TRIM(A2)`、`=VALUE(SUBSTITUTE(B2,"$",""))`、`=UPPER(C2)`、`=DATEVALUE(D2)`），应在相邻辅助列写入公式，而不是用 Python 计算结果并覆盖原值。这能保持转换透明且可审计。
- 只有在用户明确要求，或没有合理公式等价方式时（例如编码/mojibake 修复），才用计算值原地覆盖
- 对破坏性操作（删除重复项、填充空白、覆盖原始值），先向用户确认
- 每类修复后（空格 → 大小写 → 数字转换 → 日期 → 去重），向用户展示变更样例并确认，再进入下一类
- 报告变更前后摘要
