# 可比公司分析

## ⚠️ 关键：数据来源优先级（请先阅读）

**始终遵循以下数据来源层级：**

1. **首先：检查 MCP 数据源** - 如果 S&P Kensho MCP、FactSet MCP 或 Daloopa MCP 可用，则财务和交易信息只使用这些来源。
2. **如果上述 MCP 数据源可用，不要使用网页搜索**。
3. **只有在 MCP 不可用时：** 再使用 Bloomberg Terminal、SEC EDGAR 披露文件或其他机构级来源。
4. **绝不要把网页搜索作为主要数据来源** - 它缺乏机构级分析所需的准确性、审计轨迹和可靠性。

**为什么重要：** MCP 来源提供经过验证的机构级数据，并带有适当引用。网页搜索结果可能过时、不准确，或不适合金融分析。

## 概览
本技能教 Codex 构建机构级可比公司分析，把经营指标、估值倍数和统计基准比较结合起来。输出是结构化 Excel/电子表格，可通过同业比较支持知情投资决策。

**参考材料与语境化：**

`examples/可比公司_example.xlsx` 提供了一个可比公司分析示例。使用本技能目录下的该示例或其他示例文件时，应智能使用：

**可以用示例来：**
- 理解结构层级（章节如何流转）。
- 把握预期严谨度（统计深度、文档标准）。
- 学习原则（清晰表头、透明公式、审计轨迹）。

**不要用示例来：**
- 精确复刻格式或指标。
- 不考虑语境地照搬布局。
- 不管受众是谁都套用相同视觉风格。

**始终先问自己：**
1. **“你有偏好的格式，还是我应当调整模板风格？”**
2. **“受众是谁？”**（投资委员会、董事会汇报、快速参考、详细备忘录）
3. **“核心问题是什么？”**（估值、增长分析、竞争定位、效率）
4. **“使用场景是什么？”**（M&A 评估、投资决策、行业基准比较、业绩审阅）

**根据具体情况调整：**
- **行业背景**：大型科技巨头需要的指标不同于新兴 SaaS 初创公司。
- **行业特定需求**：提前加入相关指标（例如科技公司可加入云 ARR、企业客户、开发者生态）。
- **公司熟悉度**：知名公司可能需要更少背景介绍，更侧重变化分析。
- **决策类型**：M&A 的重点不同于持续组合监控。

**核心原则：** 使用模板原则（清晰结构、统计严谨、公式透明），但根据语境改变执行方式。目标是机构级分析，而不是看起来像机构模板。

用户提供的示例和明确偏好始终优先于默认值。

## 核心原则
**“先搭好正确结构，再让数据讲故事。”**

从能迫使战略思考的表头开始，输入干净数据，构建透明公式，并让统计结果自动呈现。好的 comp 应当能让没有参与构建的人也立即读懂。

## ⚠️ 关键：公式优先于硬编码 + 逐步核验

**环境 — Office JS 与 Python：**
- **如果在 Excel 内运行（Office 加载项 / Office JS）：** 直接使用 Office JS（`Excel.run(async (context) => {...})`）。通过 `range.formulas = [["=E7/C7"]]` 写入公式，而不是 `range.values`。不需要单独重算步骤，Excel 会原生处理。用 `range.format.*` 设置颜色/字体。
- **如果生成独立 .xlsx 文件：** 使用 Python/openpyxl。写入 `cell.value = "=E7/C7"`（公式字符串）。
- 两种环境原则相同，只是 API 调用需要转换。
- **Office JS 合并单元格陷阱：** 不要先调用 `.merge()` 再在合并区域上设置 `.values`（会抛出 `InvalidArgument`，因为区域仍报告合并前维度）。正确做法是先把值写到左上角单元格，再合并并设置整个区域格式：
  ```js
  ws.getRange("A1").values = [["科技行业 — 可比公司分析"]];
  const hdr = ws.getRange("A1:H1");
  hdr.merge();
  hdr.format.fill.color = "#1F4E79";
  hdr.format.font.color = "#FFFFFF";
  hdr.format.font.bold = true;
  ```

**使用公式，不使用硬编码：**
- 每个派生值（利润率、倍数、统计值）都必须是引用输入单元格的 Excel 公式，绝不要粘贴预先计算好的数字。
- 使用 Python/openpyxl 构建工作表时：写 `cell.value = "=E7/C7"`（公式字符串），不要写 `cell.value = 0.687`（计算结果）。
- 唯一应硬编码的值是原始输入数据（收入、EBITDA、股价等），且每一个都要带有说明来源的单元格批注。
- 原因：输入变化时模型必须自动更新。硬编码利润率是一个隐性 bug。

**与用户逐步核验：**
- 搭好结构后 → 在填充数据前向用户展示表头布局。
- 输入原始数据后 → 展示输入模块，确认来源/期间后再构建公式。
- 构建经营指标公式后 → 展示计算出的利润率，与用户做合理性检查后再进入估值。
- 构建估值倍数后 → 展示倍数，确认看起来合理后再加入统计。
- 不要端到端构完整张表后才展示；通过逐节确认尽早捕捉错误。

## 章节 1：文档结构与设置

### 标题区块（第 1-3 行）
```
第 1 行：[分析标题] - 可比公司分析
第 2 行：[公司与股票代码列表] • [公司 1（代码 1）] • [公司 2（代码 2）] • [公司 3（代码 3）]
第 3 行：截至[期间] | 除每股金额和比率外，所有数字单位为[百万美元/十亿美元]
```

**为什么重要：** 它会立即建立语境。任何打开文件的人都能知道自己在看什么、何时创建，以及如何解读数字。

### 视觉约定标准（可选 - 用户偏好和上传模板始终优先）

**重要：这些只是建议默认值。始终优先：**
1. 用户明确的格式偏好。
2. 用户上传模板文件中的格式。
3. 公司/团队风格指南。
4. 这些默认值（仅在没有其他指引时）。

**建议字体与排版：**
- **字体族**：微软雅黑/苹方/思源黑体（中文材料默认，若模板另有要求则遵循模板）。
- **字号**：数据单元格 11pt，标题 12pt。
- **加粗文字**：章节标题、公司名称、统计标签。

**默认颜色与底色 — 专业蓝/灰色板（越克制越好）：**
- **保持克制**：只使用蓝色和灰色。不要引入绿色、橙色、红色或多个强调色。一张干净的可比公司表总共使用 3-4 种颜色即可。
- **章节标题**（例如“经营统计与财务指标”）：
  - 深蓝背景（`#1F4E79` 或 `#17365D` 海军蓝）。
  - 白色加粗文字。
  - 整行跨所有列填充底色。
- **列表头**（例如“公司”、“收入”、“利润率”）：
  - 浅蓝背景（`#D9E1F2` 或类似浅蓝）。
  - 黑色加粗文字。
  - 居中对齐。
- **数据行**：
  - 公司数据白底。
  - 公式用黑色文字；硬编码输入用蓝色文字。
- **统计行**（最大值、第 75 百分位等）：
  - 浅灰背景（`#F2F2F2`）。
  - 黑色文字，标签左对齐。
- **完整色板就是这些**：深蓝 + 浅蓝 + 浅灰 + 白色。除非用户模板另有要求，不要添加其他颜色。

**建议格式约定：**
- **小数精度**：
  - 百分比：1 位小数（12.3%）。
  - 倍数：1 位小数（13.5x）。
  - 金额：不保留小数，使用千分位分隔符（69,632）。
  - 利润率以百分比展示：1 位小数（68.7%）。
- **边框**：无边框（干净、极简外观）。
- **对齐**：所有指标居中对齐，保持整洁统一。
- **单元格尺寸**：所有列宽应统一/均匀，所有行高应一致（形成干净、专业的网格）。

**说明：** 如果用户提供模板文件或指定不同格式，就使用用户提供的格式。

## 章节 2：经营统计与财务指标

### 核心列（从这些开始）
1. **公司** - 公司名称格式保持一致。
2. **收入** - 规模指标（可根据语境使用 LTM、季度或年度口径）。
3. **收入增长** - 同比百分比变化。
4. **毛利** - 收入减去销售成本。
5. **毛利率** - GP/收入（基础盈利能力）。
6. **EBITDA** - 息税折旧摊销前利润。
7. **EBITDA 利润率** - EBITDA/收入（经营效率）。

### 可选补充项（按行业/目的选择）
- **季度与 LTM** - 如果季节性重要，则两者都纳入。
- **自由现金流** - 适用于资本密集型或 SaaS 业务。
- **FCF 利润率** - FCF/收入（现金生成效率）。
- **净利润** - 适用于成熟盈利公司。
- **经营利润** - 适用于 D&A 差异较大的业务。
- **CapEx 指标** - 适用于重资产行业。
- **Rule of 40** - 专用于 SaaS（增长率 % + 利润率 %）。
- **FCF 转化率** - 用于盈利质量分析（进阶）。

### 公式示例（以第 7 行为例）
```excel
// 核心比率 - 始终计算
毛利率 (F7): =E7/C7
EBITDA 利润率 (H7): =G7/C7

// 可选比率 - 相关时纳入
FCF 利润率: =[FCF]/[收入]
净利率: =[净利润]/[收入]
Rule of 40: =[增长率 %]+[FCF 利润率 %]
```

**黄金规则：** 每个比率都应是 [某项] / [收入]，或 [某项] / [本表中的某项]。保持简单。

### 统计区块（公司数据之后）

**关键：为所有可比指标（比率、利润率、增长率、倍数）添加统计公式。**

```
[留一行空白用于视觉分隔]
- 最大值: =MAX(B7:B9)
- 第 75 百分位: =QUARTILE(B7:B9,3)
- 中位数: =MEDIAN(B7:B9)
- 第 25 百分位: =QUARTILE(B7:B9,1)
- 最小值: =MIN(B7:B9)
```

**需要统计的列（可比指标）：**
- 收入增长 %、毛利率 %、EBITDA 利润率 %、EPS。
- EV/收入、EV/EBITDA、P/E、股息率 %、Beta。

**不需要统计的列（规模指标）：**
- 收入、EBITDA、净利润（绝对规模随公司体量差异很大）。
- 市值、企业价值（不同规模公司之间不可直接比较）。

**说明：** 在公司数据与统计行之间添加一行空白用于视觉分隔。不要添加“板块统计”或“估值统计”标题行。

**为什么四分位数重要：** 它展示分布，而不只是平均数。75 分位数倍数能说明“溢价”公司通常在哪个区间交易。

## 章节 3：估值倍数与投资指标

### 核心估值列（从这些开始）
1. **公司** - 与经营章节保持相同顺序。
2. **市值** - 当前市场估值。
3. **企业价值** - 市值 ± 净债务/现金。
4. **EV/收入** - 市场愿意为每一元销售收入支付多少。
5. **EV/EBITDA** - 市场愿意为每一元盈利支付多少。
6. **P/E 比率** - 股价相对于净利润的倍数。

### 可选估值指标（按语境选择）
- **FCF 收益率** - FCF/市值（适用于关注现金流的分析）。
- **PEG 比率** - P/E/增长率（适用于成长型公司）。
- **市净率** - 市场价值相对于账面价值（适用于重资产业务）。
- **ROE/ROA** - 回报指标（用于盈利能力比较）。
- **收入/EBITDA CAGR** - 历史增长率（用于趋势分析）。
- **资产周转率** - 收入/资产（用于运营效率）。
- **债务/权益** - 杠杆（用于资本结构分析）。

**关键原则：** 纳入对所在行业真正重要的 3-5 个核心倍数。不要因为能算就把所有可能指标都放进去。

### 公式示例
```excel
// 核心倍数 - 始终纳入
EV/收入: =[企业价值]/[LTM 收入]
EV/EBITDA：=[企业价值]/[LTM EBITDA]
P/E 比率：=[市值]/[净利润]

// 可选倍数 - 数据可用时纳入
FCF 收益率：=[LTM FCF]/[市值]
PEG 比率：=[P/E]/[增长率 %]
```

### 交叉引用规则
**关键：** 估值倍数必须引用经营指标章节。绝不要重复输入同一份原始数据。如果收入在 C7，则 EV/收入 公式应引用 C7。

### 统计区块
与经营章节结构相同：对每个指标计算最大值、第 75 百分位、中位数、第 25 百分位、最小值。在公司数据与统计行之间添加一行空白用于视觉分隔。不要添加“估值统计”标题行。

## 章节 4：说明与方法论文档

### 必需组成部分

**数据来源与质量：**
- 数据来自哪里？（S&P Kensho MCP、FactSet MCP、Daloopa MCP、Bloomberg、SEC 披露文件）
- 覆盖哪个期间？（Q4 2024、经审计数字）
- 如何验证？（与 10-K/10-Q 交叉核对）
- 说明：如可用，优先使用 MCP 数据源（S&P Kensho、FactSet、Daloopa），以获得更好的准确性和可追溯性。

**关键定义：**
- EBITDA 计算方法（毛利 + D&A，或经营利润 + D&A）。
- 自由现金流公式（经营现金流 - CapEx）。
- 特殊指标解释（Rule of 40、FCF 转化率）。
- 时间期间定义（LTM、CAGR 计算期间）。

**估值方法论：**
- 企业价值如何计算？（市值 + 净债务）
- 使用了哪些增长率？（历史 CAGR、前瞻估计）
- 是否进行了调整？（剔除一次性项目、标准化利润率）

**分析框架：**
- 投资逻辑是什么？（云/SaaS 效率）
- 哪些指标最重要？（现金生成、资本效率）
- 读者应如何解读统计结果？（四分位数提供语境）

## 章节 5：选择正确指标（决策框架）

### 从“我要回答什么问题？”开始

**“哪家公司被低估？”**
→ 关注：EV/收入、EV/EBITDA、P/E、市值。  
→ 跳过：运营细节、增长指标。

**“哪家公司效率最高？”**
→ 关注：毛利率、EBITDA 利润率、FCF 利润率、资产周转率。  
→ 跳过：规模指标、绝对金额。

**“哪家公司增长最快？”**
→ 关注：收入增长 %、EBITDA CAGR、用户/客户增长。  
→ 跳过：利润率指标、杠杆比率。

**“哪家公司现金生成能力最好？”**
→ 关注：FCF、FCF 利润率、FCF 转化率、CapEx 强度。  
→ 跳过：EBITDA、P/E 比率。

### 行业特定指标选择

**软件/SaaS：**
必备：收入增长、毛利率、Rule of 40。  
可选：ARR、净美元留存率、CAC 回收期。  
跳过：资产周转率、库存指标。

**制造业/工业：**
必备：EBITDA 利润率、资产周转率、CapEx/收入。  
可选：ROA、存货周转率、积压订单。  
跳过：Rule of 40、SaaS 指标。

**金融服务：**
必备：ROE、ROA、效率比率、P/E。  
可选：净息差、贷款损失准备。  
跳过：毛利率、EBITDA（对银行没有意义）。

**零售/电商：**
必备：收入增长、毛利率、存货周转率。  
可选：同店销售额、获客成本。  
跳过：重 R&D 或重 CapEx 指标。

### “5-10 规则”

**5 个经营指标** - 收入、增长、2-3 个利润率/效率指标。  
**5 个估值指标** - 市值、EV、3 个倍数。  
**= 总共 10 列** - 足以讲清故事，又不会多到失去主线。

如果超过 15 个指标，你很可能纳入了噪音。要果断删减。

## 章节 6：最佳实践与质量检查

### 开始前
1. **定义同业组** - 公司必须真正可比（相似商业模式、规模、地域）。
2. **选择正确期间** - LTM 可平滑季节性；季度数据可展示趋势。
3. **提前统一单位** - 百万还是十亿的选择会影响所有内容。
4. **映射数据来源** - 明确每个数字来自哪里。

### 构建时
1. **先输入所有原始数据** - 写公式前完成蓝色文字输入。
2. **为所有硬编码输入添加单元格批注** - 右键单元格 → Insert Comment → 记录来源或假设。

   **对于有来源的数据，准确引用其出处：**
   - 示例："Bloomberg Terminal - MSFT Equity DES, accessed 2024-10-02"
   - 示例："Q4 2024 10-K filing, page 42, line item 'Total 收入'"
   - 示例：“FactSet 一致预期，截至 2024-10-02”
   - **尽可能包含超链接**：右键单元格 → Link → 粘贴 SEC 披露文件、数据来源或报告 URL。

   **对于假设，解释推理：**
   - 示例："基于同业中位数假设 15% EBITDA 利润率；公司未披露该指标"
   - 示例："企业价值估算为市值 + 5,000 万美元净债务（来自 Q3 资产负债表；Q4 尚不可得）"
   - 示例："远期 P/E 基于市场一致预期 EPS 3.45 美元（12 名分析师预测均值）"

   **为什么重要**：支持审计轨迹、数据验证、假设透明和未来更新。
3. **逐行构建公式** - 每个计算测试通过后再继续。
4. **对表头使用绝对引用** - $C$6 锁定表头行。
5. **保持格式一致** - 百分比要格式化为百分比，而不是小数。
6. **添加条件格式** - 自动高亮离群点。

### 合理性检查
- **利润率测试**：毛利率 > EBITDA 利润率 > 净利率（按定义始终应成立）。
- **倍数合理性**：
  - EV/收入：通常 0.5-20x（按行业差异很大）。
  - EV/EBITDA：通常 8-25x（跨行业相对一致）。
  - P/E：通常 10-50x（取决于增长率）。
- **增长与倍数相关性**：更高增长通常对应更高倍数。
- **规模与效率权衡**：更大公司通常利润率更高（规模效益）。

### 应避免的常见错误
❌ 在公式中混用市值和企业价值。  
❌ 分子和分母使用不同时间期间（LTM vs 季度）。  
❌ 在公式中硬编码数字，而不是引用单元格。  
❌ **硬编码输入没有单元格批注说明来源或解释假设。**  
❌ 在可用时没有添加 SEC 披露文件或数据来源超链接。  
❌ 纳入过多没有明确目的的指标。  
❌ 纳入不可比公司（不同商业模式）。  
❌ 使用过时数据且未披露。  
❌ 错误计算百分比平均值（通常应使用中位数）。

## 章节 7：工作流与实用技巧

### 逐步流程
1. **设置结构**（30 分钟）
   - 创建所有表头。
   - 设置单元格格式（蓝色为输入，黑色为公式）。
   - 锁定单位和日期引用。

2. **收集数据**（60-90 分钟）
   - 从主要来源拉取数据（如可用，使用 S&P Kensho MCP、FactSet MCP、Daloopa MCP；否则使用 Bloomberg、SEC）。
   - 将所有原始数字以蓝色输入。
   - 在说明章节记录来源。

3. **构建公式**（30 分钟）
   - 从简单比率开始（利润率）。
   - 逐步推进到倍数（EV/收入）。
   - 添加交叉检查（利润率是否合理？）。

4. **添加统计**（15 分钟）
   - 为所有列复制公式结构。
   - 核验区间是否正确（B7:B9，而不是 B7:B10）。
   - 检查四分位数逻辑。

5. **质量控制**（30 分钟）
   - 运行合理性检查。
   - 核验公式引用。
   - 检查 #DIV/0! 或 #REF! 错误。
   - 与已知基准对比。

6. **文档记录**（15 分钟）
   - 完成说明章节。
   - 添加数据来源。
   - 定义方法论。
   - 给分析加日期戳。

### 专业技巧
- **保存模板**：构建一次，长期复用。
- **用颜色标记离群点**：对大于 2 个标准差的数值设置条件格式。
- **链接到来源文件**：超链接到 Bloomberg 截图或 SEC 披露文件。
- **版本控制**：保存为 "可比公司_v1_2024-12-15"，日期清楚。
- **协作审阅**：让其他人检查公式。

### Excel 格式检查清单（可选 - 按用户偏好调整）
- [ ] 字体设置为用户偏好样式（默认：中文字体栈，数据 11pt，标题 12pt）。
- [ ] 章节标题按用户模板格式设置（默认：深蓝 #17365D，白色加粗文字）。
- [ ] 列表头按用户模板格式设置（默认：浅蓝/灰 #D9E2F3，黑色加粗文字）。
- [ ] 统计行按用户模板格式设置（默认：浅灰 #F2F2F2）。
- [ ] 不应用边框（干净、极简外观）。
- [ ] **列宽设置为统一/均匀宽度**（形成干净、专业外观）。
- [ ] **行高设置一致**（数据行通常 20-25pt）。
- [ ] 数字使用正确小数精度和千分位分隔符。
- [ ] **所有指标居中对齐**，保持整洁统一。
- [ ] **公司数据与统计行之间有一行空白分隔**。
- [ ] **没有单独的“板块统计”或“估值统计”标题行**。

## 章节 10：危险信号与预警迹象

### 数据质量问题
🚩 时间期间不一致（混用季度和年度）  
🚩 缺少数据且没有解释  
🚩 数据来源之间存在显著差异（>10% 方差）

### 估值危险信号
🚩 EBITDA 为负的公司却使用 EBITDA 倍数估值（应改用收入倍数）  
🚩 P/E 比率 >100x 且没有超高增长故事支撑  
🚩 利润率与行业逻辑不符

### 可比性问题
🚩 财年结束日不同（会造成时间错配）  
🚩 混合纯业务公司和综合性集团  
🚩 将商业模式实质不同的公司标记为“可比公司”

**拿不准时，就剔除该公司。** 3 家完美可比公司胜过 6 家存疑公司。

## 章节 11：公式参考指南

### 基础 Excel 公式
```excel
// 统计函数
=AVERAGE(range)          // 简单均值
=MEDIAN(range)           // 中位值
=QUARTILE(range, 1)      // 25 分位数
=QUARTILE(range, 3)      // 75 分位数
=MAX(range)              // 最大值
=MIN(range)              // 最小值
=STDEV.P(range)          // 标准差

// 财务计算
=B7/C7                   // 简单比率（利润率）
=SUM(B7:B9)/3            // 多家公司平均值
=IF(B7>0, C7/B7, "N/A")  // 条件计算
=IF错误(C7/D7, 0)       // 处理除零

// 跨表引用
='Sheet1'!B7             // 引用另一个工作表
=VLOOKUP(A7, Table1, 2)  // 从数据表查找
=INDEX(MATCH())          // 高级查找

// 格式化
=TEXT(B7, "0.0%")        // 格式化为百分比
=TEXT(C7, "#,##0")       // 千分位分隔符
```

### 常见比率公式
```excel
毛利率 = 毛利 / 收入
EBITDA 利润率 = EBITDA / 收入
FCF 利润率 = 自由现金流 / 收入
FCF 转化率 = FCF / 经营现金流
ROE = 净利润 / 股东权益
ROA = 净利润 / 总资产
资产周转率 = 收入 / 总资产
债务/权益 = 总债务 / 股东权益
```

## 关键原则摘要

1. **结构驱动洞察** - 正确表头迫使正确思考。
2. **少即是多** - 5-10 个重要指标胜过 20 个无关指标。
3. **围绕问题选择指标** - 估值分析 ≠ 效率分析。
4. **统计结果揭示模式** - 中位数/四分位数比平均值提供更多信息。
5. **透明胜过复杂** - 使用人人能理解的简单公式。
6. **可比性最重要** - 宁可剔除，也不要强行纳入不合适的 comp。
7. **记录选择理由** - 在说明章节解释选择了哪些指标以及为什么。
