# 数据查询顺序合同

本文件是本 skill 的本地 reference。凡任务需要查询、刷新或补充外部数据，包括行情、财报、公告、行业、公司、宏观、监管、KYC、基金、月结和第三方数据库信息，必须先读取本文件，并先完成“数据源发现记录”。

## 网页搜索前 Gate

在任何网页搜索、公司官网抓取、SEC/交易所抓取、免费网页源整理前，先填写数据源发现记录：

- 用户文件：
- 当前会话可用 MCP / connector：
- 本地数据库 / 已授权数据源：
- 本任务适用数据源：
- 已调用或未调用原因：
- 覆盖缺口：
- 降级路径：

Gate 通过条件：

- 已列出可用/不可用的数据源，包括用户文件、MCP、connector、本地数据库和已授权数据源。
- 已说明哪些数据源适用于本任务，哪些不可用、未登录、未授权或覆盖不足。
- 已说明是否实际调用；未调用时必须写明原因，不能只写“已检查”。
- 已说明免费网页仅作辅助验证或官方披露补充，不得替代官方披露、用户文件或已授权数据源。
- 对一致预期、估值倍数、市场份额、行业数据和宏观数据等授权源缺口，只在数据源发现记录中列为未覆盖数据项，不在正式交付物中写固定标签。

Gate 未通过时，不得网页搜索，不得抓取公司官网、SEC 或交易所页面，也不得生成正式报告或文件交付物。

## 与更严格规则的关系

- 如果本 skill 明确限定只能使用特定 MCP、用户文件、官方披露或本地数据，则以更严格规则为准，不得退回网页搜索。
- 如果用户明确禁止 MCP、联网或某类数据源，必须在数据源发现记录中说明“用户覆盖默认数据源顺序”，并遵守用户限制。
- 如果 MCP 登录失败、工具不可用、当前会话没有暴露相关 MCP，最终输出必须说明降级原因和未覆盖数据项。

## 输出要求

- 最终产物必须列出主要数据来源、数据日期、币种单位、会计准则和口径限制。
- 正式报告或文件交付物必须包含“数据源发现记录摘要”，说明检查过哪些 MCP / connector / 授权数据源、哪些适用、哪些不可用或覆盖不足。
- 对网页搜索得到的信息必须二次核验；无法二次核验时不得作为正式结论，只在数据源发现记录中列为未覆盖数据项。
