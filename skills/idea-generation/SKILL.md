# 投资想法生成

## 工作流

### 第 1 步：定义搜索条件

向用户确认参数：
- **方向**：多头想法、空头想法，或两者兼有
- **市值**：大盘、中盘、小盘、微盘
- **行业**：特定行业或跨行业
- **风格**：价值、成长、质量、特殊情境、事件驱动
- **地域**：A股、港股、美股、国际或全球
- **主题**：任何特定主题角度（AI、供应链回流、人口老龄化等）

### 第 2 步：量化筛选

按风格运行筛选：

**价值筛选**
- P/E 低于行业中位数
- EV/EBITDA 低于历史平均
- 自由现金流收益率 >5%
- 市净率低于 1.5x
- 过去 90 天有内部人增持
- 股息率高于市场平均

**成长筛选**
- 收入同比增长 >15%
- 盈利同比增长 >20%
- 收入增长加速（增速提升）
- 利润率扩张
- 投入资本回报率较高（>15%）
- 净留存强劲（SaaS 公司 >110%）

**质量筛选**
- 收入持续增长（5 年以上）
- 利润率稳定或扩张
- ROE >15%
- 债务/权益比率较低
- 自由现金流转化率较高
- 内部人持股比例 >5%

**空头筛选**
- 收入下滑或增长减速
- 利润率压缩
- 应收账款/存货相对销售额上升
- 内部人减持
- 相对可比公司存在缺乏支撑的估值溢价
- 空头比例较高且基本面恶化
- 会计红旗（审计师变更、重述）

**特殊情境筛选**
- 近期 IPO / SPAC 且限售期即将到期
- 过去 12 个月内完成分拆
- 刚走出重组的公司
- 活跃投资人参与
- 经营不佳公司发生管理层变更

### 第 3 步：主题扫描

对于主题型想法，研究主题并识别受益方：

1. 定义投资论点（例如“AI 基础设施支出到 2026 年持续加速”）
2. 绘制价值链：谁直接受益，谁间接受益？
3. 区分纯标的和多元化敞口
4. 判断哪些标的已被“计入价格”，哪些仍被低估
5. 寻找市场尚未与主题充分关联的二阶受益方

### 第 4 步：想法呈现

对每个通过筛选的想法，呈现：

**[公司名称] — [多头/空头] — [一句话投资论点]**

| 指标 | 数值 | 相对同业 |
|------|------|----------|
| 市值 | | |
| EV/EBITDA 倍数（NTM） | | |
| P/E (NTM) | | |
| 收入增长 | | |
| EBITDA 利润率 | | |
| FCF 收益率 | | |

**投资论点（3-5 条）：**
- 为什么定价存在偏差
- 市场忽视了什么
- 价值实现催化剂

**关键风险：**
- 哪些情况会推翻该判断

**建议下一步：**
- 是否搭建完整模型？是否开展深度尽调？是否安排专家访谈？

### 第 5 步：输出

- 5-10 个想法的短名单，并附一页式摘要
- 记录筛选标准和方法
- 所有想法的对比表
- 优先级清单：先研究哪些想法

## 重要说明

- 筛选只能产生候选标的，不能直接得出结论；每个筛选结果都需要基本面研究
- 最好的想法常来自交叉区域（例如因短期逆风而以价值价格交易的高质量公司）
- 避免拥挤交易：检查持仓数据、空头比例以及分析师覆盖数量
- 逆向想法需要催化剂：没有催化剂的“早到”与“错误”没有区别
- 持续跟踪想法命中率：哪些筛选条件和研究路径能产出最佳想法？
- 空头想法需要更高确信度：择时更难，风险也不对称
