# 投资银行 / M&A 公司速览

## 目的

用于交易语境的公司画像，可服务于潜在标的、潜在收购方或推介材料。重点放在战略定位、分部细节、业务关系和 M&A 活动上。估值以交易倍数呈现，而不是围绕投资论点展开。

**默认页数：** 1–2 页。投行公司画像经常延展到第 2 页，尤其当分部和 M&A 数据丰富时。

## 查询计划

从以下查询开始。如结果不完整，拆分查询并继续追问。

**查询 1 — 画像 + 识别信息：**
`"[公司] 业务描述 总部 成立时间 员工数 板块 行业 所有权结构 主要股东"`
→ 页眉、业务概览
→ **立即写入** `/tmp/tear-sheet/company-profile.txt`

**查询 2 — 分部 + 财务：**
`"[公司] 按分部收入 业务单元 最近 2 个财年 AND 年度利润表 收入 毛利 EBITDA 经营利润 净利润 capex 自由现金流 总债务 现金及等价物 最近 4 个财年"`
→ 分部拆分（需要 2 年数据计算同比增长）、财务摘要（拉取 4 年；展示 3 年；最早一年仅用于计算同比增长）
→ **立即将原始财务数据写入** `/tmp/tear-sheet/financials.csv`
→ **立即将分部数据写入** `/tmp/tear-sheet/segments.csv`（如未返回分部数据则跳过）

**查询 3 — 估值 + 可比公司：**
如果用户提供了具体可比公司，逐个查询：
`"[可比公司] 企业价值 EV/收入 EV/EBITDA 收入增长 EBITDA 利润率"`
否则：
使用竞争对手工具识别 3–5 家上市同业，然后为每家拉取 EV/收入（NTM）、EV/EBITDA（NTM）、收入增长率 % 和 EBITDA 利润率 %。
另查：`"[公司] 企业价值 市值 EV/收入 EV/EBITDA 估值倍数"`
→ 页眉（EV/市值）、交易可比公司
→ **立即将公司倍数写入** `/tmp/tear-sheet/valuation.csv`
→ **立即将同业数据写入** `/tmp/tear-sheet/peer-comps.csv`

**查询 4 — M&A 活动：**
`"[公司] 收购 剥离 已完成交易 最近 5 年 交易价值"`
→ 公司自身交易
→ **立即写入** `/tmp/tear-sheet/ma-activity.csv`

**查询 5 — 可比交易（视数据可得性）：**
使用查询 1 结果中的具体行业（例如“云可观测性软件 M&A 交易”，不要只搜“科技 M&A”）。如果用户指定了可比公司，也尝试：`"[可比公司] 收购 交易倍数"`。
→ 可比交易
→ **追加**可比交易到 `/tmp/tear-sheet/ma-activity.csv`（增加 `type=precedent`，与公司自身交易区分）

**查询 6 — 业务关系 + 所有权：**
`"[公司] 关键客户 供应商 合作伙伴 业务关系 机构持股 内部人持股"`
→ 业务关系、所有权（视数据可得性）
→ **立即写入** `/tmp/tear-sheet/relationships.txt`

## 章节

以下按优先级排序。明确裁剪指导见下方“页面预算与裁剪顺序”。

### 1. 公司页眉

包含交易相关识别信息的 key-value 区块。

| 字段 | 说明 |
|---|---|
| 公司名称 | 大号、加粗 |
| 股票代码和交易所 | 如为上市公司；私营公司省略 |
| 总部地点 | 城市、州/国家 |
| 成立年份 | 年份 |
| 员工数 | 近似员工数 |
| 市值 / 估值 | 上市公司用市值；私营公司用最新已知估值 |
| 企业价值 | |
| 所有权 | 公众公司 / PE 持股（注明发起人）/ 家族 / 其他 |

对私营公司：醒目标注“私营公司”；跳过股票代码和交易所。

### 2. 业务概览

**这是推介材料段落，不是 CIQ 摘要。** 不要粘贴数据工具返回的公司描述。用推介材料文风重写 4–6 句：
- 描述收入模式（经常性 / 交易型、订阅 / 许可）
- 点明规模化客户基础（例如“服务 80% 的财富 500 强银行”）
- 具体写出竞争壁垒（例如“X 的专有数据集”“唯一拥有 Y 的供应商”）
- 从买方或卖方关注角度框定增长向量

语气应自信且具体。投行人员读完这一段，应立即理解公司的战略定位。

### 3. 收入与分部拆分

按业务单元或产品线拆分收入。

| 分部 | 收入（百万美元） | 占总收入比例 | 同比增长 |
|---|---|---|---|
| [分部 A] | | | |
| [分部 B] | | | |
| **合计** | | **100%** | |

**如果无法取得分部数据：** 用 2–3 句定性描述收入结构，替代表格（例如“收入主要来自订阅许可（约 70%）和专业服务（约 30%）。”）。空表看起来像坏结果；定性描述仍能传递有用信息。

### 4. 财务摘要（3 年 + LTM）

实际财政年度作为列表头。**如果可获得 LTM（过去十二个月）数据，在最近财政年度右侧加入 LTM 列。** 标注为“LTM [季度结束日期]”（例如“LTM 2025 年 Q3”）。投行通常用 LTM 做估值交叉检查；只有财政年度视角可能已经滞后 6 个月以上。

| 指标（百万美元） | FY20XX | FY20XX | FY20XX | LTM [日期] |
|---|---|---|---|---|
| 收入 | | | | |
| 收入增速 % | | | | |
| 毛利 | | | | |
| 毛利率 % | | | | |
| EBITDA | | | | |
| EBITDA 利润率 % | | | | |
| 经营利润 | | | | |
| 净利润 | | | | |
| Capex | | | | |
| 自由现金流 | | | | |
| FCF 利润率 % | | | | |

在 M&A 语境中，利润率和 FCF 转化率与绝对规模同样重要；买方评估的是效率和现金生成潜力。

**资本结构**（财务摘要下方的紧凑子表）：

| 指标 | 数值 |
|---|---|
| 总债务 | $XXM |
| 现金及等价物 | $XXM |
| 净债务 | $XXM |
| 净债务 / EBITDA | X.Xx |
| S&P 信用评级 | XX（如可得） |

使用已取得的资产负债表数据。这是任何投行公司画像的标准内容；总债务、杠杆率和信用评级会告诉买方融资图景是什么。如果没有信用评级，则省略该行。

### 5. 交易可比公司

公司倍数**和经营指标** — 投行会一起看，而不是孤立看倍数。

**如可得，前瞻倍数是强制项。** 表格必须包含 NTM 倍数（如工具返回）。当前瞻数据存在时只展示过去口径倍数，是重大缺口；投行按前瞻盈利定价交易。

**同业列是预期内容。** 如果用户提供了可比公司，每家公司各占一列。如果未提供，则用竞争对手工具识别 3–5 家上市同业，拉取倍数和经营指标，并纳入表格。没有同业语境的仅公司交易可比表，对任何投行用途都是不完整的。

| 指标 | [公司] | [可比公司 1] | [可比公司 2] | [可比公司 3] | 同业中位数 |
|---|---|---|---|---|---|
| EV/收入（NTM） | | | | | |
| EV/EBITDA 倍数（NTM） | | | | | |
| 收入增速 % | | | | | |
| EBITDA 利润率 % | | | | | |

如果尝试同业查询后只能取得公司自身倍数，则展示这些倍数，并在表格下方列出选定同业名称。

私营公司跳过本节。

### 6. M&A 活动

两部分。**本节预期包含交易价值**；投行人员会注意到缺失。

**硬规则：如果 M&A 工具返回交易价值，输出中必须出现。** 不得把已知交易价值降级为“未披露”；这是数据完整性问题。只有当工具确实未返回交易价值时，才使用“未披露”。

**a) 公司自身交易：**

**表格必须包含单独的交易价值列。** 不要把交易价值合并到备注或交易逻辑列；投行人员会扫描数字，单独列能支持快速阅读。

| 日期 | 标的 / 剥离资产 | 交易价值（百万美元） | 类型 | 交易逻辑 |
|---|---|---|---|---|
| | | | 收购 / 剥离 | |

如果没有找到：“过去 5 年未披露交易。”

**b) 可比行业交易（视数据可得性）：**
使用前面识别出的具体行业（例如“云基础设施软件 M&A”，不要用泛泛的“科技 M&A”）。如果用户指定了可比公司，也查找涉及这些具体公司的交易。

| 日期 | 标的 | 收购方 | EV（百万美元） | EV/收入 | EV/EBITDA |
|---|---|---|---|---|---|

如果工具无法取得：“数据源未提供可比交易数据。”不要编造先例交易倍数。

### 7. 关键业务关系

利用 S&P Capital IQ 关系数据。按类型分组：

**客户：** 前 3–5 个具名客户
**供应商：** 关键供应商和技术提供商
**合作伙伴：** 战略联盟、分销、JV
**竞争对手：** 关键竞争对手

每个条目都要包含关系类型和括号说明，解释关系性质（例如“AWS — 云基础设施（主要托管服务商）”，“JPMorgan — 客户（企业分析平台）”）。只有名称没有上下文并无帮助。给本节留出空间；它有战略价值，而且多数竞品公司速览缺少这部分。

### 8. 所有权快照（视数据可得性；如工具未返回则省略）

如果工具返回机构持股、内部人持股比例或主要持有人，纳入紧凑区块：

前几大机构持有人（如可得）：按持股比例列出前 3–5 名。
内部人持股：合计百分比。

对 PE 支持公司，注明发起人、收购年份和持股比例。所有权结构直接影响交易复杂度；广泛持有的上市公司、创始人控制公司和 PE 支持公司需要完全不同的交易路径。

如果工具未返回所有权数据，整体省略本节，不要展示占位符。

**不要包含管理团队表。** 没有 S&P Global 工具返回高管数据；见数据完整性规则 10。来自训练数据的管理层姓名会过时。

## 页面预算与裁剪顺序

**目标：最多 2 页。** IB 画像可以充分使用两页，但不得溢出到第 3 页。如果内容超过 2 页，按以下顺序裁剪（每项完全裁掉后再进入下一项）：

1. 所有权概况（章节 8）— 整体省略
2. 可比行业交易（章节 6b）— 保留公司自身 M&A，删除先例交易
3. 业务关系（章节 7）— 压缩为前 3 个竞争对手 + 供应商/合作伙伴/客户各前 2 个，描述只保留括号说明
4. 资本结构（章节 4）— 将净债务/EBITDA 合并为财务摘要中单独一行
5. 交易可比公司（章节 5）— 减少至 3 个同业

绝不要裁掉：业务概览（2）、收入与分部拆分（3）、财务摘要（4 核心表）、M&A 活动中公司自身交易（6a）。

## 格式说明

- 业务概览和分部拆分应获得最高视觉权重。
- **M&A 活动是标志性章节：** M&A 表头使用强调色（#2E75B6）填充、白色加粗文字；这是唯一使用不同于标准 #D6E4F0 表头色的表格。扫读时应醒目。
- **业务关系：空间允许时要留呼吸感。** 各关系组之间留 6pt，条目保留完整描述。但如果溢出到第 3 页，则按上方裁剪顺序压缩；本节价值高，也最容易压缩。
- 对私营公司，页眉、业务概览、财务数据和关系构成核心；其他章节可能较稀疏。
- **两页纪律：** 渲染前先在脑中估算页数。如果业务关系 + M&A 活动加起来会超过一整页，按裁剪顺序开始删减。
