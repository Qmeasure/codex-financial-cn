# 股票研究 Tear Sheet

## 目的
面向买方或卖方分析师评估投资机会的高密度快照。重点放在估值、前瞻预测、财务轨迹和分析师一致预期。所有内容都应支持或挑战一个投资逻辑。

**默认页数：** 1 页。股票研究 tear sheet 通常是单页，重点就是信息密度。如果用户要求更多空间，可扩展到 2 页。

## 查询计划

从以下查询开始。如果结果不完整，再拆成更窄的追加查询。

**查询 1 — 公司 profile + 市场数据：**
"[Company] 公司概览 板块 行业 市值 企业价值 股价 52周高低点 流通股 beta"
→ 页眉、业务描述  
→ **立即写入** `/tmp/tear-sheet/company-profile.txt`

**查询 2 — 历史财务：**
"[Company] 年度利润表 收入 毛利 EBITDA 净利润 EPS 自由现金流 总债务 现金及等价物 最近4个财政年度"
→ 财务摘要（提取 4 年，展示 3 年；最早一年只用于同比增速计算）  
→ **立即把原始值写入** `/tmp/tear-sheet/financials.csv`

**查询 2b — 分部（如可得）：**
"[Company] 按分部 业务单元 收入 最近2个财政年度"
→ 收入与分部拆分（需要 2 年数据计算同比增速）。如果分部数据不可得，跳过本节，不要留下空表。  
→ **立即写入** `/tmp/tear-sheet/segments.csv`（如果未返回分部数据则跳过）

**查询 3 — 估值 + 一致预期：**
"[Company] P/E EV/EBITDA EV/收入 估值倍数 一致预期收入 EPS 预测 分析师建议 目标价"
→ 估值快照、一致预期  
→ **立即把 multiples 写入** `/tmp/tear-sheet/valuation.csv`  
→ **立即把预测写入** `/tmp/tear-sheet/consensus.csv`

**查询 4 — 业绩：**
"[公司] 最近一次业绩会 核心要点 指引"
→ 业绩要点  
→ **立即写入** `/tmp/tear-sheet/earnings.txt`

**查询 5 — 股价表现：**
"[Company] 股价回报 1个月 3个月 6个月 1年 年初至今表现"
→ 股价表现（无需中间文件，数据直接进入文档）

**查询 6（如用户提供可比公司）：**
"[Comp company] 市值 EV/收入 EV/EBITDA 收入增长" — 每个可比公司重复查询
→ 估值快照所需 peer context  
→ **立即写入** `/tmp/tear-sheet/peer-comps.csv`

## 章节

以下按优先级排序。如果限制为一页，从底部开始删减。

### 1. 公司页眉
按全局样式配置渲染为两栏无边框 key-value 信息块。

左栏：Ticker（交易所）、板块 / 行业、总部  
右栏：股价、52 周区间、市值、EV、股本、beta

### 2. 业务描述
用 2-3 句紧凑表达。**面向分析师受众用自己的话重写**，不要逐字粘贴 CIQ 公司摘要。CIQ 摘要只是输入，输出应简洁且围绕投资逻辑。

对知名且覆盖充分的公司，假设分析师已了解基础业务。先写正在*变化*的事项，例如战略转向、组合重塑、新增长向量，而不是 Wikipedia 式概述。例如，对 Fortune 500 公司，不要花一句写“向机构提供金融数据”。可以写：“公司正把业务组合重塑为更高利润率的数据与分析业务，待完成 Mobility 分拆，并通过 Kensho 子公司积极投资 AI。”

对知名度较低的公司，可以先用一句简短说明“做什么”，再转向与投资逻辑相关的动态。

### 3. 估值快照
这是股票研究 tear sheet 的核心。

| 指标 | 历史口径 | 远期（NTM） |
|---|---|---|
| P/E | | |
| EV/EBITDA 倍数 | | |
| EV/收入 | | |
| P/FCF | | |
| 股息率 | | |

**如果工具可得，必须展示前瞻倍数。** 有前瞻数据却只展示历史倍数是重大缺口，因为分析师通常用前瞻盈利给公司估值。如果前瞻倍数不可得，只展示历史倍数，并注明“前瞻预测不可得”。

如果用户提供可比公司，为每家公司添加列；如果可比公司不少于 3 家，可改用“同业中位数”列。如果用户未提供可比公司，但工具返回同业数据，加入“同业中位数”列。如果两者都没有，只展示公司自身倍数。

### 4. 一致预期
展示市场预期。这是该类型 tear sheet 的关键差异点。

**数据可得性说明：** 一致预期的深度取决于公司和覆盖度。工具返回什么就纳入什么，例如分析师数量、目标价、Buy/Hold/Sell 分布；但不要编造或估算任何一致预期数字。对覆盖较少的公司，本节可能只有收入和 EPS 预测，这仍然有价值。

| 指标 | FY[year] 预测 | FY[year+1] 预测 |
|---|---|---|
| 收入 | | |
| EPS（标准化） | | |
| EBITDA | | |

如可得，使用 normalized/adjusted EPS。GAAP EPS 可能受一次性项目扭曲，对前瞻预测帮助较小。

在主要预测表下方加入紧凑的分析师一致预期块（如工具可得）：

| 分析师一致预期 | |
|---|---|
| 平均目标价 | $XXX |
| 预测数量 | XX |
| 买入 / 持有 / 卖出 | XX / XX / XX |

如果目标价或评级建议不可得，省略分析师一致预期块，不要展示空行。不要编造这些数字。

如果完全没有一致预期数据，跳过整个章节，并注明“无可用一致预期。”不要自行估算。

### 5. 财务摘要（3 年）
使用真实财年标签的高密度单表。

| 指标（百万美元） | FY20XX | FY20XX | FY20XX |
|---|---|---|---|
| 收入 | | | |
| 收入增长率 % | | | |
| 毛利率 % | | | |
| EBITDA | | | |
| EBITDA 利润率 % | | | |
| 净利润 | | | |
| EPS（摊薄） | | | |
| 自由现金流 | | | |
| 净债务 | | | |

从原始数据计算衍生指标（增速、利润率），不要单独查询。

**资本结构（放在财务摘要下方的独立紧凑子表）：**
不要把这些行追加到 3 年财务摘要表中，因为前几年列出现空单元格会像缺失数据。应直接在下方渲染为独立两列表（指标 | 数值），只展示最近一个财年：

| 指标 | FY[最近一年] |
|---|---|
| 总债务 | $XXM |
| 现金及等价物 | $XXM |
| 净债务 | $XXM |

这与 Corp Dev 和 IB/M&A tear sheet 使用的资本结构格式一致。保持紧凑，不要在财务摘要和子表之间添加额外间距。

### 6. 收入与分部拆分
如果工具可得分部数据，加入紧凑的分部收入表。这是股票研究的重要背景，因为分析师需要看到哪些业务线正在驱动增长。

| 分部 | 收入（百万美元） | 占总收入比例 | YoY 增长 |
|---|---|---|---|
| [Segment A] | | | |
| [Segment B] | | | |

为单页保持紧凑：只放表格，不写定性段落。如果分部数据不可得，完全跳过本节，不要包含空表或占位表。

### 7. 近期业绩要点
包含季度和日期，例如“2025 财年第 3 季度 — 2025 年 10 月”。用 3-4 个带**投资视角**的要点；该受众需要分部层面的具体信息，而不是泛泛战略主题。

**如有指引，先写指引。** 如果管理层发布前瞻指引，把它作为第一个要点，并使用加粗 **指引：** 前缀，例如“**指引：** 2026 财年 EPS 为 $19.40–$19.65，意味着 9–10% 增长；有机收入增长 6–8%。”指引是分析师最可操作的单一前瞻数据点，不要把它埋在经营亮点中。

**超预期/低于预期背景（数据允许时）：** 如果报告期的一致预期数据可得，把标题结果写成超预期/低于预期：“收入为 $X，较 $Y 的一致预期高出/低出 Z%。”如果工具没有返回报告期一致预期，只用绝对值和增速描述结果，不要编造一致预期数字。

随后写：
- 分部表现：哪些业务线加速或放缓
- 利润率轨迹：成本结构或盈利趋势相关评论

归因给管理层：使用“管理层强调……”或“CFO 表示……”而不是直接断言。本节应像业绩复盘，而不是新闻稿摘要。

### 8. 关键经营指标
如数据可得，加入 2-3 个与行业相关的 KPI（订阅用户数、同店销售、NIM 等）。如果没有行业特定指标，用已获取财务数据计算 ROE 和 ROIC。该节可选，空间紧张时删除。

### 9. 股价表现（优先删减）
期间收益率表。对该受众的分析价值较低，优先删减。

| 期间 | 回报 |
|---|---|
| 1 个月 | |
| 3 个月 | |
| YTD | |
| 1 年 | |

## 格式说明
- **这是信息密度最高的 tear sheet 类型。** 视觉上应明显比其他模板更紧凑。
- 财务摘要表：8pt 文本（size: 16），行高 240 DXA。使用所有模板中最紧凑的间距。
- 估值快照和一致预期：8.5pt 文本，占据视觉中心，因为分析师会先扫这些内容。
- 正文：8.5pt（size: 17），小于全局默认 9pt。单页材料中每半个 point 都重要。
- 章节间距：最小化。章节标题前 6pt（不是全局 12pt），分割线后 2pt。
- 对出现显著拐点的指标加粗（增长转正、利润率扩张/压缩）。
- 始终优先信息量，而不是留白。
