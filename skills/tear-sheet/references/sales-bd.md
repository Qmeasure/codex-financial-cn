# 销售 / 商务拓展 Tear Sheet

## 目的
这是一份帮助销售或 BD 团队准备客户会议的简报材料。重点是理解潜在客户的业务、管理层公开强调的优先事项，并识别如何把你的产品/服务与客户需求连接起来。财务信息应简化为规模和趋势。

这是最偏叙事的 tear sheet 类型。读起来应像会议简报备忘录，而不是数据表。

**默认页数：** 1-2 页。没有严格格式约定，优先保证可读性，不要过度压缩。

## 查询计划

从以下查询开始。如果结果不完整，再追加查询。

**查询 1 — 公司简介 + 财务：**
"[Company] 业务描述 概览 产品 服务 总部 员工 板块 行业 收入 毛利率 最近2个财政年度"
→ Header、公司概览、财务快照  
→ **立即写入** `/tmp/tear-sheet/company-profile.txt`  
→ **立即把原始财务数据写入** `/tmp/tear-sheet/financials.csv`

**查询 2 — 战略 + 业绩：**
"[公司] 最近一次业绩会 战略重点 CEO 评论 指引 关键举措"
→ 战略重点  
→ **立即写入** `/tmp/tear-sheet/earnings.txt`

**查询 3 — 关系 + 新闻：**
"[Company] 关键客户 供应商 合作伙伴 竞争对手 业务关系 近期收购 合作公告"
→ 关键关系、近期新闻  
→ **立即写入** `/tmp/tear-sheet/relationships.txt`

通常三个查询已经足够。对知名公司，这些查询会返回丰富结果。对小公司或非上市公司，查询 2 和 3 可能较稀疏，这可以接受。定性部分仍然有价值，因为 Codex 会把已有信息综合成有用的会议框架。

## 章节

以下按优先级排序。如果篇幅受限，从底部开始删减。

### 1. 公司页眉
保持简洁，只做身份识别，不放估值指标。

| 字段 | 说明 |
|---|---|
| 公司名称 | 大字号、加粗 |
| Ticker & Exchange | 上市公司填写；非上市公司省略 |
| 总部 | 城市、州/国家 |
| 行业 / 板块 | |
| 员工数 | |
| 年收入（最近一期） | 四舍五入到十亿美元或百万美元；A股/港股按披露币种和中文单位 |
| 市值 | 上市公司填写；非上市公司省略 |
| FY 收入指引 | 如业绩数据可得；例如“有机增长 6–8%” |
| FY EPS 或 EPS 指引 | 上市公司填写；从 `earnings.txt` 提取 |
| 关键财务指标 | 调整后 EPS、EBITDA 利润率或类似指标，只放一个头部数字 |

前瞻指引和 EPS 数据来自查询 2（业绩），填充页眉时应引用 `earnings.txt`，不要只依赖 `company-profile.txt`。

顶部使用一条横向信息带。不要放企业价值、beta 等指标，这类受众通常不需要。

### 2. 公司概览
这是最重要的部分。销售代表读完后，应能带着对潜在客户的扎实理解进入会议。

**不要粘贴 CIQ 公司摘要。** 它读起来像 SEC 文件，会让非金融受众失去兴趣。用 3-5 句通俗语言重写：
- 公司做什么（不用投资者术语：说“销售”，不要说“变现”；说“年收入”，不要说“top-line CAGR”）
- 客户是谁
- 如何赚钱
- 在哪些地区运营
- 有什么独特之处

用自然段写作。非金融背景人士应能理解每一句。

### 3. 战略重点与管理层评论
管理层当前关注什么？如果你知道 CEO 正在谈什么，就能让销售话术与之对齐。

**这不是业绩复盘。** 不要复用股票研究 tear sheet 的要点。提炼 3-5 个带主题标签和支撑数据点的*战略主题*：

- **AI/数据商业化：** 管理层正积极投资 AI 能力，FY2024 投入 X 美元研发，并推出三款 AI 驱动产品。
- **利润率提升：** CEO 把运营效率列为重点，目标是通过自动化提升 200bps 经营利润率。
- **国际增长：** 在 EMEA 开设新办公室；欧洲收入占比已从 18% 升至 25%。

每个 bullet 都应回答：“这家公司现在关心什么？有什么证据支持？” 销售代表读完后，应能立即看到产品连接角度。

如果没有业绩会数据（非上市公司常见），改用“近期进展”，从工具返回的新闻或公告中提取信息。

### 4. 财务快照
简化处理。使用一张紧凑表格，只展示规模、方向和一个盈利能力信号。销售代表只需要知道三件事：公司有多大、是否在增长、是否健康。

| 指标 | FY[上年] | FY[最近一年] | 同比变化 |
|---|---|---|---|
| 收入 | | | +X% |
| 毛利率 % | | | +X.Xpp |
| 员工数 | | | |

最多三行。不要 EBITDA、不要 EV multiples、不要资产负债表、不要净利润。毛利率（不是 EBITDA，也不是净利润）是适合销售受众的单一盈利能力指标：它直观表达“扣除直接成本后保留多少”，并能在不要求财务知识的情况下反映业务健康度。如果销售代表需要更深入财务信息，可以请求股票研究版本。

对非上市公司，这张表可能只有收入和员工数；两个展示规模和增长的数据点足以服务销售会议。

### 5. 关键关系与生态
帮助销售代表理解潜在客户所在生态，并识别切入角度。

四组带标签清单，每组 3-5 个名称，每个名称配一句说明：

**客户：** 他们向谁销售。帮助理解 go-to-market 和共同目标客户。  
示例：“JPMorgan Chase — 客户（企业分析平台部署）”

**供应商 / 技术：** 他们采购什么。识别替换或集成机会。  
示例：“AWS — 供应商（主要云基础设施）；Snowflake — 供应商（数据仓库）”

**合作伙伴：** 他们与谁合作。识别 co-sell 角度和共同关系。  
示例：“Deloitte — 合作伙伴（企业客户实施）”

**竞争对手：** 他们与谁竞争。提供定位背景。  
示例：“Bloomberg — 竞争对手（金融数据终端）”

每个 entry 都需要括号说明，让销售代表理解关系的*含义*，而不只是知道*是谁*。

如果关系数据不可得，注明“关系数据不可得”，然后继续。

### 6. 近期新闻与进展
3-5 个要点，每条一句，按时间倒序排列。可得时包含日期。**先写最新业绩报告**，这是销售会议最重要的近期事件，也为其他内容设定背景。随后写：M&A、产品发布、管理层变化、重大赢单。

**在本节末尾加入即将到来的催化剂**，使用“**即将发生：**”标签。示例：即将公布业绩日期、待完成剥离、产品发布、投资者日、监管里程碑。这些事项会为销售触达创造自然窗口，往往也是联系客户的最佳理由（“我注意到贵司 Q2 即将举办 Investor Day……”）。从业绩会评论和 M&A 数据（待完成交易）中提取。

### 7. 开场话题（优先删减）
基于上述数据综合生成 2-3 个建议话题。**每个开场话题都必须引用第 3 节的某个具体战略重点**，泛泛而谈的问题没有价值。用问题形式呈现。

**为每个话题标注建议角色画像**，例如（CTO）、（CFO）、（CDO）、（数据负责人）、（工程副总裁）、（采购负责人）。与 CTO 会面和与 CFO 会面需要不同开场。如果用户指定了会面对象，只为该角色画像生成话题。

示例：
- *(CTO/CDO)* “贵司在最近业绩会上提到[第 3 节的具体 AI initiative]，这会如何影响你们的[相关需求]？”
- *(CFO/COO)* “考虑到贵司的[第 3 节利润率提升目标]，你们是否在评估可以加速达成时间表的工具？”
- *(VP Strategy/Corp Dev)* “我注意到 [Company] 最近收购了 [target]，这会改变你们对[能力]的规划方式吗？”

如果用户描述了正在销售的产品/服务，要把这些话题定制为连接潜在客户优先事项与该产品/服务的角度。否则，保持话题扎根于潜在客户战略主题，但解决方案框架可以更通用。

**校验测试：** 最终确定每个开场话题前，确认其中至少包含一个来自 tear sheet 的具体数字、日期、产品名或 initiative 名称。任何可以套用到该行业任意公司的问题，都不是好的开场话题。“你们如何看待 AI？”太泛泛。“贵司 CEO 提到自 2018 年以来已投入 10 亿美元 AI 投资，且 iLEVEL auto-ingestion feature 已有 20% adoption，这正在如何改变分析师工作流？”则具体，并能体现准备充分。

本节是 Codex 的综合判断，不是工具返回的原始数据。需要清楚标注。

## 格式说明
- **这应是最温和、最易读的 tear sheet。** 内容要严谨，但版式应像简报备忘录，而不是数据终端。
- 正文：使用完整 9pt（size: 18）。不要压缩，优先可读性而不是密度。
- 正文段落行距：1.15 倍（比默认略宽松）。在这个模板中，留白是功能，不是浪费。
- 公司概览和战略重点应占页面约 40-50%。
- 财务快照：视觉上紧凑，重要性居次。保持小而清晰。
- 关键关系：考虑双栏布局（左侧客户 + 供应商，右侧合作伙伴 + 竞争对手），既节省垂直空间，又保留说明文字可见。
- 开场话题：使用缩进块状要点。这是文档的价值落点，视觉上应突出。
