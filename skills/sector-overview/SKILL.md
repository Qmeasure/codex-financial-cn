# 行业概览

## 工作流

### 第 1 步：定义范围

- **行业 / 子行业**：具体是什么行业，边界多窄？
- **目的**：客户报告、内部研究、pitch 材料、投资想法生成
- **深度**：高层概览（5-10 页）或深度研究（20-30 页）
- **角度**：中性格局分析 vs. 主题论点（例如“AI 基础设施建设”）
- **范围**：仅上市公司，还是也包含非上市公司？

### 第 2 步：市场概览

**市场规模与增长**
- 总可服务市场（TAM）及来源
- 历史增长率（5 年 CAGR）
- 预测增长率和关键假设
- 市场分层（按产品、地域、终端市场、客户类型）

**行业结构**
- 分散 vs. 集中：前五大市场份额
- 价值链图谱：价值在哪里沉淀？
- 商业模式类型（订阅、交易、许可、服务）
- 进入壁垒（资本、监管、技术、网络效应）

**关键趋势与驱动因素**
- 长期顺风因素（3-5 个主要趋势）
- 逆风因素和风险
- 技术颠覆方向
- 监管变化
- M&A 活动和整合趋势

### 第 3 步：竞争格局

**公司画像**（前 5-10 家参与者）：

| 公司 | 收入 | 增长 | EBITDA 利润率 | 市场份额 | 核心差异化 |
|------|------|------|--------------|----------|------------|
| | | | | | |

对每家公司给出简要画像：
- 业务描述（2-3 句）
- 战略定位和护城河
- 近期进展（业绩、M&A、产品发布）
- 估值快照（P/E、EV/EBITDA、EV/收入）

**竞争动态**
- 公司如何竞争？（价格、产品、服务、渠道）
- 谁在获得/失去份额，为什么？
- 新进入者或相邻市场参与者带来的颠覆风险

### 第 4 步：估值背景

- 板块交易倍数（当前和历史区间）
- 溢价/折价驱动因素（增长、利润率、市场地位）
- 近期 M&A 交易倍数
- 该板块相对大盘如何？

### 第 5 步：投资启示

- 最好的风险/回报机会在哪里？
- 可以通过该板块表达哪些主题投资？
- 板块关键争议（bull vs. bear 观点）
- 可能改变板块叙事的催化剂

### 第 6 步：输出

- Word 文档或 PowerPoint，包含：
  - 市场概览和规模测算
  - 竞争格局图
  - 公司对比表
  - 估值摘要
  - 关键图表：市场增长、份额趋势、估值历史
- 包含详细公司数据的 Excel 附录

## 重要说明

- 所有市场规模数据都必须标注来源，引用研究机构或方法
- 区分 TAM 炒作和现实可服务市场
- 行业概览很快过时，应注明日期并标记可能过期的数据
- 图表是必要内容：市场规模瀑布图、竞争定位矩阵、估值散点图
- 如面向客户，应将“所以呢”部分贴合客户具体场景（M&A 标的识别、竞争定位、市场进入）
