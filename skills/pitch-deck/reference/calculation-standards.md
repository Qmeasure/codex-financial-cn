## 关键验证公式

### CAGR 预测

**公式：**
```
未来值 = 当前值 × (1 + CAGR)^n
```

**变量：**
- 当前值：当前/基准年市场规模
- CAGR：复合年增长率（小数形式，例如 16.4% = 0.164）
- n：基准年到目标年之间的年数

**验证示例：**
```
来源声称：$22.1bn（2024），按 16.4% CAGR 增长至 $55.0bn（2030）

验证：22.1 × (1.164)^6 = 22.1 × 2.488 = 55.0 ✓
```

**计算 n（年数）：** 统计基准年到目标年之间的年数。示例：2024→2030 = 6 年，2025→2030 = 5 年。

### 估值倍数

**EV/收入：**
```
EV/收入倍数 = 企业价值 ÷ 收入
隐含 EV = 收入 × 倍数
```

**EV/EBITDA：**
```
EV/EBITDA 倍数 = 企业价值 ÷ EBITDA
隐含 EV = EBITDA × 倍数
```

**验证示例：**
```
来源声称：$436m 交易，收入 $45m，对应 9.7x 收入倍数

验证：436 ÷ 45 = 9.69 ≈ 9.7x ✓
```

### 市场份额

**公式：**
```
市场份额 =（分部规模 ÷ 总市场规模）× 100
```

**验证示例：**
```
来源声称：线上分部（$18bn）占总市场（$65bn）的 28%

验证：18 ÷ 65 = 0.277 = 27.7% ≈ 28% ✓
```

### 增长率

**同比增长：**
```
YoY 增长 =（当年 - 上年）÷ 上年 × 100
```

**基于起止值的 CAGR：**
```
CAGR =（终值 ÷ 起始值）^(1/n) - 1
```

## 一致预期方法论

当来源数据包含多个预测时，验证一致预期计算：

### 规模一致预期（区间）

**方法：** 使用所有来源的完整最小值-最大值区间。

**示例：**
```
来源：$14.9bn、$18.3bn、$21.1bn、$21.2bn、$22.1bn
一致预期：$15-22bn（四舍五入至最接近的 $1bn）
```

### CAGR 一致预期（中心簇）

**方法：** 剔除异常值（最高和最低），使用中间簇区间。

**示例：**
```
来源：10.6%、16.4%、17.2%、19.0%、22.7%
剔除异常值：10.6%（低）、22.7%（高）
中心簇：16.4%、17.2%、19.0%
一致预期：16-19%，或保守取 16-17%
```

### 预测一致预期

**方法：** 将一致预期 CAGR 应用于规模区间中点。

**示例：**
```
规模区间：$15-22bn → 中点：$18.5bn
CAGR 一致预期：16-17%
按 16%：18.5 × (1.16)^6 = $45.1bn
按 17%：18.5 × (1.17)^6 = $47.5bn
一致预测：$45-48bn
```

## 取整规则

以下是**常见惯例**；请根据数值量级和模板风格调整：

| 数值类型 | 常见取整 | 示例 |
|----------|----------|------|
| 大型市场规模（$10bn+） | 最接近的 $1bn | 18.47 → $18bn |
| 较小市场规模（<$10bn） | 最接近的 $0.5bn 或 $0.1bn | 2.3 → $2.5bn |
| 规模区间 | 匹配来源精度 | 14.9-22.1 → $15-22bn |
| CAGR | 整数百分比或 0.5% | 16.4% → 16% 或 16.5% |
| 市场份额 | 最接近的 5%，或匹配来源 | 27.7% → 25% 或 30% |
| 收入（$m） | 保留 1 位小数 | 18.47 → $18.5m |
| 倍数 | 保留 1 位小数 | 9.688 → 9.7x |

**取整原则：**
- 取整不应实质性改变数字含义；较小数值应使用更细精度。
- 一致性比精度更重要；类似数字应使用相同取整规则。
- 创建区间时，低端向下取整，高端向上取整。
- 对均值、中位数等统计摘要，匹配输入数据精度。

## 验证清单

使用来源数据中的任何计算值前：

### 公式验证
- [ ] 预测使用正确 CAGR 公式：`PV × (1 + r)^n`
- [ ] 倍数按 EV ÷ 指标计算（不要反向）
- [ ] 增长率分母使用正确基准年
- [ ] 适用时，百分比份额合计约为 100%

### 输入验证
- [ ] 基准年数字与来源文件一致
- [ ] CAGR/增长率与来源披露的方法论一致
- [ ] 时间段（n）计算正确
- [ ] 币种和单位一致（$bn vs $m）

### 输出验证
- [ ] 计算结果与来源披露数字一致
- [ ] 如不一致，调查方法论差异
- [ ] 取整规则应用一致
- [ ] 结果合理（无数量级错误）

### 一致预期验证
- [ ] 区间计算包含所有来源
- [ ] 异常值剔除方法已记录
- [ ] 中点计算使用正确平均方式
- [ ] 区间边界代表真实最小/最大值，或已说明使用的是有依据的子集

## 需要调查的异常信号

**预测不一致：**
- 自己计算的预测与来源差异 >5%
- 可能原因：基准年不同、CAGR 不同或取整方式不同

**倍数不一致：**
- 计算倍数与来源不一致
- 可能原因：指标定义不同（LTM vs NTM，收入 vs 净收入）

**一致预期不一致：**
- 你的共识区间与来源的一致预期不同
- 可能原因：来源剔除了部分数据点，或异常值处理方式不同

**不确定时：** 在脚注中说明差异，并展示你的计算方法。
