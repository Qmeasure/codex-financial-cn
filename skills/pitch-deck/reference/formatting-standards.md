## 视觉层级与布局

### 框体与章节布局

幻灯片布局会根据内容要求和模板设计变化。常见元素包括：
- 带标题和副标题的页眉章节
- 带标签侧栏的内容框
- 用于结构化数据的表格
- 用于视觉呈现数据的图表
- 幻灯片底部脚注栏

具体布局应遵循用户提供的模板。常见内容类型和典型结构：
- **市场定义页**：带要点内容的标签框 + 评论章节
- **TAM/规模测算页**：指标突出显示 + 数据表 + 关键结论
- **竞争分析**：比较表或矩阵
- **财务摘要**：图表 + 支撑数据表

### 对齐原则

**并列章节的垂直对齐：**

垂直堆叠的框体应保持一致：
- 左边距位置
- Bullet 缩进
- 文本起始位置
- 框体宽度

水平相邻的框体应保持一致：
- 顶部位置
- 高度（在内容允许时）
- 内部 padding

## 文本格式

### Bullet point 结构

避免无结构文本堆砌。将内容拆成便于扫读的 bullet points。

**正确结构示例：**
```
✓  面向消费者的移动端和 Web 语言学习应用
   (Duolingo, Babbel, Memrise, Busuu)
✓  B2B 企业语言培训平台
   (goFLUENT, Speexx, Learnship)
✓  在线辅导平台型市场
   (italki, Preply, Cambly)
```

**错误结构示例（文本堆砌）：**
```
面向消费者的移动端/Web 应用（Duolingo、Babbel、Memrise、Busuu）
B2B 企业平台（Speexx、Rosetta Stone Enterprise）
在线辅导平台型市场（Preply、italki、Cambly）
```

### Bullet 符号指南

| 语境 | 符号 | 用法 |
|---------|--------|-------|
| 纳入/正向 | ✓（勾选符号） | 范围内项目、功能存在 |
| 排除/负向 | ×（叉号） | 范围外项目、功能缺失 |
| 中性清单 | •（项目符号） | 一般枚举、评论 |
| 编号序列 | 1. 2. 3. | 流程步骤、排名 |
| 子要点 | ‣ 或 – | 主要点下的次级要点 |

符号使用应适配模板既有约定。

### 要点一致性

同一框体/章节内所有要点应使用相同格式：
- 同一框体内使用同一项目符号（除非有意区分）
- 所有一级要点缩进一致
- 项目符号大小一致
- 项目符号与文本之间间距一致
- 同层级要点文本字号一致

### 字号指南

以下为典型范围，应根据模板规格调整：

| 元素 | 典型字号（pt） | 样式 |
|---------|-------------------|-------|
| 幻灯片标题 | 40-48 | 加粗 |
| 副标题/定义 | 18-22 | 加粗 |
| 章节标题 | 14-16 | 常规 |
| 正文/要点 | 12-14 | 常规 |
| 表头 | 10-12 | 加粗 |
| 表格正文 | 9-11 | 常规 |
| 脚注 | 8-9 | 斜体 |

### 文本密度指南

- 每个内容框**最多 6-7 个要点**（根据空间调整）
- 每个要点**最多 2 行**
- **括号示例**放在同一行或下方缩进
- **避免孤行词**：调整换行，避免单个词独占新行

## 表格创建

### 关键：使用真实表格对象

**表格必须是真实表格对象，而不是使用 tab 间距排版的文本。**

使用 tab 的文本永远无法稳定对齐，看起来也不专业。始终创建真正的表格对象。

### 表格结构指南

1. **列对齐**：
   - 文本列：左对齐（表头和内容都左对齐）
   - 数字列：居中或右对齐
   - 表头应与对应列内容对齐

2. **表头行**：
   - 文本加粗
   - 背景加底色（使用模板品牌色）
   - 使用有对比度的文字颜色，保证可读性
   - 对齐方式与列内容一致

3. **交替行底色**（可选）：
   - 隔行浅色底纹可提升可读性

4. **汇总/合计行**：
   - 文本加粗
   - 使用较粗上边框（分隔线）
   - 使用不同背景底色

5. **表格宽度**：
   - 填满指定章节宽度
   - 避免表格漂浮在大片空白中

### XML 实现模式见 [`xml-reference.md`](xml-reference.md#table-implementation)

## 图表与图片处理

### 从 Excel 粘贴图表

从 Excel 粘贴图表时：

1. **只粘贴图表**：不要包含来源数据表
2. **调整尺寸以填满指定区域**：图表不应像小缩略图
3. **保持宽高比**：不要拉伸变形
4. **核验可读性**：轴标签、图例、数据标签必须可读

### 从 Excel 粘贴表格

从 Excel 粘贴表格时：

1. **只粘贴格式化表格**：排除任何来源数据或计算过程
2. **调整尺寸以填满指定区域**：表格应占满其章节
3. **核验列宽**：调整列宽，避免文本截断
4. **检查格式保留情况**：颜色、边框、字体可能需要调整

### 尺寸指南

**最小尺寸原则：**
- 图表：应占据指定区域的主要部分
- 表格：完整填满指定章节宽度
- 图片：尺寸适配语境，绝不要像缩略图

**视觉元素过小的表现（避免）：**
- 图表只占可用空间的一小部分
- 文本标签不可读
- 视觉元素周围有大片空白
- 视觉元素看起来像“缩略图”

### 正确尺寸调整工作流

1. 识别目标区域尺寸
2. 粘贴图表/表格
3. 立即调整尺寸以填满目标区域
4. 核验所有文本仍可读
5. 如需要，调整内部元素（图例位置、轴标签）

## 数据可视化

### 关键指标展示

展示关键指标（例如 TAM、CAGR、预测）时，优先考虑呈现数值之间的关系，而不是静态罗列：

- **视觉流向标识**：使用形状（箭头、chevrons、连接线）展示推进关系
- **尺寸层级**：主要指标用更大字号，标签用更小字号
- **空间布局**：通过元素位置展示逻辑流

### 箭头和流向标识

如果使用箭头或流向标识：
- 使用 PowerPoint 形状对象，不要使用文本字符
- 最终演示中不要使用基于文本的箭头（→、⟹）
- 使用 PowerPoint 形状工具或 XML shape elements 创建箭头

**XML 实现见 [`xml-reference.md`](xml-reference.md#arrow-shapes)**

## 字体一致性

### 跨框体字体一致性

同一层级的所有文本框应使用相同字号。

**应保持一致的同层级框体：**

| 框体类型 | 应与之匹配 |
|----------|-------------------|
| “纳入分部”内容 | “排除分部”内容 |
| “定义”内容 | “范围理由”内容 |
| 左栏要点 | 右栏要点 |
| 所有标签框 | 彼此 |
| 所有章节标题 | 彼此 |

### 校验流程

1. 识别同一层级的所有文本框
2. 检查每个文本框的字号
3. 如有差异，统一调整
4. 如果内容能放下，默认使用较大字号；否则统一使用较小字号

**例外**：子要点或次级文本可以比一级要点小，但必须在所有框体中保持一致。

## 模板适配

这些标准应适配正在使用的具体模板：

1. **颜色**：使用模板品牌色，不另行指定固定颜色
2. **字体**：使用模板字体族；中文内容仍需使用可读的中文字体 fallback
3. **间距**：匹配模板既有间距约定
4. **布局**：遵循模板章节结构

无论模板如何变化，以下关键原则保持不变：
- 文本在背景上必须可读
- 表格必须是真实表格对象
- 内容应适当填满可用空间
- 并列元素之间格式必须一致
- 图表/图片尺寸必须合适
