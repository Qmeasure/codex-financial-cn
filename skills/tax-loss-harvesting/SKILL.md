# 税损收割

## 工作流

### 步骤 1：识别候选持仓

扫描应税账户中存在未实现亏损的持仓：

| 证券 | 资产类别 | 成本基础 | 当前价值 | 未实现亏损 | 持有期 | 亏损比例 |
|------|----------|----------|----------|------------|--------|----------|
| | | | | | ST / LT | |

**按以下顺序优先：**
1. 绝对亏损金额最大（税务收益最大）
2. 短期亏损优先（可抵消按普通收入税率征税的短期收益）
3. 亏损比例最大的持仓（短期快速修复概率较低）

### 步骤 2：收益/亏损预算

计算客户税务状况：

| 类别 | 金额 |
|------|------|
| 年初至今已实现短期收益 | |
| 年初至今已实现长期收益 | |
| 年初至今已实现亏损 | |
| 净收益/亏损头寸 | |
| 往年结转亏损 | |
| **目标收割金额** | |

**税务节省估算：**
- 短期亏损 × 边际普通收入税率
- 长期亏损 × 资本利得税率
- 最多可用 3,000 美元净亏损抵扣普通收入
- 超额部分向后结转

### 步骤 3：替代证券

为每个收割候选持仓建议替代品，要求：
- 保持类似市场敞口（相同资产类别、行业、地域）
- 不构成“实质相同”（wash sale 规则）
- 具有类似风险/收益特征

| 卖出 | 替代买入 | 理由 | 跟踪误差风险 |
|------|----------|------|--------------|
| SPDR S&P 500 (SPY) | iShares Core S&P 500 (IVV) | 相同指数，不同基金公司 | 极低 |
| Vanguard Total Intl (VXUS) | iShares MSCI ACWI ex-US (ACWX) | 类似敞口，不同指数 | 低 |
| 个股 ABC | 行业 ETF (XLK) | 更广敞口，无 wash sale 风险 | 中等 |

### 步骤 4：Wash Sale 检查

执行前核验是否存在 wash sale：

- 检查家庭所有账户（应税账户、IRA、Roth、配偶账户）
- 30 天回看：过去 30 天是否买入过实质相同证券？
- 30 天前瞻：阻止未来 30 天回购同一证券
- 检查股息再投资计划（DRIPs）是否可能触发 wash sale
- 记录每笔交易的 wash sale 窗口

| 已卖出证券 | Wash Sale 窗口开始 | 窗口结束 | DRIP 启用？ | 风险 |
|------------|--------------------|----------|-------------|------|
| | | | | |

| 交易 # | 账户 | 动作 | 证券 | 股数 | 预计所得 | 预计亏损 | 替代证券 | 备注 |

**摘要：**
- 预计收割亏损合计：$
- 预计税务节省：$（按 % 边际税率）
- 对组合的净影响：较小（替代证券保持敞口）
- Wash sale 窗口管理：[日期]

### 步骤 6：收割后跟踪

30 天以上后，可选择：
- 换回原证券（如偏好）
- 继续持有替代证券（如无换回必要）
- 更新成本基础记录
- 为税务申报记录归档

## 重要说明

- Wash sale 规则很严格；违规会导致亏损不可抵扣，并调整成本基础。
- “实质相同”指同一证券，不是同一资产类别；跟踪不同指数的 ETF 通常可以。
- 始终协调家庭全部账户，包括退休账户。
- 考虑长期成本基础下降：收割会重置成本基础，意味着未来潜在收益更高。
- 年末是主要收割季，但全年都可能存在机会。
- 共同基金 12 月资本利得分配可能增加收割紧迫性。
- 为税务申报和合规记录所有事项。
- 并非所有亏损都值得收割；交易成本和跟踪误差是真实成本。
