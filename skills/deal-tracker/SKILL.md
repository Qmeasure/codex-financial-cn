- 用户模板和品牌规范优先，但不得突破中文可读性、来源脚注、币种/单位/日期/口径说明这些底线。
- 保留 DCF、LBO、WACC、EV/EBITDA、IRR、MOIC、NAV、KYC、AML、MCP、CLI 等专业缩写和代码标识。

# 交易跟踪器

## 工作流

### 第 1 步：交易设置

对每笔交易记录：
- **交易名称 / 代码名**：Project [Name]
- **客户**：卖方或买方名称
- **交易类型**：卖方、买方、融资、重组
- **角色**：牵头顾问、联席顾问、公平性意见
- **交易规模**：预期企业价值
- **阶段**：Mandate 前 → 已聘用 → Marketing → IOI → 尽调 → 最终报价 → 签署 → 交割
- **团队**：指定 MD、VP、Associate、Analyst
- **关键日期**：聘用日期、CIM 分发、IOI 截止、管理层会议、最终报价截止、目标交割

### 第 2 步：里程碑跟踪

按交易跟踪关键里程碑：

| Teaser 分发 | | | | |

| CIM 分发 | | | | |

状态：按计划 / 有风险 / 延迟 / 完成

### 第 3 步：行动事项

维护覆盖所有交易的动态行动事项清单：

| 行动 | 交易 | 负责人 | 截止日期 | 优先级 | 状态 |
|------|------|--------|----------|--------|------|
| | | | | P0/P1/P2 | 未完成/已完成/受阻 |

### 第 4 步：每周交易回顾

为每周团队会议生成摘要：

**对每个活跃交易：**
1. 一句话状态更新
2. 本周关键进展
3. 即将到来的里程碑（未来 2 周）
4. 阻碍或风险
5. 下周行动事项

**Pipeline 摘要：**
- 按阶段统计活跃交易总数
- 有风险交易（错过里程碑、流程停滞）
- Pipeline 中的新 mandate / pitch
- 本季度预计交割项目

### 第 5 步：输出

- Excel 工作簿，包含：
  - Pipeline 概览（所有交易，每笔一行）
  - 每笔交易的里程碑跟踪页签
  - 行动事项总表
  - 每周回顾摘要
- 可选：用于邮件/Slack 分发的 Markdown 摘要

## 重要说明

- 至少每周更新跟踪器；过期跟踪器比没有跟踪器更糟
- 标记里程碑滑坡的交易；提前预警能避免意外
- 没有负责人和截止日期的行动事项不会被完成，应写具体
- Pipeline 视图应展示交易阶段、规模和可能性，便于收入预测
- 记录买方/投资人反馈；反馈模式会指导策略调整
- 单独归档已关闭/死亡交易，保持活跃视图清晰
