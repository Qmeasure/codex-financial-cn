# 中文 PPTX 格式合同

本文件是本 skill 的本地 PPTX/PowerPoint reference。生成正式演示文件前必须读取；根级 `../../CN_PPTX_OUTPUT_CONTRACT.md` 仍作为上位标准。

## 版式与字体

- 标题、正文、图表、表格、脚注和来源必须使用中文金融材料语气。
- 中文字体优先级：Microsoft YaHei、PingFang SC、Noto Sans CJK SC、Source Han Sans SC、SimSun、Arial Unicode MS fallback。
- 页面密度必须适合机构材料阅读，避免文字溢出、孤词、遮挡和过窄表格。
- 用户模板和品牌规范优先，但不得突破中文可读性、来源脚注和币种单位底线。

## 图表、表格与来源

- 图表标题、轴标签、图例、单位和来源必须中文化。
- 表格必须是真实 PPT 表格或可编辑对象，不得用管道符或制表符伪造。
- 来源脚注必须包含来源名称、日期和口径；可用时保留可点击链接。
- 每页应有清晰的信息层级，标题不得只写英文泛称。

## 交付与 QA

- 最终回复前必须确认 PPTX 文件已生成、路径存在、可打开或结构校验通过。
- 可用时必须渲染或截图检查，重点检查中文字体、文字溢出、图表遮挡、表格错位和页脚来源。
- 如无法完成视觉 QA，最终回复必须说明原因。
- 最终回复必须包含 PPTX 文件路径。
