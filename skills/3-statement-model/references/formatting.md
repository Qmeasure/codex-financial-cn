# 中文三表模型格式参考

本参考文件必须与根目录 `CN_OUTPUT_FORMATTING.md` 一起使用。三表模型、检查表、图表、脚注和最终摘要必须使用中文金融语境；默认 A股优先，港股和美股兼容。跨市场或跨币种模型必须显式标注币种、单位、汇率、会计准则、数据日期和来源。

# 格式标准参考

| 元素 | 格式 |
|------|------|
| 硬编码输入 | 蓝色字体 |
| 公式 | 黑色字体 |
| 指向其他工作表的链接 | 绿色字体 |
| 检查单元格 | 错误为红色，平衡为绿色 |
| 负数 | 使用括号，不使用减号 |
| 货币 | 大额数字不保留小数；每股数据保留 2 位小数 |
| 百分比 | 保留 1 位小数 |
| 表头 | 加粗，底部边框 |
| 单位行 | 在表头下方包含单位行（百万元、%、等） |

## 视觉分隔规则

- 历史期和预测期之间使用细竖线分隔。
- 章节合计行后使用粗底边框（例如资产合计）。
- 小计使用单底边框。
- 总计使用双底边框。

## 合计和小计行格式

## 资产负债表检查行格式

资产负债表检查行（位于负债和权益合计下方）使用条件数字格式：非零值显示为红色。资产负债表正确平衡时（检查值 = 0），数值显示为黑色或标准格式。

| 检查值 | 字体颜色 |
|--------|----------|
| = 0（平衡） | 黑色（标准） |
| ≠ 0（错误） | 红色 |

**实现方式：** 应用自定义数字格式 `[Red][<>0]0.00;[Red][<>0](0.00);0.00`，或使用 Excel 条件格式规则“单元格值 ≠ 0”→ 红色字体。

## 利润率行格式

| 元素 | 格式 |
|------|------|
| 利润率 % 行 | 缩进、斜体、保留 1 位小数 |
| 正向趋势 | 无特殊格式，或使用浅绿色 |
| 负向趋势 | 标记为需要审阅，使用浅黄色 |
| 低于同业平均 | 可考虑高亮并用于讨论 |

## 信用指标格式

| 元素 | 格式 |
|------|------|
| 杠杆倍数 | 保留 1 位小数并加 “x” 后缀（例如 2.5x） |
| 百分比 | 保留 1 位小数并加 “%” 后缀 |
| 净债务为负 | 使用括号，表示净现金状态 |
| 章节标题 | 加粗，写 “信用指标” |
| 分隔线 | 在信用指标章节上方使用细边框 |

## 信用指标阈值颜色

| 指标 | 绿色 | 黄色 | 红色 |
|------|------|------|------|
| 总债务 / EBITDA | < 2.5x | 2.5x-4.0x | > 4.0x |
| 净债务 / EBITDA | < 2.0x | 2.0x-3.5x | > 3.5x |
| 利息保障倍数 | > 4.0x | 2.5x-4.0x | < 2.5x |
| 债务 / 总资本 | < 40% | 40%-60% | > 60% |
| 流动比率 | > 1.5x | 1.0x-1.5x | < 1.0x |
| 速动比率 | > 1.0x | 0.75x-1.0x | < 0.75x |

## Checks 工作表条件格式

- 单元格包含通过标记 → 绿色填充
- 单元格包含失败标记 → 红色填充
- 单元格包含警告 → 黄色填充
- 差异单元格 = 0 → 浅绿色填充
- 差异单元格 ≠ 0 → 浅红色填充

## 利润率合理性标记

- 毛利率 < 0% → 错误：审阅 COGS
- 毛利率 > 80% → 警告：核实收入/COGS
- EBITDA 利润率 < 0% → 标记：经营亏损
- EBITDA 利润率 > 50% → 警告：异常偏高
- 净利率 < 0% → 标记：净亏损（成长阶段可能可以接受）
- 净利率 > 毛利率 → 错误：公式问题
