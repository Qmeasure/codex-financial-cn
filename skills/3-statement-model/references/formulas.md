# 公式参考

**重要：** 除非用户另有说明，否则使用本参考文件中的公式。

---

## 核心勾稽关系

```
资产负债表：          资产 = 负债 + 权益
净利润：              利润表净利润 → 现金流量表经营活动（起点）
现金流量表：          Δ现金 = CFO + CFI + CFF
现金勾稽：            期末现金（现金流量表）= 现金（资产负债表资产）
月度/年度现金：       期末现金（月度）= 期末现金（年度）
留存收益：            期初留存收益 + 净利润 - 股利 = 期末留存收益
股权融资：            Δ普通股/APIC（资产负债表）= 股权发行（CFF）
第 0 年权益：         第 0 年募集权益 = 第 1 年期初权益
```

## 毛利计算

**重要：** 毛利必须基于净收入计算，而不是总收入。

```
净收入 - 收入成本 = 毛利
```

| 术语 | 定义 |
|------|------|
| 总收入 | 扣除任何调整前的全部收入 |
| 净收入 | 总收入 - 退货 - 折让 - 折扣 |
| 收入成本 | 直接归属于已售商品/服务生产的成本 |
| 毛利 | 净收入 - 收入成本 |

**注：** 盈利能力计算必须始终以净收入为起点。净收入在多数财务报表中也可能写作“净销售额”或“收入”。总收入会高估真实收入表现。

## 利润率公式

```
毛利率 %        = 毛利 / 净收入
EBITDA          = EBIT + D&A（或 = 毛利 - OpEx）
EBITDA 利润率 % = EBITDA / 净收入
EBIT 利润率 %   = EBIT / 净收入
净利率 %        = 净利润 / 净收入
```

## 信用指标公式

```
总债务              = 一年内到期债务 + 长期债务
净债务              = 总债务 - 现金
总债务 / EBITDA     = 总债务 / EBITDA（来自利润表）
净债务 / EBITDA     = 净债务 / EBITDA（来自利润表）
利息保障倍数        = EBITDA / 利息费用（来自利润表）
净利息费用 / 债务   = 净利息费用 / 长期债务
债务 / 总资本       = 总债务 /（总债务 + 总权益）
债务 / 权益         = 总债务 / 总权益
流动比率            = 流动资产合计 / 流动负债合计
速动比率            =（流动资产合计 - 存货）/ 流动负债合计
```

## 预测公式（净收入百分比法）

```
收入成本（预测） = 净收入 × 收入成本 % 假设
S&M（预测）      = 净收入 × S&M % 假设
G&A（预测）      = 净收入 × G&A % 假设
R&D（预测）      = 净收入 × R&D % 假设
SBC（预测）      = 净收入 × SBC % 假设
```

## 营运资本公式

```
应收账款
  期初 AR
  + 收入（来自利润表）
  - 现金回收（轧差项）
  = 期末 AR
  DSO =（AR / 收入）× 365

存货
  期初存货
  + 采购（轧差项）
  - COGS（来自利润表）
  = 期末存货
  DIO =（存货 / COGS）× 365

应付账款
  期初 AP
  + 采购（来自存货计算）
  - 现金付款（轧差项）
  = 期末 AP
  DPO =（AP / COGS）× 365

净营运资本 = AR + 存货 - AP
ΔWC = 当期 NWC - 前期 NWC
```

## D&A 明细表公式

```
期初 PP&E（原值）
+ CapEx
= 期末 PP&E（原值）

期初累计折旧
+ 折旧费用
= 期末累计折旧

PP&E（净额）= PP&E 原值 - 累计折旧
```

## 债务明细表公式

```
期初债务余额
+ 新增借款
- 偿还债务
= 期末债务余额

利息费用 = 平均债务余额 × 利率
  （可使用期初余额避免循环引用；如启用循环引用，也可迭代计算）
```

## 留存收益公式

```
期初留存收益
+ 净利润（来自利润表）
+ 股权激励费用（SBC）（来自利润表）
- 股利
= 期末留存收益
```

## NOL（净经营亏损）明细表公式

```
NOL 结转明细表

期初 NOL 余额（第 1 年 / 成立时 = 0）
+ 本期产生 NOL（如果 EBT < 0，则 ABS(EBT)，否则为 0）
- 使用 NOL（受应税收入和使用上限限制）
= 期末 NOL 余额

期初余额规则

对于新业务或模型首期：
  期初 NOL 余额 = 0
  NOL 只能通过已实现亏损增加（EBT < 0）
  不得凭空创建或假设存在 NOL

NOL 使用计算

税前利润（EBT）
  如果 EBT > 0：
    可用 NOL = 期初 NOL 余额
    使用上限 = EBT × 80%（2017 年后美国联邦限制）
    已使用 NOL = MIN(可用 NOL, 使用上限)
    应税收入 = EBT - 已使用 NOL
  如果 EBT ≤ 0：
    已使用 NOL = 0
    应税收入 = 0
    本期产生 NOL = ABS(EBT)

含 NOL 的税费计算

应付税费 = MAX(0, 应税收入 × 税率)
  （税费不能为负；亏损应形成 NOL 资产）

NOL 递延所得税资产（DTA）

DTA - NOL 结转 = 期末 NOL 余额 × 税率
ΔDTA = 当期 DTA - 前期 DTA
  （DTA 增加 = 现金流量表中的非现金收益）
  （DTA 减少 = 现金流量表中的非现金费用）
```

## 资产负债表结构

```
资产
  现金（来自现金流量表期末现金）
  应收账款（来自营运资本）
  存货（来自营运资本）
  流动资产合计

  PP&E 净额（来自 D&A）
  递延所得税资产 - NOL（来自 NOL 明细表）
  非流动资产合计
  资产合计

负债
  应付账款（来自营运资本）
  一年内到期债务（来自债务明细表）
  流动负债合计

  长期债务（来自债务明细表）
  负债合计

权益
  普通股
  留存收益（来自留存收益明细表）
  权益合计

检查：资产 - 负债 - 权益 = 0
```

## 现金流量表结构

```
经营活动现金流（CFO）
  净利润（链接：利润表）
  + D&A（链接：D&A 明细表）
  + 股权激励费用（SBC）（链接：利润表或假设）
  - ΔDTA（递延所得税资产）（链接：NOL 明细表；DTA 增加 = 使用现金）
  - ΔAR（链接：营运资本）
  - Δ存货（链接：营运资本）
  + ΔAP（链接：营运资本）
  = CFO

投资活动现金流（CFI）
  - CapEx（链接：D&A 明细表）
  = CFI

融资活动现金流（CFF）
  + 债务发行（链接：债务明细表）
  - 债务偿还（链接：债务明细表）
  + 股权发行（链接：资产负债表普通股/APIC）
  - 股利（链接：留存收益明细表）
  = CFF

现金净变化 = CFO + CFI + CFF
期初现金
+ 现金净变化
= 期末现金（链接至：资产负债表现金）
```

## 检查公式

```
资产负债表平衡检查：     = 资产 - 负债 - 权益（必须 = 0）
现金勾稽：               = 资产负债表现金 - 现金流量表期末现金（必须 = 0）
留存收益滚动：           = 前期留存收益 + 净利润 + SBC - 股利 - 资产负债表留存收益（必须 = 0）
DTA 勾稽：               = NOL 明细表 DTA - 资产负债表 DTA（必须 = 0）
股权融资勾稽：           = Δ普通股/APIC（资产负债表）- 股权发行（CFF）（必须 = 0）
第 0 年权益勾稽：        = 第 0 年募集权益 - 第 1 年期初权益（必须 = 0）
月度 vs 年度现金：       = 期末现金（月度）- 期末现金（年度）（必须 = 0）
NOL 使用上限：           = 已使用 NOL ≤ EBT × 80%（2017 年后必须为 TRUE）
NOL 非负：               = 期末 NOL 余额 ≥ 0（必须为 TRUE）
NOL 起始余额：           = 期初 NOL（第 1 年）= 0（新业务必须为 TRUE）
NOL 累积：               = NOL 仅在 EBT < 0 时增加（亏损产生 NOL）
```
