# SEC 披露文件数据提取参考

**何时使用：** 仅当模型模板明确要求从 SEC 披露文件（10-K、10-Q）提取数据时引用本文件。若模板已直接提供数据，或使用其他数据源，则不需要此参考。

---

## 从 SEC 披露文件提取数据（10-K / 10-Q）

使用上市公司数据填充模型模板时，应直接从 SEC 披露文件提取财务数据。

### 步骤 1：定位披露文件

1. 使用 SEC EDGAR：`https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=[TICKER]&type=10-K`
2. 季度数据使用 `type=10-Q`

### 步骤 2：识别披露币种

提取数据前，先识别报告币种：
- 检查封面页或页眉中的报告币种
- 查看报表标题，例如 "in thousands of U.S. dollars"
- 审阅附注 1（重大会计政策摘要）

**常见币种标识**

| 标识 | 币种 |
|------|------|
| $, 美元 | 美元 |
| €, EUR | 欧元 |
| £, GBP | 英镑 |
| ¥, JPY | 日元 |
| ¥, 人民币, RMB | 人民币 |
| CHF | 瑞士法郎 |
| CAD, C$ | 加拿大元 |

模型币种应与披露文件一致，并在假设标签页记录。

### 步骤 3：定位财务报表

在 10-K 或 10-Q 中定位：
- **Item 8**（10-K）或 **Item 1**（10-Q）：财务报表
- 需要提取的关键章节：
  - 合并经营报表（利润表）
  - 合并资产负债表
  - 合并现金流量表
  - 财务报表附注（用于获取明细表）

### 步骤 4：数据提取映射

**利润表（来自合并经营报表）**

| 披露行项目 | 模型行项目 |
|------------|------------|
| 净收入 / 净销售额 | 收入 |
| 销售成本 | COGS |
| 销售、一般及管理费用 | SG&A |
| 折旧与摊销 | D&A |
| 利息费用净额 | 利息费用 |
| 所得税费用 | 税项 |
| 净利润 | 净利润 |

**资产负债表（来自合并资产负债表）**

| 披露行项目 | 模型行项目 |
|------------|------------|
| 现金及现金等价物 | 现金 |
| 应收账款净额 | AR |
| 存货 | 存货 |
| 不动产、厂房和设备净额 | PP&E（净额） |
| 总资产 | 总资产 |
| 应付账款 | AP |
| 短期债务 / 长期债务一年内到期部分 | 短期债务 |
| 长期债务 | 长期债务 |
| 留存收益 | 留存收益 |
| 股东权益合计 | 总权益 |

**现金流量表（来自合并现金流量表）**

| 披露行项目 | 模型行项目 |
|------------|------------|
| 净利润 | 净利润 |
| 折旧与摊销 | D&A |
| 应收账款变动 | ΔAR |
| 存货变动 | ΔInventory |
| 应付账款变动 | ΔAP |
| 资本开支 | CapEx |
| 发行普通股所得款项 | 股权发行 |
| 债务发行所得款项 / 债务偿还 | 债务活动 |
| 已支付股息 | 分红 |

### 步骤 5：从附注提取支持性明细

对明细表，从财务报表附注提取：
- **债务附注** → 到期安排、利率、covenants
- **不动产、厂房及设备附注** → PP&E 原值、累计折旧、使用寿命
- **收入附注** → 分部拆分、地区拆分
- **租赁附注** → 经营租赁 vs. 融资租赁义务

### 步骤 6：历史数据要求

至少提取 3 年历史数据：
- 10-K 通常提供 3 年 IS/CF、2 年 BS
- 第 3 年 BS 从上一年的 10-K 中提取
- 如需要季度颗粒度，使用 10-Q 补充

### 数据提取检查清单

- 识别报告币种和单位口径（千、百万）
- 3 年历史利润表
- 3 年历史现金流量表
- 3 年历史资产负债表
- 核验 IS 净利润 = CF 起始净利润（每年）
- 核验 BS 现金 = CF 期末现金（每年）
- 从附注提取债务到期安排
- 提取 D&A 明细或使用寿命假设
- 记录需要正常化的非经常性/一次性项目

### 处理常见披露差异

| 差异 | 处理方式 |
|------|----------|
| D&A 嵌入 COGS/SG&A | 从现金流量表提取 D&A |
| "Other" 行项目金额重大 | 查阅附注拆分 |
| 重述 | 使用重述后数字，并在假设中注明 |
| 财年 ≠ 日历年 | 使用财年结束日标注，例如 FYE Jan 2025 |
| 非美元报告币种 | 调整模型币种，使其匹配披露文件 |
