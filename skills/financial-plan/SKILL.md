# 财务规划

## 工作流

### 步骤 1：客户画像

收集或确认：
- **人口统计信息**：年龄、配偶年龄、被抚养人、预期寿命假设
- **就业情况**：当前收入、预期加薪、目标退休年龄
- **账户**：所有投资账户余额和资产配置
- **收入来源**：工资、奖金、租金收入、Social Security 估算、养老金
- **支出**：当前年度支出、预期变化（房贷还清、子女独立等）
- **负债**：房贷、学生贷款、其他债务
- **保险**：寿险、失能险、长期护理险、健康险
- **遗产**：遗嘱、信托、受益人指定、赠与策略

### 步骤 2：现金流分析

构建年度现金流预测：

| 年份 | 年龄 | 总收入 | 税费 | 生活支出 | 储蓄 | 净现金流 |
|------|------|--------|------|----------|------|----------|
| | | | | | | |

关键输入：
- 通胀率假设（通常 2.5-3%）
- 税率（边际税率和有效税率）
- 储蓄率，以及储蓄流向（税前、Roth、应税账户）

### 步骤 3：退休测算

**积累阶段：**
- 当前投资组合价值
- 年度缴款（401k、IRA、应税账户）
- 按资产类别设定预期回报
- Monte Carlo 模拟：不同支出水平下的成功概率

**支取阶段：**
- 退休后所需年度支出（今日美元 → 通胀调整后）
- Social Security 起领年龄和福利金额
- 养老金收入（如有）
- 投资组合提款率和顺序
- 必须最低提取额（RMDs）

**关键输出：**
- 退休时预计投资组合价值
- 可持续提款率
- 资金不耗尽概率（目标 >85%）
- “假如”情景：提前退休、市场下跌、更高支出

### 步骤 4：目标专项分析

#### 教育资金
- 子女年龄和目标入学时间
- 当前 529 计划余额
- 目标资金水平（公立 vs. 私立，4 年制 vs. 研究生）
- 达成目标所需每月储蓄
- 财务资助因素

#### 遗产规划
- 当前遗产价值和预计增长
- 遗产税风险敞口（联邦和州）
- 现有信托结构
- 赠与策略（年度免税额、终身免税额度使用）
- 慈善捐赠计划
- 受益人审阅

#### 风险管理
- 寿险需求分析（收入替代、债务偿还、教育资金）
- 失能险充足性
- 长期护理规划
- 伞式责任险覆盖

### 步骤 5：情景建模

运行关键情景：

| 情景 | 成功概率 | 90 岁时组合价值 | 备注 |
|------|----------|------------------|------|
| 基准情景 | | | |
| 提前 2 年退休 | | | |
| 第 1 年市场下跌 20% | | | |
| 更高支出（+20%） | | | |
| 一方配偶活到 95 岁 | | | |
| 长期护理事件 | | | |

### 步骤 6：建议

按优先级列出行动项：
1. 储蓄率调整
2. 资产配置调整
3. 税务优化（Roth conversion、tax-loss harvesting、asset location）
4. 需要补足的保险缺口
5. 遗产文件更新
6. 受益人指定审阅

### 步骤 7：输出

- 财务规划文档（Word/PDF，15-25 页）
- 现金流预测电子表格（Excel）
- 退休测算图表
- 目标资金分析
- 情景对比表
- 行动项清单

## 重要说明

- 财务规划是动态文档；应每年或重大人生事件后审阅并更新。
- 对回报假设保持保守；高估回报会带来虚假的信心。
- 税务规划与投资回报同等重要；每条建议都要建模其税务影响。
- Social Security 领取时点是重要杠杆；建模 62、67 和 70 岁起领。
- 始终对计划做压力测试；只在基准情形下成立的计划不是好计划。
- 合规：确保建议符合适当性/受托责任标准。
