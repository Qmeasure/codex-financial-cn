# 中文 HTML 格式合同

本文件是本 skill 的本地 HTML reference。生成正式 HTML 报告前必须读取。

## 页面与中文显示

- HTML 必须自包含或明确说明外部资源；中文字体栈使用 Microsoft YaHei、PingFang SC、Noto Sans CJK SC、Source Han Sans SC、SimSun、Arial Unicode MS fallback。
- 标题、导航、表格表头、图表标题、来源脚注和免责声明必须中文化。
- 页面必须适合浏览器打开和打印阅读，避免表格溢出、文字遮挡和移动端不可读。
- 数字、币种、单位、日期和会计准则必须按中文机构材料表达。

## 链接与来源

- 所有来源链接必须使用 `<a href="...">显示文本</a>`，禁止正文裸露长 URL。
- 每个关键数字、定性判断和引用必须能追溯到来源、日期和口径。
- Exhibit 下方来源标注必须使用很小字号：CSS 默认 8px，最大不得超过 7pt（约 9px）。
- 每个 Exhibit 下方只保留最重要的 1 个来源，必须使用 `<a href="...">有意义显示文本</a>`；多来源清单放入“数据来源与口径说明”或参考资料，不得在 Exhibit 下方罗列。
- HTML 正文、表格、脚注、来源、caption 和链接显示文本不得出现固定校验标签；正式表格缺失值使用 `—`，说明性限制放入“数据来源与口径说明”。
- 风险提示和免责声明必须在页面内可见。

## 交付与 QA

- 最终回复前必须确认 HTML 文件已生成、路径存在、可在浏览器打开或结构校验通过。
- 可用时进行浏览器截图或打印预览检查，确认中文字体、表格、图表、脚注和链接可读。
- 最终回复必须包含 HTML 文件路径。
