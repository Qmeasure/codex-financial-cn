# 差异说明

给定同一范围下的本期实际、上期实际和预算，生成差异说明表。

## 阈值

若满足以下任一条件，则标记该行需要说明：

- 绝对差异 ≥ 公司重要性阈值（使用用户提供的值；默认取该行 5% 或固定底线中的较大者）
- 该行位于“始终说明”清单中（收入、人员成本、现金）

## 对每个被标记行项目

| 列 | 内容 |
|---|---|
| **行项目** | 科目或标题 |
| **本期 / 上期 / 预算** | 三个数值 |
| **相对上期 Δ** 和 **相对预算 Δ** | 金额和百分比 |
| **驱动因素** | 用一句话从底层活动解释变动，不要只是重复数字 |

驱动因素解释的是 *为什么*，不是 *发生了什么*：应写“5 月发布新增 GPU 预留导致云支出增加 $1.2M”，而不是“云支出增加 $1.2M（18%）”。

## 驱动因素来源

通过 internal-gl MCP 查看该行背后的活动（分录来源拆分、供应商结构、人数变化、数量 × 单价）。如果数据无法说明驱动因素，写“驱动因素不明确 — 提交 controller 关注”，不要编造原因。

## 输出

输出差异说明表，并附 3-5 句简短文字，总结本期最大变动项。
