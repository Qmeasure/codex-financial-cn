# 滚动表

给定科目（或科目组）、主体和期间，生成能将期初余额勾稽到期末余额的滚动表。

## 结构

```
期初余额（依据上期结账包）                  X
  + 新增/本期发生                            A
  + 本期已入账预提                           B
  − 前期预提转回                            (C)
  − 付款/结算                               (D)
  ± 重分类/调整                              E
  ± 外币折算                                 F
期末余额（依据期末总账）                    Y
```

## 逐行勾稽

- **期初**：上期结账包，或上期期末日期的总账余额。
- **每个发生额行**：通过 internal-gl MCP 查询总账（科目 + 日期范围 + 分录来源过滤条件）。引用该查询。
- **期末**：期末日期的总账余额。

滚动表**必须加总一致**：`X + A + B − C − D + E + F = Y`。如果不一致，差额就是未解释项目，应明确暴露，不要用 plug 平掉。

## 输出

输出滚动表，包含 “勾稽至” 列，逐行引用总账查询或支持文件；同时输出加总检查（通过/失败，以及如有未解释差额）。
