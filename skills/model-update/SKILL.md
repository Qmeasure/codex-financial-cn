# 模型更新

## 工作流

### 第 1 步：识别变化

确定更新触发因素：
- **业绩发布**：需要填入新的季度实际值
- **指引变化**：公司更新前瞻展望
- **预测修订**：分析师基于新数据调整假设
- **宏观更新**：利率、FX、大宗商品价格变化
- **事件驱动**：M&A、重组、新产品、管理层变动

### 第 2 步：填入新数据

#### 业绩发布后
用已披露实际值更新模型：

| 行项目 | 此前预测 | 实际 | 差异 | 备注 |
|--------|----------|------|------|------|
| 收入 | | | | |
| 毛利率 | | | | |
| 经营费用 | | | | |
| EBITDA | | | | |
| EPS | | | | |
| [关键指标 1] | | | | |
| [关键指标 2] | | | | |

**分部明细**（如适用）：
- 更新每个分部的收入和利润率
- 注明任何分部结构变化

**资产负债表 / 现金流量表更新**：
- 现金和债务余额
- 股本数量（回购、摊薄）
- Capex 实际值 vs. 预测
- 营运资本变化

### 第 3 步：修订前瞻预测

基于新数据调整前瞻预测：

| | 旧 FY 预测 | 新 FY 预测 | 变化 | 旧下一财年 | 新下一财年 | 变化 |
|---|----------|----------|------|------------|------------|------|
| 收入 | | | | | | |
| EBITDA | | | | | | |
| EPS | | | | | | |

**关键假设变化：**
- 你在改变哪些假设，为什么？
- 收入增长率：旧 → 新（原因）
- 利润率假设：旧 → 新（原因）
- 任何新增项目（重组费用、一次性收益等）

### 第 4 步：估值影响

用更新后的预测重新计算估值：

| 估值方法 | 此前 | 更新后 | 变化 |
|----------|------|--------|------|
| DCF 公允价值 | | | |
| P/E（NTM EPS × 目标倍数） | | | |
| EV/EBITDA（NTM EBITDA × 目标倍数） | | | |
| **目标价** | | | |

### 第 5 步：摘要与行动

**预测变化摘要：**
- 用一段话说明发生了什么变化、为什么变化，以及对股票意味着什么
- 这是会改变投资论点的事件，还是噪音？

**评级 / 目标价：**
- 维持还是调整评级？
- 新目标价（如调整）及方法
- 相对当前价格的上行/下行空间

### 第 6 步：输出

- 更新后的 Excel 模型（如用户提供现有模型）
- 预测变化摘要（Markdown 或 Word）
- 更新后的目标价推导

## 重要说明

- 在向前预测前，始终将你的预测与公司已披露数字勾稽
- 标注任何非经常性项目，并说明你的预测是 GAAP 还是调整后口径
- 跟踪预测修订历史，它能体现分析过程
- 如果季度噪音较多，在预测变化中区分信号和噪音
- 更新后检查一致预期：你的修订预测与 Street 相比如何？
- 股本数量很重要：股权激励、可转债或回购导致的摊薄/减少可能显著影响 EPS
