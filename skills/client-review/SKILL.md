# 客户回顾准备

## 工作流

### 第 1 步：客户背景

收集或查询：
- **客户姓名** 和家庭成员
- **账户类型**：应税账户、IRA、Roth、401(k)、信托等
- **跨账户总 AUM**
- **投资政策声明（IPS）**：目标配置、风险承受能力、约束
- **人生阶段**：积累期、退休前、退休、传承
- **上次会议日期** 和任何未完成行动事项

### 第 2 步：组合表现

对每个账户及家庭合计：

| 指标 | QTD | YTD | 1 年 | 3 年 | 成立以来 |
|------|-----|-----|------|------|----------|
| 组合回报 | | | | | |
| 基准回报 | | | | | |
| Alpha | | | | | |

**业绩归因：**
- 哪些资产类别 / 持仓驱动了回报？
- 前三大正贡献和前三大负贡献
- 是否存在单一持仓影响过大？

### 第 3 步：配置回顾

当前配置 vs. 目标配置：

| 资产类别 | 目标 | 当前 | 偏离 | 行动 |
|----------|------|------|------|------|
| 美国大盘 | | | | |
| 美国中小盘 | | | | |
| 国际发达市场 | | | | |
| 新兴市场 | | | | |
| 固收 | | | | |
| 另类资产 | | | | |
| 现金 | | | | |

标记任何超过 IPS 再平衡阈值的偏离（通常为 3-5%）。

### 第 4 步：谈话要点

生成会议议程：

1. **市场概览**（2-3 分钟）：简要宏观背景和展望
2. **组合表现**（5 分钟）：表现如何？原因是什么？
3. **配置回顾**（5 分钟）：是否需要再平衡？
4. **规划更新**（5-10 分钟）：
   - 生活变化？（工作、健康、家庭、住房、教育）
   - 收入需求是否变化？
   - 税务情况更新
   - 遗产规划更新
5. **行动事项**（5 分钟）：下次会议前要做什么？

### 第 5 步：主动建议

基于回顾，提出：
- 再平衡交易（如偏离超过阈值）
- Tax-loss harvesting 机会
- 现金配置或提款规划
- Roth 转换机会（如适用）
- 受益人更新或遗产规划需求
- 保险回顾（寿险、失能险、长期护理）

### 第 6 步：输出

- 一页式客户回顾摘要（Word 或 PDF）
- 含基准的表现表
- 配置饼图（当前 vs. 目标）
- 建议行动事项
- 会议议程

## 重要说明

- 会前了解客户，审阅上次会议记录
- 先讲客户关心的内容，而不是你想讲的内容
- 如果表现较差，直接说明，不要掩盖或包装
- 结尾始终给出明确行动事项、下一步和日期
- 记录会议纪要以及对 IPS 的任何修改
- 合规：确保所有材料符合机构政策和监管要求
