# 演示材料刷新

更新演示材料中的数字。材料本身是格式的事实来源；你只负责改值。

## 环境检查

此 skill 同时适用于 PowerPoint add-in 和聊天场景。开始前先判断所处环境。编辑机制不同，但目标相同：

- **Add-in**：材料已实时打开；直接编辑文本 run、表格单元格和图表数据。
- **Chat**：材料是上传文件；通过重生成受影响的幻灯片来写入新值，并把结果保存回文件。

无论哪种环境：都做最小必要修改，并保持既有格式不变。

这是一个四阶段流程，第三阶段是审批门。用户看过计划之前不要编辑。

## 阶段 1 — 获取数据

使用 `ask_user_question` 确认新数字如何提供：

- **粘贴映射**：用户输入或粘贴“收入 $485M → $512M，EBITDA $120M → $135M”。这是最清晰的情况。
- **上传 Excel**：可能有旧值/新值列，也可能是用户希望引用的全新输出 sheet。读取后，先确认哪一列对应什么，再相信数据。
- **只有新值**：“Q4 收入是 $512M，利润率是 22%。”你需要判断每个新值替换哪个旧值。这可以处理，但动手前必须确认映射；如果把用户本意用于毛利的 “$512M” 映射成收入，会造成很隐蔽的错误。

还要询问**派生数字**：如果收入变化，用户是否希望同步重算增长率、份额百分比等，还是保持原状？多数材料里会嵌着 “+15% YoY” 这类现在可能过期的数字。是否处理这些派生项应由用户决定，而不是由你擅自决定。

## 阶段 2 — 通读材料，找全位置

逐页阅读每一页。对每个旧值，找出所有出现位置，包括看起来并不完全相同的形式：

| 变体 | 示例 |
|---|---|
| 口径 | `$485M`、`$0.485B`、`$485,000,000` |
| 精度 | `$485M`、`$485.0M`、`~$485M` |
| 单位写法 | `$485M`、`$485MM`、`$485 million`、`485M` |
| 嵌入文本 | “收入增长至 $485M”、“a $485M business”、坐标轴标签 |

同一个数字可能在第 3 页写作 `$485M`，在第 8 页图表坐标轴写作 `485`，在第 15 页脚注写作 `$485.0 million`。这三处都是同一个数字。普通查找替换会漏掉其中两处，你不能漏。

**数字常藏在这些地方：**
- 文本框（最明显）
- 表格单元格
- 图表数据标签和坐标轴标签
- 图表源数据，即驱动柱形/折线的真实数据，不只是显示标签
- 脚注、来源行、小字说明
- 演讲者备注，如果用户关心备注

建立清单：对每个旧值，列出所有出现位置、出现时的精确文本，以及将变成什么。这份清单就是计划。

## 阶段 3 — 展示计划并取得批准

**这是对他人花时间制作的材料执行破坏性操作。** 编辑任何内容之前，先展示完整变更清单。格式要便于快速扫描：

```
$485M → $512M（收入）
  第 3 页  — 标题框：“收入增长至 $485M”
  第 8 页  — 图表坐标轴标签：“485”
  第 15 页 — 脚注：“FY24 收入为 $485.0 million”

$120M → $135M（Adj. EBITDA）
  第 3 页  — 表格单元格
  第 11 页 — 正文：“$120M of Adj. EBITDA”

未覆盖映射 — 可能为派生数字，未包含在用户映射中：
  第 3 页  — “+15% YoY”（增长率；如果基期未变，是否已过期？）
  第 7 页  — “12% market share”（是否由 $485M / 市场规模计算得出？）
```

“未覆盖映射”部分很重要。你不只是做查找替换，而是在捕捉用户晚上 11 点可能漏掉的二阶影响。如果映射写着 `$485M → $512M`，而第 3 页旁边还有 `+15% YoY`，这个增长率很可能已经不对。要标出来；不要悄悄修，也不要悄悄不管。

使用 `ask_user_question` 请求批准：按清单继续、继续但跳过未覆盖项，或让用户先修订映射。

## 阶段 4 — 执行、保留格式并报告

对每项修改，采取能完成目标的最小编辑。具体方式取决于环境：

- **Add-in**：直接编辑实时材料中的特定 run、单元格或图表序列。
- **Chat**：在新值就位的情况下重生成受影响的幻灯片，精确保留其他所有元素，并写回文件。

无论哪种方式，标准相同：

- **形状中的文本**：只改数值，字体、字号、颜色、加粗状态完全保持不变。如果 `$485M` 是句子中 14pt 深蓝加粗文本，`$512M` 也应在同一句位置保持 14pt 深蓝加粗。
- **表格单元格**：只改单元格，不动表格结构。
- **图表数据**：更新底层序列值，让柱形/折线真的移动。只改标签不改数据，会留下“说谎”的图表。

不要重排任何不需要触碰的内容。材料既有样式默认就是正确答案；你是外科医生，不是装修队。

最后一项修改完成后，报告实际发生了什么：

```
已在 8 页中更新 11 个数值。

已修改：
  [阶段 3 的清单，改为过去时]

未覆盖映射 — 未修改：
  第 3 页 — “+15% YoY”（派生值；由用户单独指定）
  第 7 页 — “12% market share”
```

对每一页已编辑幻灯片运行标准视觉核验。数字变长时（例如 `$485M` → `$1,205M`），可能溢出文本框或挤压表格列宽。要在用户发现之前先发现。

## 不做什么

- **不重建幻灯片**：如果新数字让页面叙事不再成立（例如文字写“利润率压缩”，但新数字显示利润率上升），标出问题，不要重写叙事。
- **不擅自重算**：派生数字由用户决定。阶段 1 的问题就是为了覆盖这一点。
- **不改格式**：如果材料使用 `$MM`，而用户映射写 `$M`，要匹配材料写法，而不是匹配用户映射。数值可以变，风格不变。
