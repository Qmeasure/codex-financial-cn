## 中文版执行契约

- 默认使用中国大陆金融语境：A股优先，港股和美股兼容；如用户指定市场、币种、会计准则或模板，以用户输入为准。
- 数据来源必须遵守插件根目录 `../../DATA_SOURCES_CN.md`：官方披露、用户文件、已授权 MCP/数据库优先；免费源只作辅助；监管、会计、KYC、基金文件和月结判断缺少依据时不得下结论，只在数据源发现记录中列为未覆盖数据项。
- 所有产物必须遵守插件根目录 `../../CN_OUTPUT_FORMATTING.md`：中文字体栈、中文日期、币种/单位、图表标题、表格表头、来源脚注、风险提示和免责声明都要按中文机构材料处理。
- 用户模板和品牌规范优先，但不得突破中文可读性、来源脚注、币种/单位/日期/口径说明这些底线。
- 保留 DCF、LBO、WACC、EV/EBITDA、IRR、MOIC、NAV、KYC、AML、MCP、CLI 等专业缩写和代码标识。

# 客户报告

## 工作流

### 第 1 步：报告参数

- **客户姓名** 和家庭
- **报告期间**：季度、YTD、年度、自定义区间
- **账户**：全部账户或特定账户
- **基准**：S&P 500、60/40 组合、与 IPS 匹配的自定义基准
- **机构品牌**：Logo、颜色、免责声明

### 第 2 步：表现摘要

**家庭汇总：**

|------|----------|------|------|------|----------|----------|
| | | | | | | |

### 第 5 步：市场评论

根据客户专业程度定制简短市场摘要：
- 本季度市场发生了什么（2-3 句）
- 对组合产生了什么影响
- 展望和配置理由（2-3 句）
- 零售客户避免术语；成熟投资者可以更技术化

### 第 6 步：活动摘要

- 期间执行的交易
- 追加投入和提款
- 收到的股息和利息
- 收取的费用
- 再平衡活动

### 第 7 步：规划备注

- 财务目标进展（退休、教育等）
- 任何计划变化或建议
- 即将执行的行动事项
- 下次回顾日期

### 第 8 步：输出

- 带机构品牌的 PDF 报告（8-12 页）
- 用于定制的 Word 文档
- Excel 数据附录（可选）

**报告结构：**
1. 封面页（客户姓名、期间、机构 logo）
2. 执行摘要（1 页）
3. 表现摘要（1-2 页）
4. 含图表的配置概览（1 页）
5. 持仓明细（1-2 页）
6. 市场评论（1 页）
7. 活动摘要（1 页）
8. 规划备注（1 页）
9. 披露和免责声明（1 页）

## 重要说明

- 除非客户/合规要求使用 gross，业绩必须按扣费后计算
- 始终包含适当免责声明和披露（过往业绩、风险因素）
- 客户之间报告应保持一致，使用标准模板
- 细节程度应匹配客户需求：有些客户要每个持仓，有些只要一页摘要
- 基准选择很重要：使用 IPS 中的基准，而不是选择看起来最好的基准
- 新模板首次分发前必须经过合规审阅批准
