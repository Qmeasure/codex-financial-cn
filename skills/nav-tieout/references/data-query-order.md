# 数据查询顺序合同

本文件是本 skill 的本地 reference。凡任务需要查询、刷新或补充外部数据，包括行情、财报、公告、行业、公司、宏观、监管、KYC、基金、月结和第三方数据库信息，必须先读取本文件。

## 默认执行顺序

1. 先检查用户提供的文件、当前会话可用 MCP、本地数据库和已授权数据源。
2. 明确哪些 MCP 或数据源适用于当前任务，哪些不可用、未登录、未授权或覆盖不足。
3. 优先使用官方披露、交易所公告、监管文件、公司公告、用户文件、已授权 MCP 和本地数据库。
4. MCP 或授权源不可用、无法覆盖或返回不足时，再进行网页搜索。
5. 免费网页源只能作为辅助验证；不得替代官方披露、用户文件或已授权数据源。
6. 监管、会计、KYC、基金文件、月结判断和合规结论没有依据时，必须写“需确认”。

## 与更严格规则的关系

- 如果本 skill 明确限定只能使用特定 MCP、用户文件或本地数据，则以更严格规则为准，不得退回网页搜索。
- 如果用户明确禁止联网或禁止使用某类数据源，必须遵守用户限制。
- 如果 MCP 登录失败或工具不可用，最终输出必须说明降级原因和未完成的复核项。

## 输出要求

- 最终产物必须列出主要数据来源、数据日期、币种单位、会计准则和口径限制。
- 涉及一致预期、估值倍数、市场份额、行业数据和宏观数据时，必须说明来源和截至日期。
- 对网页搜索得到的信息必须二次核验；无法二次核验时写“需确认”。
