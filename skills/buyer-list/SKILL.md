# 买方清单

## 工作流

### 第 1 步：理解标的

- 公司描述、所属行业和商业模式
- 收入、EBITDA 和增长特征
- 核心资产和能力（IP、客户关系、地域布局、团队）
- 预期估值区间
- 卖方偏好（战略买方 vs. 财务买方、管理层延续、时间表）

### 第 2 步：战略买方

按类别识别战略收购方：

**直接竞争对手**
- 与标的处于同一赛道、可通过收购获得市场份额的公司
- 逻辑：收入协同、减少竞争对手、扩大规模

**相邻市场参与者**
- 可从相邻市场扩展进入标的业务领域的公司
- 逻辑：产品延伸、交叉销售、进入新市场

**纵向整合方**
- 可进行纵向整合的客户或供应商
- 逻辑：供应链控制、利润留存、战略绑定

**平台型构建方**
- 通过 M&A 在该领域搭建平台的大型公司
- 逻辑：tuck-in 收购、补足能力缺口

对每个战略买方进行评估：

| 买方 | 行业 | 收入 | 战略匹配度 | 财务能力 | M&A 记录 | 可能性 | 优先级 |
|-------|------|------|--------------|----------|----------|--------|--------|
| | | | 高/中/低 | | 活跃/一般/无 | | A/B/C |

### 第 3 步：财务投资人

识别 PE/财务买方：

**平台型投资人**
- 正在该行业寻找新平台资产的投资人
- 标准：基金规模、行业聚焦、交易规模区间

**Add-on 买方**
- 已有组合公司可将标的作为 bolt-on 收购的投资人
- 识别具体组合公司和协同逻辑

**成长股权投资人**
- 适用于较早期或高增长标的
- 明确少数股权 vs. 控股偏好

对每个投资人进行评估：

| 投资人 | 基金规模 | 行业聚焦 | 组合重叠 | 近期活动 | 优先级 |
|--------|----------|----------|----------|----------|--------|
| | | | | | A/B/C |

### 第 4 步：优先级排序

对买方清单分层：

- **Tier 1（5-10 家）**：战略匹配度最高、有明确收购记录、逻辑清晰，优先联系
- **Tier 2（10-15 家）**：匹配度较好但逻辑不如 Tier 1 直接，第二波联系
- **Tier 3（10-20 家）**：存在可能性但概率较低，流程需要扩展时联系

### 第 5 步：联系人映射

对每个 Tier 1 买方：
- 关键决策人（CEO、Corp Dev 负责人、合伙人）
- 关系状态（已有关系、冷启动外联、需要引荐）
- 已知偏好或限制（规模、地域、交易结构）
- 最佳接触渠道

### 第 6 步：输出

- Excel 工作簿，包含：
  - 战略买方页签（按层级排序）
  - 财务投资人页签（按层级排序）
  - Tier 1 联系人映射
  - 汇总统计（按层级、类型统计买方总数）
- 用于聘书或 pitch 的一页式买方池摘要

## 重要说明

- 质量优先于数量：30-40 家经过充分研究的买方清单，优于 200 个泛泛名称
- 研究近期 M&A 活动：刚在该领域完成交易的买方，可能更积极，也可能资金或管理精力已被占用
- 检查直接竞争对手的反垄断问题：标记可能面临监管问题的买方
- 财务投资人：检查基金 vintage 和部署节奏，接近投资期末的基金可能更有动力
- 始终询问卖方是否有必须纳入或排除的买方
- 随流程推进持续更新清单，并根据反馈调整买方层级
