# 业绩预览

## 工作流

### 步骤 1：收集背景

- 确认公司和报告季度
- 通过网络检索提取一致预期（收入、EPS、关键分部指标）
- 查找业绩发布时间（盘前或盘后）
- 审阅公司上一季度业绩会，提取指引和管理层表述

### 步骤 2：关键指标框架

针对该公司构建“关注要点”框架：

**财务指标：**
- 收入 vs 一致预期（整体及分部）
- EPS vs 一致预期
- 利润率（毛利率、经营利润率、净利率）- 扩张还是收缩？
- 自由现金流
- 前瞻指引 vs 一致预期

**经营指标**（按行业选择）：
- 科技/SaaS：ARR、净留存率、RPO、客户数量
- 零售：同店销售、客流、客单价
- 工业：在手订单、订单出货比、价格 vs 销量
- 金融：NIM、信贷质量、贷款增长、手续费收入
- 医疗健康：处方量、患者量、管线进展

### 步骤 3：情景分析

构建 3 个情景并说明股价影响：

| 情景 | 收入 | EPS | 关键驱动 | 股价反应 |
|----------|---------|-----|------------|----------------|
| 乐观 | | | | |
| 基准 | | | | |
| 悲观 | | | | |

每个情景都要说明：
- 经营层面需要发生什么
- 管理层哪些表述会验证该情景
- 历史背景：类似业绩结果下股价曾如何反应？

### 步骤 4：催化剂清单

识别决定股价反应的 3-5 个因素：

1. [指标] vs [一致预期/买方预期] - 为什么重要
2. [指引项目] - 买方希望听到什么
3. [叙事变化] - 是否存在战略变化、M&A、重组

### 步骤 5：输出

生成一页业绩预览，包含：
- 公司、季度、业绩发布日期
- 一致预期表
- 重点关注指标（按重要性排序）
- 乐观/基准/悲观情景表
- 催化剂清单
- 交易设置：近期股价表现、期权隐含波动对应的预期涨跌幅

## 重要说明

- 一致预期会变化 - 必须注明来源和预测日期
- 来自买方调研的“whisper numbers”往往比公开一致预期更能反映市场真实期待
- 历史业绩反应可用于校准预期（如需外部数据，先按 `references/data-query-order.md` 检查可用 MCP/已授权源，覆盖不足时再搜索“[公司] 业绩后股价反应历史”）
- 期权隐含涨跌幅反映市场预期，应与情景分析进行对比
