# 组合再平衡

## 工作流

### 第 1 步：当前状态

对每个账户记录：
- 账户类型（应税账户、IRA、Roth、401k）
- 持仓和当前市值
- 成本基础（应税账户）
- 每个持仓的未实现收益/亏损

### 第 2 步：偏离分析

将当前配置与 IPS 目标比较：

| 资产类别 | 目标 % | 当前 % | 偏离 | 超配/低配金额 |
|----------|--------|--------|------|--------------|
| 美国大盘股 | | | | |
| 美国中小盘股 | | | | |
| 国际发达市场 | | | | |
| 新兴市场 | | | | |
| 投资级债券 | | | | |
| 高收益 / 信用 | | | | |
| TIPS / 通胀保护 | | | | |
| 另类资产 | | | | |
| 现金 | | | | |

标记超过再平衡区间的持仓（通常为 ±3-5%）。

### 第 3 步：交易建议

生成交易，使配置回到目标：

**税务敏感再平衡规则：**
- 优先在税收优惠账户（IRA、Roth）中再平衡，因为没有税务后果
- 在应税账户中避免卖出短期收益较大的持仓
- 在再平衡过程中尽可能实现亏损收割
- 注意所有账户之间的 wash sale 规则（30 天窗口）
- 可考虑将新增资金投向低配资产类别，而不是直接交易

**交易清单：**

| 账户 | 动作 | 证券 | 股数/金额 | 原因 | 税务影响 |
|------|------|------|----------|------|----------|
| | 买入/卖出 | | | 再平衡 / TLH | 短期收益 / 长期收益 / 亏损 |

### 第 4 步：资产位置审阅

优化各类资产应放在哪类账户：
- **递延纳税账户（IRA/401k）**：债券、REITs、高换手基金（税务拖累最高）
- **Roth**：预期增长最高的资产（免税增长）
- **应税账户**：税务效率较高的权益资产（指数基金、ETF、市政债）、可用于 tax-loss harvesting 的持仓

### 第 5 步：执行

- 按账户汇总交易
- 预计交易成本
- 预计税务影响（已实现收益/亏损）
- 对配置偏离的净影响

### 第 6 步：输出

- 偏离分析表
- 推荐交易清单（Excel）
- 税务影响摘要
- 再平衡前后配置对比

## 重要说明

- 不要为了再平衡而再平衡；区间内的小幅偏离可以接受
- 应税账户中的税务成本可能超过再平衡收益，应计算盈亏平衡点
- 交易前考虑待发生现金流（追加投入、提款、RMDs）
- 检查客户特定限制（ESG、集中持股、锁定期）
- 为每笔交易记录理由，以满足合规留痕
- Wash sale 规则跨账户适用；应在家庭账户层面协调交易
