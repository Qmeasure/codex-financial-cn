# Deck 检查报告格式

## 报告模板

```markdown
# Deck 检查报告：[演示文稿名称]

## 摘要
- 问题总数：X
- 严重：X（数字不一致、事实错误）
- 重要：X（叙事与数据不一致、语言问题）
- 轻微：X（格式问题）

## 严重问题

### 数字一致性
1. **[问题名称]**（第 X、Y 页）
   - 第 X 页：[数值]
   - 第 Y 页：[数值]
   - 处理建议：[建议]

### 数据与叙事一致性
1. **[问题名称]**（第 X、Y 页）
   - 表述：“[引用文本]”
   - 数据显示：[矛盾点]
   - 处理建议：[建议]

## 重要问题

### 语言打磨
1. **[问题类型]**（第 X 页）
   - 当前：“[引用文本]”
   - 建议：“[替代表述]”

## 轻微问题

### 格式
1. **[问题类型]**（第 X 页）
   - [问题描述和修复方式]

## 最终检查清单
- [ ] 数字已勾稽一致
- [ ] 叙事与数据一致
- [ ] 语言达到投行标准
- [ ] 图表已注明来源
- [ ] 格式一致
```

## 问题严重程度分类

**严重**（客户交付前必须修复）：
- 幻灯片之间数字不一致
- 计算错误
- 事实错误（姓名、职务、日期）
- 数据与叙事矛盾

**重要**（应修复）：
- 语言过于口语或不正式
- 结论含糊、缺少具体性
- 术语不一致
- 图表缺少来源

**轻微**（润色项）：
- 字体/颜色不一致
- 日期格式不一致
- 间距/对齐问题
- 孤行文本
