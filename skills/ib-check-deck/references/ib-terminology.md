# IB 术语参考

## 口语表达到专业表达的替换

| 口语/非正式表达 | 投行标准表达 |
|-----------------|--------------|
| “增长很多” | “显著增长”或“增长 X%” |
| “利润率还不错” | “利润率具有吸引力”或“利润率为 X%” |
| “他们买了这家公司” | “该公司被收购” |
| “大交易” | “转型性交易” |
| “估值便宜” | “估值具有吸引力”或“存在估值折价” |
| “贵” | “估值溢价” |
| “赚更多钱” | “提升盈利能力”或“推动利润率扩张” |
| “变大” | “追求增长”或“扩大经营规模” |
| “削减成本” | “实施成本优化”或“提升运营效率” |
| “很匹配” | “战略契合”或“具备有说服力的战略逻辑” |
| “帮忙” | “支持”或“促进” |
| “一堆” | “多个”或“众多” |
| “有点儿”/“差不多” | 删除或改为具体表述 |
| “真的”/“非常” | 删除或量化 |
| “大量” | “可观”或量化 |
| “巨大” | “显著”或量化 |
| “基本上” | 删除或澄清 |

## 应避免的语言模式

- **缩写口语：** 避免英文口语缩写；使用完整、正式表述。
- **感叹号：** 通常不适合投行材料。
- **第一人称：** “我们认为……”应改为“管理层认为……”或使用被动语态/客观表述。
- **缺乏证据的最高级：** “best-in-class” 必须有支持数据。
- **模糊量词：** “一些”、“很多”、“若干”应替换为具体数字。

## 推荐表达模式

**增长叙事：**
- “已验证的 X% 收入 CAGR 记录”
- “[期间] 内利润率持续扩张”
- “已验证的内生增长能力”

**市场地位：**
- “[具体细分市场] 第 X 大参与者”
- “[具体产品/服务] 的领先提供商”
- “通过 [具体属性] 形成差异化定位”

**战略逻辑：**
- “由……驱动的有说服力的战略契合”
- “通过……实现的有吸引力价值创造机会”
- “来自 [具体来源] 的 $Xm 协同潜力”
