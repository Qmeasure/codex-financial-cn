# 中文 XLSX 格式合同

本文件是本 skill 的本地 XLSX/Excel reference。生成正式工作簿前必须读取；根级 `../../CN_XLSX_OUTPUT_CONTRACT.md` 仍作为上位标准。

## 工作簿结构

- Sheet 名称使用中文或金融通用缩写，避免无意义默认名。
- 至少包含来源、假设或检查区；模型类文件必须有输入、计算、输出和检查逻辑。
- A股默认人民币单位；港股、美股、ADR 必须明确币种、单位和会计准则。
- 输入、公式、链接和检查项使用一致颜色或样式区分。

## 公式与来源

- 能用公式表达的计算必须优先使用公式，不要只写死数值。
- 来源单元格必须写明来源名称、日期和口径；可用时添加 hyperlink。
- 若工作簿包含图表，图表下方来源标注必须使用很小字体，建议 6-7.5pt，最大不得超过 8pt。
- 工作簿图表下方只保留最重要的 1 个来源并添加 hyperlink；多来源清单放入来源/假设 sheet，不得在图表下方罗列。
- 一致预期、估值倍数、市场数据和宏观数据未接入授权源时不得作为正式模型输入，必须放入数据缺口说明。
- 表头和单位必须中文化，例如 `收入（人民币亿元）`、`毛利率（%）`、`EV/EBITDA（倍）`。

## 交付与 QA

- 最终回复前必须确认 XLSX 文件已生成、路径存在、可打开或结构校验通过。
- 必须检查公式未被静态值替代、关键 sheet 存在、来源/假设/检查区可读。
- 最终回复必须包含 XLSX 文件路径。
