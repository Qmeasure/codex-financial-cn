# 中文 Markdown 与聊天输出格式合同

本文件是本 skill 的本地 reference。生成正式 Markdown 文件、聊天摘要、清单、表格或最终交付说明前必须读取；根级 `../../CN_OUTPUT_FORMATTING.md` 和 `../../CN_MARKDOWN_OUTPUT_CONTRACT.md` 仍作为上位标准。

## 适用范围

- 聊天摘要、即时分析、清单、备忘录、Markdown 报告和最终交付说明。
- 纯文本输出不强制落盘；但不得把聊天摘要冒充已经生成的文件交付物。
- 若用户要求或本 skill 承诺 `.md` 文件，必须生成真实 Markdown 文件，并在最终回复中给出文件路径。

## 中文格式要求

- 标题使用中文金融语境，层级从 `#`、`##`、`###` 依次展开，不跳级。
- 日期使用中文或 ISO 日期并保持一致，例如 `2026年5月29日` 或 `2026-05-29`。
- A股优先使用人民币和中文单位；港股、美股、ADR 必须明确币种、交易所、会计准则和口径。
- 表格表头使用中文，单位写入表头，例如 `收入（人民币亿元）`、`EV/EBITDA（倍）`。
- 来源必须写成可点击 Markdown 链接，禁止在正文裸露长 URL。
- 若 Markdown、聊天输出或最终交付说明包含 Exhibit（图表、表格、图片或关键数据块），Exhibit 下方来源标注只保留最重要的 1 个来源，并使用可点击 Markdown 链接；多来源清单放入“数据来源与口径说明”或“参考资料”，不得在 Exhibit 下方罗列。
- 正式 Markdown 导出到 DOCX、PPTX、HTML 或图片时，Exhibit 下方来源标注必须使用很小字体：默认 6pt，最大不得超过 7pt。
- 正式输出的正文、表格、脚注、Exhibit caption 和链接显示文本不得出现固定校验标签；正式表格缺失值使用 `—`，说明性限制放入“数据来源与口径说明”。
- 引用外部事实时必须写明来源、日期和口径；无法核验时不得作为正式结论。
- 结尾必须包含风险提示、数据缺口或免责声明，说明不构成投资、法律、税务、会计或监管建议。

## 最终回复门槛

- 如果主交付物是文件，最终回复必须包含真实文件路径。
- 如果只是聊天输出，最终回复必须说明主要来源、口径限制和需要人工审阅的事项。
- 不得声称已经完成未生成、未校验或路径不可访问的文件。
