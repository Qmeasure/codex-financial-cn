# 投资委员会备忘录

## 工作流

### 第 1 步：收集输入

从用户处收集，或从本会话既有分析中提取：

- 公司概览和业务描述
- 行业/市场背景
- 历史财务（3-5 年）
- 管理层评估
- 交易条款（价格、结构、融资）
- 尽调发现（商业、财务、法律、运营）
- 价值创造计划 / 100 天计划
- 回报分析（base、upside、downside）

### 第 2 步：起草备忘录结构

标准投委会备忘录格式：

**I. 执行摘要**（1 页）
- 公司描述、交易逻辑、关键条款
- 建议和核心回报
- 前三大风险和缓释措施

**II. 公司概览**（1-2 页）
- 业务描述、产品/服务
- 客户基础和 go-to-market
- 竞争定位
- 管理团队

**III. 行业与市场**（1 页）
- 市场规模和增长
- 竞争格局
- 长期趋势 / 顺风因素
- 监管环境

**IV. 财务分析**（2-3 页）
- 历史表现（收入、EBITDA、利润率、现金流）
- 盈利质量调整
- 营运资本分析
- Capex 需求

**V. 投资论点**（1 页）
- 为什么这是一项有吸引力的投资（3-5 个支柱）
- 价值创造抓手（内生增长、利润率扩张、M&A、倍数扩张）
- 100 天重点事项

**VI. 交易条款与结构**（1 页）
- 企业价值和隐含倍数
- 资金来源与用途
- 资本结构 / 杠杆
- 关键法律条款

**VII. 回报分析**（1 页）
- Base、upside 和 downside 情景
- 各情景下 IRR 和 MOIC
- 驱动回报的关键假设
- 敏感性分析

**VIII. 风险因素**（1 页）
- 按严重性和可能性排序的关键风险
- 每项风险的缓释措施
- 交易否决性风险（如有）

**IX. 建议**
- 明确建议：推进 / 放弃 / 有条件推进
- 关键条件或下一步

### 第 3 步：输出格式

- 默认：采用专业格式的 Word 文档（.docx）
- 替代：用于快速审阅的 Markdown
- 财务和回报部分必须包含表格，不只写正文

## 重要说明

- 投委会备忘录应基于事实且保持平衡，诚实呈现 bull 和 bear case
- 不要淡化风险。IC 成员会发现这些问题，可信度很重要
- 如用户提供机构标准备忘录模板，应使用该模板
- 财务表必须勾稽：检查 EBITDA bridge、S&U 平衡和回报计算一致性
- 缺少输入时应询问，不要自行假设交易条款或回报
