# 组合公司监控

## 工作流

### 第 1 步：读取财务包

- 接收用户的组合公司财务包（Excel 工作簿、PDF 或 CSV）
- 提取关键财务数据：收入、EBITDA、现金余额、未偿债务、capex、营运资本
- 识别报告期间，并与上期和预算/计划比较

### 第 2 步：KPI 提取与差异分析

需跟踪的关键指标（按公司所在行业调整）：

**财务 KPI：**
- 收入 vs. 预算（金额和百分比）
- EBITDA 和 EBITDA 利润率 vs. 预算
- 现金余额和净债务
- 杠杆率（净债务 / LTM EBITDA）
- 利息覆盖倍数
- Capex vs. 预算
- 自由现金流

**运营 KPI**（询问用户或从数据推断）：
- 客户数量 / 单客户收入
- 员工人数 / 人均收入
- 在手订单 / pipeline
- 流失率 / 留存率

### 第 3 步：标记并总结

- **绿色**：在计划 5% 以内
- **黄色**：低于计划 5-15%，标记用于讨论
- **红色**：低于计划 >15% 或存在契约违约风险，需立即关注

输出简洁摘要：
1. 一段执行摘要（“公司 X 当前表现[超前/落后/符合]计划……”）
2. KPI 表，包含实际 vs. 预算 vs. 上期
3. 带背景的红色/黄色 flags
4. 契约合规状态（如适用）
5. 给管理层的问题

### 第 4 步：趋势分析

如果提供多个期间：
- 绘制关键指标随时间变化图（收入、EBITDA、现金）
- 识别趋势：加速、减速或稳定
- 与 underwriting case 比较

## 重要说明

- 如未提供预算/计划，始终询问用于比较的预算/计划
- 不要假设行业特定 KPI；询问这家公司最重要的指标
- 如果契约水平未知，向用户询问信贷协议条款
- 输出应可直接用于董事会：简洁、基于事实、不空泛
