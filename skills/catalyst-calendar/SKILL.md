## 中文版执行契约

- 默认使用中国大陆金融语境：A股优先，港股和美股兼容；如用户指定市场、币种、会计准则或模板，以用户输入为准。
- 数据来源必须遵守根目录 `DATA_SOURCES_CN.md`：官方披露、用户文件、已授权 MCP/数据库优先；免费源只作辅助；监管、会计、KYC、基金文件和月结判断无依据时写“需确认”。
- 所有产物必须遵守根目录 `CN_OUTPUT_FORMATTING.md`：中文字体栈、中文日期、币种/单位、图表标题、表格表头、来源脚注、风险提示和免责声明都要按中文机构材料处理。
- 用户模板和品牌规范优先，但不得突破中文可读性、来源脚注、币种/单位/日期/口径说明这些底线。
- 保留 DCF、LBO、WACC、EV/EBITDA、IRR、MOIC、NAV、KYC、AML、MCP、CLI 等专业缩写和代码标识。


# 催化剂日历

## 工作流

### 步骤 1：定义覆盖池

- 需要跟踪的公司清单（股票代码或名称）
- 板块/行业重点
- 是否纳入宏观事件？（美联储会议、经济数据、监管截止日期）
- 时间范围（未来 2 周、1 个月、1 个季度）

### 步骤 2：收集催化剂

为每家公司识别即将发生的事件：

**业绩与财务事件**
- 季度业绩日期和时间（盘前/盘后）
- 年度股东大会
- 投资者日/分析师日
- 资本市场日
- 债务到期/再融资日期

**公司事件**
- 产品发布或公告
- FDA 批准/监管决定
- 合同续约或到期
- M&A 里程碑（交割日期、监管审批）
- 管理层变动
- 内部人交易窗口（限售解禁）

**行业事件**
- 重要会议（日期、参会公司）
- 展会和博览会
- 监管征求意见期或裁决
- 行业数据发布（月度销售、客流等）

**宏观事件**
- 美联储会议（FOMC 日期）
- 非农就业报告、CPI、GDP 发布
- 央行决议（ECB、BOJ 等）
- 对市场有影响的地缘政治事件

### 步骤 3：日历视图

| 日期 | 事件 | 公司/板块 | 类型 | 影响（高/中/低） | 我方仓位观点 | 备注 |
|------|-------|---------------|------|-----------------|----------------|-------|
| | | | 业绩/公司/行业/宏观 | | 多头/空头/中性 | |

### 步骤 4：周度预览

每周生成一份前瞻摘要：

**本周关键事件：**
1. [日期]：[公司] Q[X] 业绩 - 一致预期 [$X EPS]，我方预测 [$X]，重点关注：[指标]
2. [日期]：[事件] - 为什么对 [股票] 重要
3. [日期]：[宏观数据] - 市场预期和仓位观点

**下周预览：**
- 提前提示即将发生的重要事件

**仓位影响：**
- 可能影响具体持仓的事件
- 是否建议提前布局
- 二元事件前的风险管理

### 步骤 5：输出

- 带日历视图和可排序字段的 Excel 工作簿
- 周度预览邮件/笔记（Markdown）
- 可选：与 Google Calendar 集成

## 重要说明

- 业绩日期会变动 - 临近日期时需用公司 IR 页面和 Bloomberg/FactSet 复核
- 预公告风险：跟踪有业绩预告历史的公司（正面或负面）
- 会议参会名单很有价值 - 哪些公司出席，哪些公司明显缺席？
- 部分催化剂会周期性重复（月度行业数据）- 建立模板并自动填充
- 按影响程度使用颜色编码：红色 = 高影响，黄色 = 中等影响，绿色 = 常规
- 归档过去催化剂及实际结果 - 长期形成模式识别能力
