### 步骤 2：构建 DCF 分析

#### A. 计算 WACC

**1. 确定无风险利率**
   - 使用 10 年期国债收益率（检查当前利率；A股可用中国 10 年期国债收益率，美股用美国 10 年期国债收益率）
   - 示例：2024 年末约 4.0-4.5%

**2. 确定股权成本（CAPM）**
   ```
   股权成本 = 无风险利率 + Beta × 股权风险溢价

   输入：
   - 无风险利率：[当前 10 年期国债收益率，例如 4.2%]
   - Beta：[来自 Bloomberg/FactSet 的公司 beta 或同业平均值]
   - 股权风险溢价：5-6%（历史均值）

   示例：
   股权成本 = 4.2% + 1.3 × 5.5% = 11.35%
   ```

**3. 确定债务成本**
   ```
   债务成本 = 当前借款利率或债券隐含收益率

   对非上市公司：
   债务成本 = 无风险利率 + 信用利差（基于评级）

   示例：
   税前债务成本 = 6.5%
   税后债务成本 = 6.5% × (1 - 25% 税率) = 4.875%
   ```

**4. 确定资本结构**
   ```
   使用市场价值（不是账面价值）：

   股权市场价值 (E) = 股价 × 流通股数
   债务市场价值 (D) = 总债务（如果债券不交易，则使用账面价值）
   总价值 (V) = E + D

   股权权重 = E / V
   债务权重 = D / V

   示例：
   E = $5,000M (90.9%)
   D = $500M (9.1%)
   V = $5,500M (100%)
   ```

**5. 计算 WACC**
   ```
   WACC = (E/V × 股权成本) + (D/V × 债务成本 × (1 - 税率))

   示例：
   WACC = (90.9% × 11.35%) + (9.1% × 6.5% × (1 - 25%))
   WACC = 10.32% + 0.44% = 10.76%

   四舍五入：基准情形使用 10.8%
   ```

#### B. 计算终值

**方法 1：永续增长法（优先）**
```
终值 = FCF(2029) × (1 + g) / (WACC - g)

其中：
- FCF(2029) = 模型中的最后一年 unlevered FCF
- g = 永续增长率（通常 2.0-3.0%）
  - 不应超过长期 GDP 增速
  - 基准情形可使用 2.5%

示例：
FCF(2029) = $500M
g = 2.5%
WACC = 10.8%

终值 = $500M × (1.025) / (0.108 - 0.025)
终值 = $512.5M / 0.083 = $6,175M
```

**方法 2：退出倍数法（替代）**
```
终值 = EBITDA(2029) × 退出倍数

其中：
- 退出倍数 = 当前同业交易中位数（例如 12-15x EBITDA）

示例：
EBITDA(2029) = $800M
退出倍数 = 13x

终值 = $800M × 13x = $10,400M
```

**选择一种方法，或取两者平均。**

#### C. 将现金流折现到现值

```
预测 FCF 现值 = Σ [FCFt / (1 + WACC)^t]，t = 1 至 5

示例：
年份    FCF      折现       FCF 现值
        ($M)     系数       ($M)
2025    $250     1/(1.108)^1 = 0.9026    $226
2026    $320     1/(1.108)^2 = 0.8147    $261
2027    $390     1/(1.108)^3 = 0.7353    $287
2028    $450     1/(1.108)^4 = 0.6636    $299
2029    $500     1/(1.108)^5 = 0.5988    $299
                              现值合计： $1,372M

终值现值 = 终值 / (1 + WACC)^5
终值现值 = $6,175M / (1.108)^5 = $6,175M × 0.5988 = $3,697M

企业价值 = $1,372M + $3,697M = $5,069M
```

#### D. 计算股权价值和每股价格

```
企业价值                 $5,069M
- 净债务（债务 - 现金）        ($450M)
+ 非经营性资产                  $0M
- 少数股东权益                  $0M
- 优先股                        $0M
= 股权价值                      $4,619M

稀释后流通股数                  100M

每股价格 = $4,619M / 100M = $46.19

当前股价：$42.00
隐含上涨空间：10.0%
```

### 步骤 3：可比公司分析

#### A. 选择可比公司

**选择标准：**
- 同行业/同板块（首要要求）
- 商业模式相似
- 规模可比（市值、收入）
- 增长画像相似
- 地域相似

**识别 5-10 家可比公司：**
1. [同业 1] - 直接竞争对手
2. [同业 2] - 直接竞争对手
3. [同业 3] - 相邻玩家
4. [同业 4] - 相似商业模式
5. [同业 5] - 区域竞争对手
6. [再添加 3-5 家]

**记录选择每家同业公司的理由。**

#### B. 收集同业财务数据

**对每家可比公司收集：**
- 当前股价
- 摊薄后股本
- 市值
- 总债务和现金（用于 EV 计算）
- 企业价值
- LTM（过去十二个月）财务数据：
  - 收入
  - EBITDA
  - EBIT
  - 净利润
- NTM（未来十二个月）一致预期
- 收入增速
- EBITDA 利润率

**数据来源：**
- FactSet、CapitalIQ、Bloomberg（优先）
- 公司 10-K/10-Q 或年报/季报用于实际数据
- 如果没有专业工具，可使用 Yahoo Finance、Seeking Alpha 等一致预期；A股/港股优先使用官方披露、交易所文件、已授权 MCP 或合规数据源

#### C. 计算估值倍数

**对每家同业公司计算：**
```
EV/收入 (LTM) = 企业价值 / LTM 收入
EV/收入 (NTM) = 企业价值 / NTM 收入（估算）
EV/EBITDA (LTM) = 企业价值 / LTM EBITDA
EV/EBITDA (NTM) = 企业价值 / NTM EBITDA（估算）
P/E (NTM) = 市值 / NTM 净利润（估算）
```

#### E. 将倍数应用于目标公司

**选择主要倍数（成熟公司通常使用 EV/EBITDA）：**

```
标的公司 NTM EBITDA = $550M（来自财务模型）

应用同业中位数倍数：
同业 EV/EBITDA (NTM) 中位数 = 13.8x
隐含 EV = $550M × 13.8x = $7,590M

应用第 25 百分位（保守）：
第 25 百分位 EV/EBITDA (NTM) = 12.5x
隐含 EV = $550M × 12.5x = $6,875M

应用第 75 百分位（乐观）：
第 75 百分位 EV/EBITDA (NTM) = 14.1x
隐含 EV = $550M × 14.1x = $7,755M

估值区间（可比公司）：$6,875M - $7,755M
中点：$7,315M

转换为股权价值：
隐含 EV（中位数）          $7,590M
- 净债务                   ($450M)
= 隐含股权价值             $7,140M

流通股数                   100M
隐含每股价格               $71.40
```

**说明溢价/折价理由：**
- 标的增长 17%，同业中位数 17% → 一致
- 标的 EBITDA 利润率 23%，同业中位数 23% → 一致
- 标的市场地位 → [说明溢价/折价]
- **结论**：采用中位数倍数（不调整）

#### B. 确定权重理由

**典型权重：**
- DCF：40-60%（预测可靠时更高）
- 交易可比公司：25-40%（反映市场情绪）
- 先例交易：10-25%（除非 M&A 可能性较高，否则较低）

**本示例：**
- DCF 50%：对预测有较高信心
- 可比公司 40%：同业组充分
- 先例交易 10%：近期 M&A 可能性较低

## 合理性检查

**始终执行以下校验：**

1. **历史倍数检查**
   - 隐含倍数是否符合公司历史交易区间？
   - 如果不符合，解释原因

2. **同业比较**
   - 相对同业的溢价/折价是否由基本面支持？
   - 检查：增长、利润率、市场地位

3. **隐含增长检查**
   - 当前价格隐含了什么增长？
   - 结合公司轨迹是否合理？

4. **市值合理性**
   - 结合公司规模和 peers，总市值是否合理？
   - 相对行业，公司是否会显得过大或过小？

5. **终值检查**
   - 终值是否低于总企业价值的 60-70%？
   - 如果超过 70%，预测期可能不够长

6. **WACC 合理性**
   - 典型公司 WACC 是否落在 8-14% 区间？
   - 科技/高增长：10-14%
   - 成熟/稳定：7-10%

7. **隐含回报检查**
   - 从当前价格到 12 个月目标价的 IRR 是多少？
   - 是否与投资评级一致？
