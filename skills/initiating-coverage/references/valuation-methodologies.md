## 折现现金流（DCF）分析

### 概览

DCF 分析基于公司未来预计现金流的现值来估值。由于其基础是公司基本面的价值创造，因此通常被视为理论上最严谨的估值方法。

### DCF 分步流程

#### 1. 历史财务分析
- 收集 3-5 年历史财务数据
- 计算历史 FCF = EBIT(1-税率) + D&A - CapEx - NWC 变动
- 分析历史增速和利润率
- 识别趋势与周期性

#### 2. 建立收入预测（5-10 年）
**方法：**
- **自上而下**：从市场规模（TAM）→ 市场份额 → 收入
- **自下而上**：销量 × 单位价格
- **混合方法**：组合多个驱动因素

**关键考虑：**
- 管理层指引和历史增长
- 行业增速和市场趋势
- 竞争动态和市场份额演变
- 产品管线和新市场机会
- 宏观经济因素

#### 3. 预测经营费用
- **COGS**：按收入百分比建模（分析历史毛利率）
- **SG&A**：通常具有半固定属性；按收入百分比并体现规模效应建模
- **R&D**：对科技/医药行业尤其关键；按收入百分比建模
- **D&A**：基于 CapEx 假设

**计算 EBIT** = 收入 - COGS - 经营费用

#### 4. 计算无杠杆自由现金流
```
EBIT
× (1 - 税率)
= NOPAT（税后净营业利润）
+ 折旧与摊销
- 资本开支
- 净营运资本增加额
= 无杠杆自由现金流 (UFCF)
```

**CapEx 假设：**
- 维护性 CapEx：维持当前运营所需投入（通常为收入的 2-4%）
- 增长性 CapEx：扩张所需投入
- 参考行业基准和公司指引

**净营运资本：**
- NWC =（应收账款 + 存货）- 应付账款
- 按收入百分比或天数建模（DSO、DIO、DPO）
- NWC 增加代表现金流出

#### 5. 确定终值

**方法 A：永续增长法**
```
终值 = FCF（最后一年）× (1 + g) / (WACC - g)
```
- g = 永续增长率（通常 2-3%，不应超过 GDP 长期增速）
- 适用于公司已进入稳定成熟增长阶段

**方法 B：退出倍数法**
```
终值 = EBITDA（最后一年）× 退出倍数
```
- 退出倍数基于当前交易可比公司
- 更适合周期性业务

#### 6. 计算加权平均资本成本（WACC）

```
WACC = (E/V × 股权成本) + (D/V × 债务成本 × (1 - 税率))
```

**股权成本（使用 CAPM）：**
```
股权成本 = 无风险利率 + Beta × 股权风险溢价
```
- 无风险利率：10 年期国债收益率（A股可使用中国 10 年期国债收益率；美股用 10 年期美国国债收益率）
- Beta：股票收益率相对市场的回归 beta，或使用可比公司 beta
- 股权风险溢价：历史平均约 5-6%，需结合市场调整

**债务成本：**
```
债务成本 = 无风险利率 + 信用利差
```
- 使用公司当前借款利率，或从债券推导
- 如果没有存续债券，按信用评级调整

**资本结构：**
- E/V = 股权市场价值 / 总价值
- D/V = 债务市场价值 / 总价值
- 使用目标资本结构；如果当前资本结构明显不同，不要机械沿用

#### 7. 将现金流折现至现值

```
现值 = Σ [FCFt / (1 + WACC)^t] + [终值 / (1 + WACC)^n]
```

#### 8. 计算企业价值和股权价值

```
企业价值 = 预测 FCF 现值 + 终值现值
减：净债务（总债务 - 现金）
加：非经营性资产
减：少数股东权益
减：优先股
= 股权价值

每股价格 = 股权价值 / 稀释后流通股数
```

### DCF 敏感性分析

始终对关键变量做敏感性分析：

1. **双变量敏感性表**：WACC 与终值增长率
2. **收入增长情景**：基准 / 乐观 / 悲观情形
3. **利润率假设**：经营杠杆情景
4. **终值倍数敏感性**：使用退出倍数法时

**敏感性表示例：**
```
           终值增长率
WACC      2.0%    2.5%    3.0%
8.0%      $45     $48     $52
9.0%      $40     $43     $46
10.0%     $36     $39     $41
```

### 常见 DCF 错误

1. **重复计算增长**：不要在缺少相应投资（CapEx、NWC）的情况下预测高增长
2. **不现实的终值增长率**：不应超过长期 GDP 增速
3. **忽视周期性**：周期性行业需要对利润做标准化处理
4. **现金流定义错误**：使用无杠杆 FCF，而不是净利润
5. **假设不一致**：折现率要与现金流匹配（无杠杆 FCF → WACC）

## 交易可比公司分析

### 概览

交易可比公司基于公开市场中类似公司的估值水平对公司估值，反映当前市场情绪和相对估值。

### 可比公司分步流程

#### 1. 选择可比公司

**选择标准：**
- 同行业/同板块（首要标准）
- 商业模式和收入来源相似
- 规模可比（市值、收入）
- 增长画像和利润率相似
- 终端市场和地域相似

**典型样本池：**
- 从 8-15 家公司开始
- 剔除存在特殊情况的公司
- 最终保留 5-10 家

#### 2. 收集财务信息

**所需数据：**
- 当前股价和流通/摊薄股本
- 最近财年财务报表
- 来自一致预期的下一年度（NTM）预测
- 历史增速

**计算市场指标：**
- 市值 = 股价 × 股本
- 企业价值 = 市值 + 债务 + 少数股东权益 + 优先股 - 现金
- 净债务 = 总债务 - 现金及现金等价物

#### 3. 计算估值倍数

**企业价值倍数：**
- **EV/收入**：适合早期/高增长公司
- **EV/EBITDA**：最常用，适合资本密集型业务
- **EV/EBIT**：适用于 D&A 差异显著的情况

**股权价值倍数：**
- **P/E（市盈率）**：使用最广泛
- **P/B（市净率）**：适合金融机构
- **P/S（市销率）**：适合尚未盈利公司

**计算期间：**
- 过去十二个月（LTM）：历史口径
- 未来十二个月（NTM）：前瞻口径（优先）

#### 4. 分析并选择倍数

**创建可比公司表：**

| 公司 | 市值 | EV/收入 | EV/EBITDA | EV/EBIT | P/E (NTM) | 收入增长 | EBITDA 利润率 |
|---------|-----------|------------|-----------|---------|-----------|----------------|---------------|
| 可比公司 A | $10B      | 3.5x       | 12.0x     | 18.0x   | 22.0x     | 15%            | 28%           |
| 可比公司 B | $8B       | 3.0x       | 10.5x     | 16.0x   | 19.0x     | 12%            | 27%           |
| ...     | ...       | ...        | ...       | ...     | ...       | ...            | ...           |
| 中位数 | -         | **3.2x**   | **11.0x** | **17.0x** | **20.5x** | 13%            | 27.5%         |

**调整：**
- 剔除离群值（通常为超过 2 个标准差）
- 考虑使用中位数而非均值（受离群值影响较小）
- 如果部分可比公司更可比，可对倍数加权
- 根据增长、利润率、风险差异调整

#### 5. 将倍数应用于目标公司

**计算示例：**
```
标的公司 NTM EBITDA = $500M
选定 EV/EBITDA 倍数 = 11.0x
隐含企业价值 = $500M × 11.0x = $5,500M

减：净债务 = $1,000M
股权价值 = $4,500M

流通股数 = 100M
隐含每股价格 = $45.00
```

#### 6. 选择合适倍数

**选择依据：**
- **EV/收入**：高增长、未盈利公司（科技、未盈利生物科技）
- **EV/EBITDA**：最常用；资本密集型行业（制造、电信）
- **P/E**：盈利且资本结构稳定的公司（消费、零售）
- **行业特定指标**：银行用 P/B，油气用 EV/产量，媒体用 EV/订户

### 溢价/折价分析

基于以下因素应用溢价或折价：
- **增长溢价**：增长越高 → 倍数越高
- **盈利能力**：利润率越高 → 倍数越高
- **规模**：大公司通常享有流动性溢价
- **市场地位**：市场领导者享有溢价
- **地域因素**：发达市场与新兴市场

## 先例交易分析

### 概览

先例交易基于 M&A 交易中类似公司的成交价格对公司估值，反映控制权溢价和战略价值。

### 分步流程

#### 1. 识别相关交易

**选择标准：**
- 同行业或相似行业
- 规模相似（目标公司规模的 0.5x 到 2x 以内）
- 业务特征相似
- 近期交易（优先过去 3-5 年）
- 已公告并完成的交易（避免撤回交易）

**典型样本池：**
- 至少 5-10 笔交易
- 关注近期交易（越近期权重越高）

#### 2. 收集交易详情

**所需信息：**
- 交易日期（公告日和完成日）
- 收购价格和结构（现金、股票、混合）
- 交易时目标公司财务数据
- 战略理由和协同效应
- 支付的控制权溢价

**来源：**
- SEC 披露文件（S-4、8-K、委托书）；A股/港股使用交易所公告、重大资产重组报告书、通函等官方披露
- 新闻稿和投资者演示
- M&A 数据库（CapIQ、FactSet、Bloomberg）

#### 3. 计算交易倍数

**使用与交易可比公司相同的倍数，但基于交易价值：**

```
交易价值 = 股权购买价格 + 承担债务 - 取得现金

EV/收入 (LTM) = 交易价值 / 标的 LTM 收入
EV/EBITDA (LTM) = 交易价值 / 标的 LTM EBITDA
EV/EBIT (LTM) = 交易价值 / 标的 LTM EBIT
```

**计算控制权溢价：**
```
控制权溢价 =（要约价格 - 未受影响价格）/ 未受影响价格
```
- 未受影响价格 = 公告前 1-2 天目标公司股价
- 典型范围：20-40%

#### 4. 分析先例交易

**创建先例交易表：**

| 日期 | 标的 | 收购方 | 交易价值 | EV/收入 | EV/EBITDA | 溢价 | 交易理由 |
|------|--------|----------|------------|------------|-----------|---------|-----------|
| Q1'24 | 可比公司 X | 买方 A | $5.0B | 4.0x | 14.0x | 35% | 市场整合 |
| Q3'23 | 可比公司 Y | 买方 B | $3.5B | 3.5x | 12.5x | 28% | 战略契合 |
| 中位数 | - | - | - | **3.8x** | **13.0x** | **31%** | - |

#### 5. 应用于目标公司

**重要考虑：**
- 先例交易倍数通常高于交易可比公司（包含控制权溢价）
- 根据交易理由差异进行调整
- 比较交易发生时市场条件与当前市场条件
- 对近期交易赋予更高权重

**计算示例：**
```
标的公司 LTM EBITDA = $450M
选定 EV/EBITDA 倍数 = 13.0x（先例交易）
与交易可比公司倍数 = 11.0x

隐含 EV（先例交易）= $450M × 13.0x = $5,850M
隐含 EV（交易可比公司）= $450M × 11.0x = $4,950M

隐含控制权溢价 = $5,850M / $4,950M - 1 = 18%
```

### 对交易倍数的调整

**考虑按以下因素调整：**
- **市场条件**：牛市与熊市（M&A 活跃度）
- **交易结构**：战略买方与财务买方
- **协同效应**：高协同交易通常带来更高溢价
- **竞争动态**：单一竞买方与多个竞买方
- **时间价值**：较早交易相关性较低

## 估值调和

### 创建估值桥

在同一框架中展示三种方法：

**估值摘要示例：**

| 方法 | 企业价值 | 股权价值 | 每股价格 | 权重 | 隐含价值 |
|--------|------------------|--------------|-------------|--------|---------------|
| DCF 分析 | $5,200M | $4,200M | $42.00 | 50% | $21.00 |
| 交易可比公司 | $5,500M | $4,500M | $45.00 | 30% | $13.50 |
| 先例交易 | $5,850M | $4,850M | $48.50 | 20% | $9.70 |
| **加权平均** | - | - | **$44.20** | - | **$44.20** |

### 方法权重

**典型权重：**
- **DCF**：40-60%（反映基本面价值，但依赖预测准确性）
- **交易可比公司**：25-40%（反映当前市场情绪）
- **先例交易**：15-25%（除非 M&A 可能性较高，否则相关性较低）

**根据以下因素调整权重：**
- **预测置信度**：置信度越高 → DCF 权重越高
- **市场条件**：牛/熊市会影响可比公司法可靠性
- **M&A 可能性**：如果公司可能被收购或行业正在整合，权重更高
- **公司成熟度**：成熟公司 → 可比公司法权重更高；成长公司 → DCF 权重更高

### 估值区间

始终展示估值区间，而不是单点估值：

**方法：**
- **基准情形**：最可能情景
- **乐观情形**：乐观假设（收入增长、利润率）
- **悲观情形**：保守假设

**示例：**
```
悲观情形：$38 - $40
基准情形：$42 - $46
乐观情形：$48 - $52

投资建议：买入，目标价 $45（基准情形中点）
```

### 合理性检查

**用以下方式交叉检查估值：**
1. **历史倍数**：当前估值是否符合历史区间？
2. **同业比较**：相对同业的溢价/折价是否合理？
3. **隐含增长**：市场价格隐含了什么增长？
4. **隐含回报**：从当前价格到目标价的 IRR
5. **市值分析**：总市值是否合理？

---

## 结论

综合使用三种估值方法，可以为判断公允价值提供更稳健的框架：

- **DCF** 提供基于基本面的内在价值
- **交易可比公司**反映当前市场估值
- **先例交易**指示 M&A 价值和控制权溢价

关键是理解每种方法背后的假设，并展示一个经过充分论证、同时考虑多种情景和方法的估值区间。
