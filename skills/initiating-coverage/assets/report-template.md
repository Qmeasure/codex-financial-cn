# 股票研究首次覆盖报告模板

本模板提供创建完整股票研究首次覆盖报告的结构。构建最终报告文档时，以此作为指南。

**说明：** 实际报告必须使用 DOCX skill 创建。不要生成 Markdown 内容。

**关键要求：**
1. 创建 Word 文档前，先使用 Python（matplotlib/plotly）生成 20–30+ 张图表图片
2. **使用 DOCX skill**：创建具有专业样式、页眉/页脚和格式的报告
3. **嵌入真实图表图片**：在 Word 文档适当位置插入生成的 PNG/JPG 图表文件
4. **不要生成 Markdown**：不要生成 Markdown 内容。使用 DOCX skill 创建 `.docx` 文件。

**关键格式指南：**
- **最高信息密度**：每一页都应信息充实。文字、图表和表格交错排布。
- **不要出现孤立章节**：不要让章节标题单独占一页，也不要让单张图表独占一页。
- **20–30+ 张真实图表图片**：先生成图表图片文件，再用 DOCX skill 嵌入正文段落。

## 第 1 页：投资更新（最重要页面）

**关键**：第 1 页不是传统执行摘要，而是专业股票研究机构使用特定格式的**投资更新**。

**重要结构说明：**
- 这是“投资更新”或“公司更新”页面，不是“执行摘要”
- 左上角使用评级框
- 重点展示股价表现图（图 1）
- 包含 3–4 条详细 bullet，使用 ■ 字符
- 每条 bullet 以**加粗主题标题**开头，随后用 3–5 句解释
- 底部包含财务和估值指标表
- 所有图表都必须有图号（图 1、图 2 等）和来源行

**主体内容 - 详细 bullet（3–4 条）：**

使用 ■ 字符作为 bullet。每条 bullet 遵循以下格式：
```
■ **[加粗主题标题，概括核心观点]。** 正文解释，提供 3–5 句细节，包含具体数字、对比和分析。尽可能以数字和量化开头。使用 “vs.”，不要使用 “versus”。表述要具体、明确。

■ **[第二个主题标题]。** [3–5 句详细解释……]

■ **[第三个主题标题]。** [3–5 句详细解释……]

■ **[第四个主题标题 - 可选]。** [3–5 句详细解释……]
```

**Bullet 格式示例：**
```
■ **垂直 SaaS 领导地位与监管壁垒有望支撑 2030 年 500 亿美元以上 TAM。**

和交叉销售能力，推动了市场扩张。随着医疗 IT 市场预计到 2030 年达到 500 亿美元以上，
Acme Health 凭借监管壁垒和高切换成本，有望持续获取份额。管理层表示，当前 70% 的
收入来自企业级医院系统，显示出较强产品市场契合度。
```

## 图号和格式标准

**关键**：所有图表、图形和表格都必须遵循专业股票研究中的严格图号规则。

### 图号格式

**每张图/表必须包含：**
1. **连续编号**：图 1、图 2、图 3 等（贯穿整份报告连续编号）
2. **描述性标题**：“图 X - [公司] [具体指标] [图表/分析类型]”
3. **来源行**（始终在底部）：“来源：公司数据，[机构名称]估算。”

**示例：**
- 图 1 - [公司] 股价表现
- 图 2 - [公司] 按产品拆分的历史与预测收入结构
- 图 3 - [公司] 按地域拆分收入
- 图 4 - [产品名称]收入和每名患者每年价格
- 图 5 - [公司]毛利率变化
- 图 6 - DCF 敏感性分析（美元/股）
- 图 7 - 估值 Football Field

### 图注格式

```
图 X - [描述性标题]
[图表/表格/图形内容]
来源：公司数据，[机构名称]估算。
```

如果表格有多个数据来源：
```
图 X - [描述性标题]
[表格内容]
来源：公司披露文件、FactSet、[机构名称]估算。
```

### 放置指南

- 图表应按报告中出现顺序编号
- 第一张图（图 1）通常是第 1 页的股价图或收入增长轨迹
- 每张图必须在视觉元素正下方放置图注
- 来源行使用较小字体、斜体，位于图表最底部

## 使用本模板的说明

1. **第 1 页是关键：** 第 1 页的执行摘要必须包含全部关键信息：速览事实、财务快照、3 张图表、估值摘要、投资论点和风险。这是最重要的一页。

2. **最高信息密度：** 专业股票研究的信息密度极高。每一页都应填充交错排布的文字、图表和表格。目标是 60–80% 页面覆盖率，并尽量减少空白。

3. **不要出现孤立章节：** 不要让章节标题单独出现，也不要让单张图/表独占一页。始终组合元素。例如，不要把“财务快照”单独放在第 6 页；应与周边内容整合。

4. **20–30+ 张图表：** 全文放入大量图形，重点包括：
   - **按产品/分部拆分收入**（堆叠面积图）
   - **按地域拆分收入**（堆叠柱状图）
   - **财务表现趋势**（多张图表）
   - 图表应嵌入正文，而不是集中放在一起

5. **使用 DOCX skill：** 此大纲应使用 DOCX skill 转换为专业 Word 文档，包含正确格式、样式、页眉/页脚和页码

6. **内容交错排布：** 正文段落中应嵌入图表。每页应有 2–4 个不同元素（表格、图表、文字块）。

7. **格式一致：** 全文标题、正文、表格和图表使用一致样式。选择一套配色并贯穿使用。

8. **引用：** 所有数据点都要包含引用和来源

9. **校对：** 始终校对准确性，特别是财务数据和计算

10. **最后写执行摘要：** 虽然它出现在第 1 页，但应在完成全部分析后最后撰写

11. **平衡：** 客观呈现正面和负面因素

12. **具体优于泛泛：** 使用具体数据和示例，而不是泛泛表述
