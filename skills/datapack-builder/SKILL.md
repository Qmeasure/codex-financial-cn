# 金融数据包构建器

为私募股权、投资银行和资产管理场景构建专业、标准化的金融数据包。将 CIM、发行备忘录、SEC 披露文件、网页检索或 MCP server 数据转化为精美 Excel 工作簿，供投资委员会审阅。

**重要：** 整个工作流中，所有 Excel 文件创建和修改都必须使用 xlsx skill。

## 关键成功因素

每个数据包都必须达到以下标准。任何一点不达标，交付物都不可用。

### 1. 数据准确性（错误零容忍）
- 每个数字都能追溯到来源文件，并标注页码
- 计算一律使用公式，不得硬编码计算值
- 交叉检查小计和总计的内部一致性
- 验证资产负债表平衡：资产 = 负债 + 权益
- 确认现金流量表与资产负债表变动勾稽一致

### 2. 基础规则

**规则 1：财务数据（衡量金额）→ 使用带 $ 的货币格式**
触发词：收入、销售额、利润、EBITDA、盈利、亏损、成本、费用、现金、债务、资产、负债、权益、Capex
格式：以百万为单位使用 `$#,##0.0`，以千为单位使用 `$#,##0`
负数：使用 `$(123.0)`，不要使用 `-$123`

**规则 2：经营数据（计数量）→ 使用数字格式，不加 $**
触发词：单位数、门店、地点、员工、客户、平方英尺、物业、人数
格式：使用带千分位的 `#,##0`
负数：使用 `(123)`，并与表格其余部分保持一致

**规则 3：百分比（比率与比例）→ 使用百分比格式**
触发词：利润率、增长率、比率、百分比、收益率、回报率、利用率、入住率
格式：保留一位小数，使用 `0.0%`
显示：使用 `15.0%`，不要显示为 `0.15`

**规则 4：年份 → 使用文本格式，防止自动插入千分位**
格式：使用文本或自定义格式，避免显示为 `2,024`
显示：`2020`、`2021`、`2022`、`2023A`、`2024E`

**规则 5：上下文混合时，每个指标使用各自合适的格式**
示例：
```
分部分析, 2022, 2023, 2024
零售收入, $50.0, $55.0, $60.0
  门店数, 100, 110, 120
  单店收入, $0.5, $0.5, $0.5
```
收入和单店收入指标使用 `$`，门店数量使用数字格式。

**规则 6：所有计算都使用公式 → 不得硬编码计算值**
所有小计、总计、比率和衍生指标必须基于公式，不能写死数值。这能保证准确性，并支持动态更新。

### 3. 专业展示标准

**格式标准：**

**配色方案 — 两层含义：**

**第 1 层：字体颜色（xlsx skill 强制要求）**
- **蓝色文字（RGB: 0,0,255）**：所有硬编码输入（历史数据、假设），不包括普通文字
- **黑色文字（RGB: 0,0,0）**：所有公式和计算
- **绿色文字（RGB: 0,128,0）**：指向其他 sheet 的链接

**第 2 层：填充颜色（用于增强展示，可选）**
- 填充颜色是可选项，仅在用户要求或确实能增强展示时使用
- 如果用户要求颜色或专业格式，使用以下标准方案：
  - **章节标题**：深蓝色（RGB: 68,114,196）背景，白色文字
  - **子标题/列表头**：浅蓝色（RGB: 217,225,242）背景，黑色文字
  - **输入单元格**：浅绿/米色（RGB: 226,239,218）背景，蓝色文字
  - **计算单元格**：白色背景，黑色文字
- 如用户指定自有品牌颜色，可覆盖上述配色

**两层配色如何配合（如果使用填充色）：**
- 输入单元格：蓝色文字 + 浅绿填充 = “用户输入数据”
- 公式单元格：黑色文字 + 白色背景 = “计算值”
- Sheet 链接：绿色文字 + 白色背景 = “来自其他标签页的引用”

**字体颜色说明内容是什么；填充颜色说明内容位于哪里（如果使用）。**

**重要：** xlsx skill 的字体颜色规则是强制性的。填充颜色是可选项；默认使用白色/无填充，除非用户要求增强格式或颜色。

**始终应用：**
- 标题加粗、左对齐
- 数字右对齐
- 子项使用 2 个空格缩进
- 小计上方单下划线
- 最终合计下方双下划线
- 冻结行/列表头窗格
- 最少边框（仅在结构需要处使用）
- 字体一致（通常使用 Calibri 或 Arial 11pt）

**不得包含：**
- 给每个单元格都加边框
- 多种字体或字号
- 图表，除非用户明确要求
- 过度格式化或装饰

## 结构一致性

除非用户明确另有要求，使用标准 8 个标签页结构：
1. 执行摘要
2. 历史财务数据（利润表）
3. 资产负债表
4. 现金流量表
5. 经营指标
6. 物业/分部表现（如适用）
7. 市场分析
8. 投资亮点

### 标签页 1：执行摘要
目的：为忙碌高管提供一页概览

内容：
- 公司概览（用 2–3 句话说明商业模式）
- 核心投资亮点（3–5 条 bullet）
- 财务快照表（最近 3 年及预测期的收入、EBITDA、增长率）
- 交易概览（如适用）
- 突出展示关键指标

格式：干净、标题加粗、装饰最少，突出关键数字

### 标签页 2：历史财务数据（利润表）
目的：完整利润表历史

内容：
- 按业务分部/产品线拆分的收入
- COGS / 收入成本
- 毛利和毛利率 %
- 经营费用明细（S&M、R&D、G&A）
- EBITDA 和 Adjusted EBITDA
- 线下项目（D&A、利息、税项）
- 净利润

格式：
- 年份作为列（文本格式：2020、2021、2022）
- 以百万美元或千美元呈现（在表格顶部明确单位）
- 所有财务数据使用会计格式
- 小计上方单下划线，净利润下方双下划线
- 所有数字右对齐

### 标签页 3：资产负债表
目的：展示期末财务状况

内容：
- 流动资产（现金、应收账款、存货、预付款、其他）
- 长期资产（PP&E、无形资产、商誉、其他）
- 流动负债（应付账款、应计费用、一年内到期债务、其他）
- 长期负债（长期债务、递延税项、其他）
- 股东权益（普通股、留存收益、其他）

格式：
- 验证公式：资产 = 负债 + 权益
- 日期标签保持一致
- 包含营运资本计算
- 主要小计上方使用单下划线，最终合计使用双下划线

### 标签页 4：现金流量表
目的：分析现金生成与使用

内容：
- 经营现金流（优先使用间接法）
- 投资现金流（capex、收购、资产出售）
- 融资现金流（债务发行/偿还、股权、分红）
- 现金净变动
- 期初和期末现金余额

格式：
- 尽可能链接到利润表和资产负债表
- 展示净利润到经营现金流的调节
- 清晰标注现金用途（流出）和现金来源（流入）

### 标签页 5：经营指标
目的：非财务 KPI 和经营数据

内容（取决于行业）：
- 销量、客户数量、门店/网点数量
- 生产率指标（人均收入、单店收入、单位收入）
- 产能利用率
- 市场份额
- 客户留存率/流失率
- 行业特定 KPI

**关键格式说明：**
经营指标不要加美元符号。这些是数量，不是货币。

格式：
- 明确单位（客户、员工、门店、平方英尺等）
- 整数带千分位：`1,250`，不要写成 `$1,250`
- 比率用百分比：`95.0%`
- 数字右对齐

### 标签页 6：物业/分部表现（如适用）
目的：按业务单元、物业或分部详细拆分

内容：
- 按分部拆分的收入和盈利能力
- 按地点/产品拆分的关键指标
- 分部特定 KPI
- 对比表现分析

格式：收入/EBITDA 与财务标签页保持一致；经营指标使用数字格式

### 标签页 7：市场分析
目的：提供行业背景与竞争定位

内容：
- 市场规模与增长趋势
- 竞争格局概览
- 市场份额分析
- 行业基准和可比公司对比
- 相关监管环境（如适用）

格式：叙述文字与表格结合；市场数据必须引用来源

### 标签页 8：投资亮点
目的：对核心投资论点进行叙述性总结

内容：
- 竞争优势详述
- 增长机会和战略举措
- 风险因素与缓释措施
- 管理层评估和过往业绩
- 投资论点总结

格式：清晰标题、bullet、简洁段落

## 分步工作流

### 阶段 1：文件处理与数据提取

**步骤 1.1：分析来源数据**
- 访问来源材料：上传文件、公开披露网页检索，或 MCP server 数据
- 审阅数据结构并识别关键章节
- 定位财务报表（通常为 3–5 年历史数据）
- 如包含管理层预测，识别预测内容
- 记录财政年度截止日
- 立即标记任何数据质量问题

**步骤 1.2：提取财务报表**
- 定位历史利润表数据
- 提取资产负债表快照（年末或季末）
- 找到现金流量表
- 如可得，提取管理层预测
- 记录所有页码引用，确保可追溯

**步骤 1.3：提取经营指标**
- 识别与行业相关的非财务 KPI
- 捕捉单位经济数据
- 提取客户/网点/产能数据
- 记录增长指标与趋势

**步骤 1.4：提取市场与行业数据**
- 竞争定位信息
- 市场规模与增长率
- 行业基准数据
- 可比公司信息

**步骤 1.5：记录关键背景**
- 交易结构和交易理由
- 管理团队背景
- 来源材料中的投资亮点
- 风险因素和考虑事项
- 任何数据缺口或不一致

### 阶段 2：数据归一化与标准化

**步骤 2.1：统一会计呈现**
- 确保所有年度使用一致的科目名称
- 标准化收入确认处理
- 识别并记录一次性费用
- 如需要，创建 “Adjusted EBITDA” 调节表
- 记录任何会计政策变化

**步骤 2.2：应用格式识别逻辑**
对每个数据点，根据完整上下文判断格式：
- 阅读标签页名称、表格标题、列表头和行标签
- 应用上方基础规则
- 不确定时，查看原始来源文件
- 默认采用更简洁的格式（少即是多）

**步骤 2.3：识别归一化调整**
常见需要记录的调整：
- 重组费用（如确属非经常性，可加回）
- 股权激励费用（按行业惯例加回）
- 收购相关成本（加回并说明金额）
- 法律和解或诉讼成本（评估复发风险）
- 资产出售或减值（从经营业绩中剔除）
- 关联方调整（归一化至市场水平）
注：来源引用格式取决于数据来源（文件页码、网页 URL、MCP 数据的 server reference）

**步骤 2.4：创建调整明细表**
对每项归一化调整：
- 记录调整内容和原因
- 引用来源（文件页码、URL 或数据来源 reference）
- 按年度量化金额影响
- 评估复发风险
- 展示从报告数到调整后数的计算

**步骤 2.5：验证数据完整性**
- 确认小计用公式正确求和
- 验证资产负债表平衡
- 检查现金流量表与资产负债表变动勾稽
- 跨标签页交叉检查数字一致性
- 标记任何需要进一步调查的差异

### 阶段 3：构建 Excel 工作簿

**关键：所有 Excel 文件操作都使用 xlsx skill。继续前先阅读 xlsx skill 文档。**

**步骤 3.1：创建标准化标签页结构**
创建包含以下标签页的工作簿：
- 执行摘要
- 历史财务数据
- 资产负债表
- 现金流量表
- 经营指标
- 物业表现（如适用）
- 市场分析
- 投资亮点

**步骤 3.2：按专业格式构建每个标签页**
系统应用格式规则：
- 标题：加粗、左对齐、11pt 字体
- 财务数据：以百万为单位使用货币格式 `$#,##0.0`
- 经营数据：使用数字格式 `#,##0`（不加 `$`）
- 百分比：使用 `0.0%` 格式
- 年份：文本格式，防止插入千分位
- 负数：使用带括号的会计格式
- 下划线：小计上方单下划线，合计下方双下划线

**步骤 3.3：为计算插入公式**
- 所有小计和合计必须基于公式
- 适当将资产负债表链接到利润表
- 将现金流量表链接到利润表和资产负债表
- 创建跨标签页引用用于校验
- 避免硬编码任何计算值

### 错误：硬编码行偏移

**不要使用相对偏移；表格结构一变就会断：**

```python
# ❌ 错误 - 基于偏移的引用很脆弱
formula = f"=B{row-15}/B{row-19}"  # row-15 是什么？row-19 是什么？

# ❌ 错误 - 魔法数字
formula = f"=B{current_row-10}*C{current_row-20}"
```

**为什么会失败：**
- 添加/删除行时会静默损坏
- 阅读代码时无法验证正确性
- 会在交付的 Excel 文件中制造调试难题

- 所有数字右对齐
- 所有文字和标题左对齐
- 按会计标准添加单/双下划线
- 确保外观干净、克制、专业

### 阶段 4：构建情景（如包含预测）

**管理层情景：**
按来源材料展示公司提供的预测：
- 提取所有管理层假设
- 记录增长率、利润率扩张、资本需求
- 说明关键驱动因素和敏感性
- 标记任何需要保持怀疑的“hockey stick”拐点
- 明确标为“管理层情景”

**基准情景（风险调整后）：**
根据公司特定风险因素，对管理层预测做保守调整：
- 基于执行风险和历史预测准确性，对收入增长打折
- 参考行业基准和经营杠杆，调低利润率扩张假设
- 如果增长依赖资本开支，提高 capex 假设
- 如果营运资本需求被低估，补充营运资本需求
- 如适用，基于整合复杂度推迟协同兑现
- 记录所有调整的理由和支持分析

**下行情景（可选，但 LBO 分析中建议包含）：**
基于行业周期性和公司脆弱性进行压力测试：
- 建模反映衰退风险或竞争压力的收入下滑
- 假设压力情景下利润率压缩（销量去杠杆、价格压力）
- 测试 covenant 合规和流动性
- 评估下行保护
- 记录被压力测试的关键风险

**情景文档要求：**
创建假设明细表，展示：
- 各情景关键假设（收入增长、利润率、capex %）
- 每项调整的理由
- 关键变量敏感性分析
- 如可得，列示历史预测准确性
- 与行业基准对比

## 归一化模式

### 常见 EBITDA 调整

**1. 重组费用**
- 如确属非经常性（关闭设施、一次性裁员），可加回
- 如果公司每年都重组，不要加回
- 记录具体性质和非经常性理由
- 示例：“2023 年重组：300 万美元设施关闭费用，来源材料已记录，为一次性事件”

**2. 股权激励费用**
- 行业惯例：私募股权分析中加回
- 作为非现金经营费用处理
- 所有期间保持一致
- 如金额异常高或包含一次性授予，需注明

**3. 收购相关成本**
- 加回交易费用和整合成本
- 按类型记录具体金额
- 不要加回持续性整合投入
- 每项调整都引用来源

**4. 法律和解与诉讼**
- 如确属孤立事件，可加回
- 评估复发风险（一项和解 vs 多次诉讼模式）
- 记录和解性质
- 考虑这是否属于正常经营过程

**5. 资产出售或减值**
- 从经营 EBITDA 中剔除资产出售收益/损失
- 如减值确属非经常性，可剔除减值费用
- 记录出售/减值资产及原因
- 如果相关资产曾产生经营收入，调整收入

**6. 关联方调整**
- 将高于市场水平的关联方费用（租金、管理费）归一化
- 用支持性文件调整至市场费率
- 剔除通过公司列支的个人费用
- 记录市场费率对比

### 保守归一化 vs 激进归一化

**管理层情景：**
- 包含管理层提出的所有调整
- 接受公司对“非经常性”的定义
- EBITDA 调整更激进
- 用于理解管理层观点

**基准情景（投资决策建议使用）：**
- 只包含明确非经常性的项目
- 对反复出现的“一次性”费用提高审查强度
- 排除投机性调整
- 更保守，也更容易向投资委员会解释

## 行业特定适配

### 科技 / SaaS
需要捕捉的关键指标：
- ARR（年度经常性收入）和 MRR
- 按 cohort 拆分的客户数量
- CAC（客户获取成本）和 LTV（生命周期价值）
- 流失率（gross 和 net）
- 净收入留存率
- Rule of 40（增长率 % + EBITDA 利润率 %）
- Magic Number（销售效率）

格式说明：ARR 是货币（$），客户数量是数字（不加 $），比率使用 %

### 制造 / 工业
需要捕捉的关键指标：
- 产能和产能利用率 %
- 按产品线拆分的产量
- 存货周转
- 按产品线拆分的毛利率
- 在手订单

格式说明：产量、产能是数字（不加 $），利用率是 %，收入/成本是货币

### 房地产 / 酒店
需要捕捉的关键指标：
- 物业/房间/面积
- 入住率 %
- ADR（平均每日房价）— 货币格式
- RevPAR（每间可售房收入）— 货币格式
- NOI（净营业收入）— 货币格式
- 资本化率 %
- FF&E 储备

格式说明：房间/面积是数字，入住率是 %，ADR/RevPAR 是货币

### 医疗 / 服务
需要捕捉的关键指标：
- 网点/机构
- 医生/员工
- 患者/就诊量（量指标）
- 单次就诊收入 — 货币
- 支付方结构 %
- 同店增长 %

格式说明：网点/就诊量是数字，单次就诊收入是货币，比率使用 %
